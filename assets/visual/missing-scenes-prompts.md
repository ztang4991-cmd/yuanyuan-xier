## 1. 缘缘茶馆·门口外景·夜晚版（脚本02）

**[全片视觉风格基准]**  
二维新国风治愈系动画风格。画面呈现温暖明亮的竹青色主调，融合淡彩色彩和柔和描边。整体氛围温馨治愈，光影柔和但有层次，避免过艳色彩。参考日系动画大师的细腻表情刻画和现代3D动画工作室的柔和质感。

**[场景描述]**  
缘缘茶馆的门口外景，夜晚时段。一扇深色竹木框架的推拉门，门框呈现自然的竹青色，表面经过打磨但保留竹节纹理。门半开着，从门内透出昏暗的竹制灯笼光——暖黄色的柔和光线在门框边缘形成光晕，照亮门口的竹制脚垫和青石台阶。

门框上方悬挂着一块手写体竹制招牌"缘缘茶馆"，字迹温润有力，在微弱的月光下依稀可辨。招牌旁挂着一串竹风铃，在夜风中静止不动。门口左侧种着一丛翠绿的小竹子，竹叶在月光下呈现深绿色。门右侧摆放着一个陶瓷茶壶造型的装饰摆件。

门外有微弱的月光从画面右上方斜射过来，在地面和门框上投下淡淡的冷色调影子，与门内透出的暖光形成冷暖对比。门槛是一块略微磨损的深色木板，可以看出被无数脚步踩踏过的痕迹。

夜空是深蓝偏紫的色调，点缀着几颗小星星。背景可以隐约看到浮云城其他建筑的夜景轮廓和飘浮的云层，营造出"私密空间的边界"氛围。整体色调以深蓝夜空、暖黄灯光、竹青门框为主，适合表现门口对峙、私密对话等场景。

**[技术参数]**  
- 画幅：9:16竖屏  
- 镜头：中景，平视角度，门口正面拍摄  
- 光线：门内暖黄灯光从半开的门透出 + 门外冷色月光，形成冷暖对比  
- 色调：深蓝夜空 + 暖黄灯光 + 竹青色门框  
- 细节：门半开状态清晰、灯光光晕、月光影子、竹风铃轮廓、门槛磨损痕迹

**[剧情功能]**  
脚本02中喜儿和缘缘在门口对峙的场景。昏暗灯光从门内透出，形成内外光线对比，营造对峙、私密空间被闯入的氛围。

## 2. 缘缘茶馆·门口外景·黄昏版（脚本09/10）

**[全片视觉风格基准]**  
二维新国风治愈系动画风格。画面呈现温暖明亮的竹青色主调，融合淡彩色彩和柔和描边。整体氛围温馨治愈，光影柔和但有层次，避免过艳色彩。

**[场景描述]**  
缘缘茶馆的门口外景，黄昏时段。同样的深色竹木框架推拉门，但这次是在夕阳的金色光线照耀下。门完全敞开，可以看到室内温暖的茶馆一角——竹桌、茶具的轮廓在背景中模糊可见。

夕阳从画面左侧斜射过来，将整个门口染成温暖的橙金色。竹木门框在夕阳下呈现出蜜糖般的暖色调，竹节的纹理被侧光强化，格外清晰。门框上方的"缘缘茶馆"招牌在逆光中形成优美的剪影，但字迹依然清晰可辨。

门口的竹风铃在夕阳光下闪烁着温润的光泽，迎风轻轻摇晃。左侧的小竹子被夕阳照得翠绿发亮，投射在地面上的影子是明亮的金绿色。门右侧的陶瓷茶壶摆件表面反射着暖光。

门口台阶2-3级，每级台阶的边缘在夕阳下形成明亮的高光线。青石铺成的地面呈现出温暖的灰金色。门口可站2-3人的空间很明显，适合多人对话场景。

天空是橙红渐变到淡紫的色彩，飘着几朵被夕阳染成粉紫色的柔软云朵。背景中浮云城的建筑剪影在夕阳中显得温馨而有希望。整体氛围从犹豫转向温暖，适合表现情感转折、温情对话等场景。

**[技术参数]**  
- 画幅：9:16竖屏  
- 镜头：中景，平视角度，门口正面，略带逆光  
- 光线：夕阳金色侧光从左侧照来，门完全敞开，室内外光线融合  
- 色调：橙金色主调 + 蜜糖色竹木 + 粉紫天空  
- 细节：夕阳光斑清晰、竹节纹理强化、风铃反光、地面影子、云朵柔软

**[剧情功能]**  
脚本09中喜儿在门口犹豫的场景，脚本10中团团走出茶馆的场景。夕阳暖光营造出从犹豫到温暖、从告别到出发的氛围转变。

## 3. 客户门口（脚本07专用）

**[全片视觉风格基准]**  
二维新国风治愈系动画风格。画面呈现温暖明亮的竹青色主调，融合淡彩色柔和描边。整体氛围温馨治愈，光影柔和但有层次，避免过艳色彩。

**[场景描述]**  
一户普通民居的门口，浮云城典型的居民建筑风格。门框是简单的木质结构，颜色是略微褪色的棕灰色，没有缘缘茶馆那样精致，显得更普通和生活化。门是关闭状态，门板上有轻微的磨损痕迹和几道浅浅的划痕。

门框旁边有一个小门牌，上面写着门牌号（模糊处理，不需要具体数字）。门前有1-2级青石台阶，台阶边缘略有磨损。台阶下方是铺着灰色石板的小平台，约1平方米，足够一个人站立。

傍晚时段，光线从门内透出——这是逆光的设置，客户站在门内，被门内的暖光勾勒出轮廓（客户本人留空，不描述具体外貌，等待后期叠加角色素材），形成一种压迫感的剪影效果。门外的喜儿位置在台阶下方，处于相对暗的区域。

门口没有装饰性物件，墙面是浮云城建筑典型的淡青色，表面有轻微的云状纹理（像是云朵凝固后的质感）。墙角有一些细微的污渍和岁月痕迹，显示这是一户普通人家。

整体氛围是"日常但带有压迫感"的冷漠场景——不是温馨的家门口，而是服务业从业者面对的众多普通客户中的一个。色调以灰棕色门框、淡青色墙面、暖黄逆光为主。

**[技术参数]**  
- 画幅：9:16竖屏  
- 镜头：中景，略微仰视（从台阶下往上看），门口正面  
- 光线：门内暖光逆光，客户剪影，门外较暗  
- 色调：灰棕门框 + 淡青墙面 + 暖黄逆光  
- 细节：门板磨损、台阶边缘、墙面云纹理、客户位置留空（剪影轮廓）

**[剧情功能]**  
脚本07开场，喜儿送快递被客户要求"笑一个"的场景。客户逆光站立形成压迫感，门外的喜儿显得渺小和被动，营造服务业的尊严被忽视的氛围。

## 4. 墙边/门口外（脚本07专用）

**[全片视觉风格基准]**  
二维新国风治愈系动画风格。画面呈现温暖明亮的竹青色主调，融合淡彩色彩和柔和描边。整体氛围温馨治愈，光影柔和但有层次，避免过艳色彩。

**[场景描述]**  
客户门口外侧的墙边区域，喜儿可以靠墙坐下的空间。这是紧邻上一个场景（客户门口）的延伸，墙面是同样的淡青色浮云城建筑材质，表面有云状纹理。墙面略微粗糙，不是光滑的现代墙面，而是带着手工感的质地。

墙面高约3米，占据画面左侧三分之二。墙角有细微的污渍和岁月痕迹——不是破败，而是生活过的真实感。墙面下方有一小块阴影区域，适合人靠墙坐下。

地面是灰色的云纹石板，石板之间的缝隙略宽，缝隙里长着几根细小的杂草。地面有轻微的起伏，不是完全平整的。墙边有一个喜儿可以坐下的位置——地面干净但不豪华，就是普通的街边墙角。

傍晚时段，光线从画面右侧照来（街道方向的余光），在墙面上投下斜长的影子。墙边区域处于半阴影中，光线昏暗但不是完全黑暗。随着时间推移（缘缘到来后），光线逐渐变暖——从冷色调的傍晚光转为暖色调的茶馆方向透来的光。

背景模糊处理，可以隐约看到浮云城街道的轮廓和飘浮的云层。整体氛围是"孤独、疲惫、崩溃边缘 → 被看见后的温暖"。色调前期以冷灰色为主（淡青墙面 + 灰色地面 + 昏暗傍晚光），后期逐渐加入暖色调。

**[技术参数]**  
- 画幅：9:16竖屏  
- 镜头：中景，平视角度，墙面占据画面左侧，右侧留出人物空间  
- 光线：前期傍晚昏暗侧光（冷色调），后期茶馆方向暖光渐入  
- 色调：淡青墙面 + 灰色地面 + 冷暖光线对比  
- 细节：墙面云纹理、污渍、地面石板缝隙、杂草、影子、坐地位置明确

**[剧情功能]**  
脚本07中喜儿崩溃坐地、缘缘路过递茶的核心场景。墙边提供了一个"撑不住可以靠着滑下"的物理支撑，地面是"坐地哭泣"的空间。光线从冷到暖的变化象征情绪从崩溃到被温暖接住。

## 使用建议

### 复制提示词时的注意事项

1. **完整复制**：每个提示词包含三段（[全片视觉风格基准] + [场景描述] + [技术参数]），建议完整复制以保证生图质量。

2. **工具适配**：
   - **即梦**：直接复制全文，在"画风"选项中选择"二维插画"或"动漫风格"
   - **Nano Banana**：复制[场景描述]段，视觉风格段精简为"新国风治愈系动画"加在开头
   - **Gemini**：完整复制效果最佳，Gemini擅长理解叙事性描述

3. **画幅设置**：所有提示词默认9:16竖屏，如需其他画幅请在生图工具中单独调整。

4. **场景关联**：
   - 场景1（茶馆门口夜晚版）和场景2（茶馆门口黄昏版）是同一地点不同时段，门框结构保持一致
   - 场景3（客户门口）和场景4（墙边）是相邻场景，墙面材质和色调保持一致

5. **光线变化**：
   - 场景1：冷暖对比（月光vs灯光）
   - 场景2：全暖色调（夕阳）
   - 场景3：逆光压迫感
   - 场景4：冷暖转变（崩溃到温暖）
