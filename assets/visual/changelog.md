# 视觉资产 changelog

> 跨集状态变化集中归档。由服化道 agent 在追加变体素材时**同时维护**；导演审核 PASS 后由制片人做最终核对。
>
> 记录什么：
> - 同一人物的外观变化（换装、老化、受伤、伪装）
> - 同一道具的状态变化（完整 → 破损、新 → 旧、原始 → 改造）
> - 同一场景的状态变化（白天 → 夜晚、晴天 → 暴雨、完好 → 废墟、季节更替）
>
> 不记录什么：
> - 首次出现的新人物/新场景/新道具（在各 prompts.md 文件的 ep<N> 段记录就够）
> - 微小细节调整（比如同一造型换了同色系略不同的衣服）
>
> **记录格式**：每集一个三级标题，按集数降序排列（最新在最上）。

---

## 记录格式说明

```markdown
## ep<N>
- char-<id> <角色名>：<原状态> → <新状态>（变体编号：char-<id>-v<X>）
- prop-<id> <道具名>：<原状态> → <新状态>（变体编号：prop-<id>-v<X>）
- scene-<id> <场景名>：<原状态> → <新状态>（变体编号：scene-<id>-v<X>）
```

变体编号规则：
- 母图（首次设计）：`char-001`、`prop-001`、`scene-001`
- 第一次变体：`char-001-v2`
- 第二次变体：`char-001-v3`
- 变体素材的提示词仍写入各 prompts.md 文件，本 changelog 只记"状态变化点"

---

## 示例记录（仅供参考，实际项目使用时清空）

```markdown
- 初始建档（首次出场的人物/场景/道具见各 prompts.md 的 ## ep01 段，本 changelog 仅在 ep02+ 出现变体时开始记录）
```
