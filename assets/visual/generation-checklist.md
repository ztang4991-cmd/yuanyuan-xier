## 六、质量检查标准

生成完成后，检查以下项目：

### 视觉风格一致性
- [ ] 色调符合"二维新国风治愈系"（竹青色/暖木色主调）
- [ ] 描边柔和，不过艳
- [ ] 与已有人物设计图风格匹配

### 场景准确性
- [ ] 空间布局与导演要求一致
- [ ] 光线方向和色温正确
- [ ] 关键道具位置合理

### 跨集一致性
- [ ] 同一场景的不同时段版本（白天/夜晚/黄昏）空间布局一致
- [ ] 道具在不同脚本中的外观一致
