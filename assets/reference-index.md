## 【全片视觉风格基准段】（单一真相源，所有提示词的开头嵌入这段）

> 来源：`assets/story/creative-brief.md` 第三节，在此处保留副本便于引用。

```
[全片视觉风格基准]
画风：二维新国风治愈系动画，柔和描边，温暖明亮，介于写实和Q版之间的平衡（角色可爱但不过度幼稚，场景精致但不炫技）
调色板：竹青色（#7FB069）+ 云白色（#F4F4F2）主色，温暖木色（#D4A574）+ 柔和天蓝（#A7C7E7）辅色，喜儿羽毛蓝黑渐变（#2C3E50 → #3498DB）强调色；温暖场景偏暖光，冲突场景偏冷光，色温对比不超过 300K
质感：柔和手绘质感，边缘有轻微颗粒感（模拟水彩晕染），不要过于锐利的数字线条，保持手绘温度，光晕柔和自然
光逻辑：主光源自然光为主（窗外柔和日光、云层透光），人工光为辅（茶馆灯笼）；侧光+顶光混合营造立体感但不制造硬阴影；低对比度（阴影用环境光填充，不出现纯黑）；整体偏暖 4500-5500K，冲突场景略偏冷但不低于 4000K
```

## 使用规则

1. **新增素材时**：先在对应段落加一行，填好编号和文件名，再通知服化道/音乐总监去生成
2. **引用时**：用文件名（如 `character-林书白.png`），不用编号@符号——V10 用文件名写清单，比@编号更直观
3. **状态说明**：🟢 已生成 / 🟡 生成中 / ⚪ 待生成 / ❌ 生成失败需重试
