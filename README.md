# 凯凯 · AI 影视制作团队 v6.1

> 一个由 5 个 AI agent 协作的影视制作系统：编剧 / 导演 / 服化道 / 音乐总监 / 分镜师。
> 从一个想法或一份剧本出发，自动产出三套**工业级、可直接复制粘贴**的提示词：
>
> - 🎬 **分镜提示词** → Seedance 2.0 / 可灵 / Runway 生成视频
> - 🎨 **视觉提示词** → Nano Banana Pro / 即梦 生成参考图
> - 🎵 **音乐提示词** → Suno 生成音乐
>
> **核心差异化能力**：本系统不只追求"获奖短片"思维，更追求**流量目的**——内置 7 大短视频平台规律对照（抖音/快手/小红书/视频号/B站/YouTube/TikTok）+ 受众参与度审视，让每一份产出都为"被看到"服务。

```
       ↓

       ↓

       ↓
你去对应 AI 工具生成 → 剪辑成片 → 在目标平台被看到
```

## 创作底层逻辑：九原则

本系统所有 5 个 agent 共享 9 条创作底线（详见 `CLAUDE.md` [创作九原则]）：

1. **开头抓人** —— 前 3 秒决定划走
2. **丝滑过渡（设计层）** —— 用呼应描述制造连贯感，不靠 AI 帧粘合
3. **马上交代** —— 每秒都在和"划走"赛跑
4. **超绝创意** —— 一句话能讲清的高概念钩子
5. **一发入魂 OST** —— 一首打中人的歌能让作品多活 10 年
6. **克制的表达** —— 潜台词冰山，少即是多
7. **细节即灵魂** —— 90% 高级感来自被认真对待的细节
8. **反流水线** —— 拒绝套路化，每个镜头都有存在的理由
9. **为流量服务** —— 艺术性 + 平台规则 = 被看到

## 我是小白，从哪里开始？

### 第一步：选你的工具

本项目原生支持 **Claude Code**，但同时兼容下面几款常见的 AI 编程/对话工具。任选其一即可：

| 你用的工具 | 你需要做的 |
|------------|-----------|
| **Claude Code** | 直接打开本项目目录就行——所有配置自动加载 |
| **Codex / Codex CLI** | 工具会自动读 `AGENTS.md`，里面会指引它去读 `CLAUDE.md` |
| **Cursor** | 工具会自动读 `.cursor/rules/main.mdc`，同样指向 `CLAUDE.md` |
| **Windsurf** | 工具会自动读 `.windsurf/rules/main.md`，同样指向 `CLAUDE.md` |

**核心原理**：所有真实配置都在 `CLAUDE.md` 和 `.claude/` 目录里。其他三个文件只是"翻译入口"，让不同工具都能找到这套配置。**所以你不需要为不同工具维护多份配置——只改 `.claude/` 一处就够。**

### 第二步：开始用

详见 **[`USAGE.md`](./USAGE.md)** —— 这是给你（用户）看的完整操作手册，包括：

- 三分钟快速开始（路径 A：从选题创作 / 路径 B：从剧本开始）
- 提示词怎么用（拿到清单后的标准工作流）
- 介入模式怎么选
- 常用指令速查（`~write` / `~start` / `~status` / `~help` / `~mode`）
- 多集项目的复用机制
- 故障排除

## 给开发者/技术好奇者

### 项目架构

- **5 个 agent**：编剧（bianju）/ 导演（director）/ 服化道（art-designer）/ 音乐总监（music-director）/ 分镜师（storyboard-artist）
- **9 个 skill**：每个 agent 至少有一个执行 skill；导演还兼任 4 个审核 skill；4 个审核 skill 共享 `_shared/review-methodology.md` 中的方法论
- **5 阶段流程**：编剧 → 导演分析 → 服化道设计 → 音乐设计 → 分镜编写
- **两步审核**：每个阶段产出后由导演做"业务审核"+"合规审核"两轮把关
- **Resumable Subagents**：跨阶段时上下文连续，不丢状态

### 分层加载（progressive disclosure）

参考 Anthropic skill-creator 的设计哲学：

- **L1 元数据**（始终在上下文）：每个 skill 的 `name + description`（约 100 字）
- **L2 主体方法论**（按需加载）：每个 SKILL.md 主体（< 500 行）
- **L3 扩展资源**（深度需求时加载）：`templates/` / `examples/` / `references/`

这样 AI 在大多数任务中只加载它真正需要的部分，避免上下文爆炸。

### 单一真相源

- 主控逻辑：`CLAUDE.md`
- 用户文档：`USAGE.md`
- 跨工具入口：`AGENTS.md` / `.cursor/rules/main.mdc` / `.windsurf/rules/main.md`（这三个只是"指针"，**不要在里面写实质内容**）

如果跨平台入口文件和 `CLAUDE.md` 冲突，**以 `CLAUDE.md` 为准**。

## 哲学（如果你好奇为什么这套 AI 团队产出比别家高级）

> - **少即是多**：能用静默说的不用音乐说，能用一个镜头说的不用三个
> - **细节即灵魂**：90% 的高级感来自被认真对待的细节
> - **反流水线**：拒绝套路化处理，每一个镜头都要有存在的理由
> - **情绪优先**：技术服务于情感，不为炫技而炫技
> - **整体感**：从第一帧到最后一帧，每一秒都属于同一个作品的呼吸

如果某次产出让你觉得"还行"但不"惊艳"——回头看是不是这五条没做到。
