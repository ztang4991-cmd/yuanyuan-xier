## 一、导演讲戏本

### P01 极强钩子（0-2s）| 这就是你的求婚戒指

**剧情内容**：
特写：一枚竹叶编成的戒指，放在茶馆木桌上。简陋但精致，每片竹叶都细心修整过。团团画外音兴奋大喊："这就是你的求婚戒指？！"镜头缓缓拉开，露出缘缘紧张的表情和对面喜儿愣住的脸。字幕：`竹叶编的戒指，你会答应吗？`

**导演阐述**：
开场用"物"建立悬念。戒指特写要拍出"简陋但精致"的质感：竹叶是新鲜的翠绿色，编织得很细密，每片叶子的纹理清晰可见，边缘修剪得整齐。它放在木桌的中央，周围是茶馆的温暖光线。

团团的画外音要突然、兴奋、带着不可置信，"这就是你的求婚戒指？！"要重读"这"和"求婚戒指"，形成强烈的质疑感。

镜头拉开时，要捕捉两个人的反应：缘缘坐在桌子一侧，身体前倾，耳朵压平（紧张），爪子放在膝盖上握紧；喜儿坐在对面，愣住的表情——眼睛盯着戒指，嘴巴微微张开，翅膀僵住。

**镜头设计**：
戒指特写（1秒） → 缓慢拉开到双人中景（1秒），捕捉两人反应。

**光影氛围**：
茶馆黄昏光线，柔和竹青色调，戒指在光下有微微反光。

**台词/声音**：
- 团团（O.S.，兴奋大喊）："这就是你的求婚戒指？！"（重读"这"和"求婚戒指"）
- 音效：轻微的竹叶摩擦声

**情绪关键词**：悬念、质疑、紧张、愣住

**音乐方向**：无BGM，只保留环境音，突出悬念感

**建议形态**：单镜 | 理由：从物到人的推镜一气呵成，单镜保持悬念建立的完整性

**上承**：无（开场第一剧情点）

**下启**：戒指的视觉延续，团团的质疑引发冲突

### P02 冲突核心（2-7s）| 连九十九块都不到

**剧情内容**：
喜儿拿起戒指端详，表情复杂。团团在一旁小声嘀咕："喜儿姐姐，这个……连九十九块都不到吧？"喜儿放下戒指，看向缘缘，语气平静但眼神有期待："所以你觉得，心意到了就行？"缘缘低头，耳朵微微发红，紧张地搓着手。

**导演阐述**：
这是冲突建立段落。喜儿拿起戒指的动作要轻，她翻看戒指的每个角度，表情从好奇变成复杂——眉头微微皱起，嘴角抿紧，眼神里有失落但在克制。

团团的小声嘀咕要有"故意让人听见"的感觉——声音不大但清晰，"连九十九块都不到吧"要说得慢，"九十九块"要重读。他的小身板和大实话形成反差萌。

喜儿放下戒指的动作要轻但有"距离感"——不是扔，而是轻轻放回桌上，然后收回手。她看向缘缘时，眼神有期待（希望听到解释），但语气平静，"心意到了就行"是反问，重读"心意"和"就行"。

缘缘的反应要有"社恐被戳穿"的尴尬——低头，耳朵发红（这是熊猫害羞的标志），双手在膝盖上搓来搓去。

**镜头设计**：
喜儿拿起戒指特写 → 团团嘀咕侧面 → 喜儿放下戒指+看缘缘中景 → 缘缘尴尬特写。

**光影氛围**：
茶馆内光线，戒指在喜儿手中被翻看时有不同角度的反光。

**台词/声音**：
- 团团（小声但清晰）："喜儿姐姐，这个……连九十九块都不到吧？"（重读"九十九块"）
- 喜儿："所以你觉得，心意到了就行？"（语气：平静但有期待，反问）
- 音效：戒指被拿起的轻微声音 + 缘缘搓手的布料摩擦声

**情绪关键词**：复杂、尴尬、期待、质疑

**音乐方向**：无BGM，保持对话的真实感

**建议形态**：故事板 | 理由：多个视角切换（喜儿看戒指+团团嘀咕+缘缘反应），需要控制节奏和情绪递进

**上承**：戒指的视觉延续，团团的质疑升级

**下启**：喜儿的反问引出她的立场

### P03 观点A（7-13s）| 不是别人替我决定

**剧情内容**：
喜儿站起身，翅膀轻轻展开（情绪外化）。"贵不贵，不是别人替我决定的。我要的仪式感，也不等于我拜金。"缘缘仍低着头，声音很轻："我以为……手工做的更有意义。"

**导演阐述**：
这是喜儿立场表达——既不是无条件接受，也不是拒绝。她站起来的动作要有"需要表达"的感觉，翅膀展开是情绪外化：不是愤怒，而是"我需要说清楚"。

她说"贵不贵，不是别人替我决定的"时，要看向团团（不是责备，而是澄清）。说"我要的仪式感，也不等于我拜金"时，转向缘缘，眼神坚定。这两句话要分开说，中间有短暂停顿，让每句话都有重量。

缘缘仍然低头，声音很轻说"我以为……手工做的更有意义"，"我以为"要说得很慢，带着自我怀疑。这句话说完后他更低头了，耳朵完全压平。

**镜头设计**：
喜儿站起中景（翅膀展开）→ 喜儿看团团+看缘缘的眼神切换 → 缘缘低头特写。

**光影氛围**：
喜儿站起时逆光，翅膀的轮廓清晰，缘缘在阴影中。

**台词/声音**：
- 喜儿："贵不贵，不是别人替我决定的。我要的仪式感，也不等于我拜金。"（语气：坚定，分两句说，有停顿）
- 缘缘："我以为……手工做的更有意义。"（语气：轻声、自我怀疑）
- 音效：喜儿翅膀展开的摩擦声 + 缘缘低头时的叹气声

**情绪关键词**：坚定、澄清、自我怀疑

**音乐方向**：轻柔BGM淡入（15%音量），舒缓但带着一点紧张

**建议形态**：单镜 | 理由：喜儿站起到缘缘低头的连贯情绪递进，单镜保持对话张力

**上承**：喜儿的反问升级为立场表达

**下启**：缘缘的自我怀疑被团团的揭秘打断

### P04 观点B+证据（13-20s）| 做坏了27个

**剧情内容**：
团团突然凑过来，捧起戒指，在光下展开。戒指展开成一圈竹节纹，每一节刻着细小的日期和小图案：第一节茶杯（第一次见面），第二节信封（第一次吵架），第三节快递箱（第一次并肩送快递）。团团小声但带心疼："他做坏了27个……每天晚上关门后，一个人在竹林里编。"喜儿愣住，手指轻轻抚过那些刻痕。

**导演阐述**：
这是情感反转段落——用细节打动人。团团凑过来的动作要突然但不唐突，他的小爪子捧起戒指时很郑重。戒指在光下展开的画面要有"魔法揭晓"的感觉——从一枚简单的戒指变成一圈故事。

戒指展开后的特写要清晰：每一节竹节上都有细小的刻痕，茶杯的图案、信封的图案、快递箱的图案要依次展示（各0.3秒特写），旁边有小字标注日期（模糊但能看出是手写）。

团团说"他做坏了27个"时，声音要小但清晰，带着心疼。"27个"要重读，让观众感受到这个数字的重量。说"每天晚上关门后，一个人在竹林里编"时，可以插入0.5秒的想象画面：缘缘独自在竹林里，月光下编戒指，旁边堆着失败的作品。

喜儿听到后愣住，手指抚过刻痕的动作要轻柔而小心，眼神从惊讶变成感动。

**镜头设计**：
团团捧起戒指中景 → 戒指展开特写（3个图案依次展示）→ 团团说话侧面 → 想象画面闪回0.5秒 → 喜儿抚摸特写。

**光影氛围**：
戒指在光下展开时有光晕效果，刻痕在侧光下显得立体。

**台词/声音**：
- 团团："他做坏了27个……每天晚上关门后，一个人在竹林里编。"（语气：小声、心疼，重读"27个"）
- 音效：戒指展开的竹子摩擦声 + 喜儿手指抚过刻痕的细微声音

**情绪关键词**：揭秘、感动、心疼

**音乐方向**：柔和的背景音乐渐入（40%音量），温暖的钢琴旋律

**建议形态**：故事板 | 理由：戒指展开+3个图案特写+想象闪回+喜儿反应，多镜头组合需要精确控制情感节奏

**上承**：缘缘的自我怀疑被团团的揭秘反转

**下启**：喜儿的感动引出更深层的问题

### P05 第二层反转（20-26s）| 你问过我吗

**剧情内容**：
喜儿没有立刻戴上戒指，而是轻轻放回桌上。温柔但认真："它很珍贵。但求婚之前，你问过我想不想结婚、喜欢什么戒指吗？"缘缘抬头，眼神里有恍然，慢慢地："没有……"他收回戒指，深吸一口气："那今天不是求婚，是需求调查。"喜儿笑出声，眼角有泪光："这句比情诗有用。"

**导演阐述**：
这是第二层反转——不是拒绝，而是指出"缺少沟通"的核心问题。喜儿放下戒指的动作要轻柔，她没有戴上（这个"没戴"很重要），而是放回桌上，这个动作要有"温柔的拒绝"的感觉。

她说话时表情温柔但认真，"它很珍贵"要说得真诚，但"但"之后语气转为严肃。"你问过我想不想结婚、喜欢什么戒指吗"要一口气说完，是两个问题的叠加，重读"问过我"。

缘缘抬头时眼神要有"恍然大悟"的感觉——眉头舒展，黑眼圈下的眼睛睁大。他说"没有"时声音很轻，带着愧疚。

缘缘收回戒指的动作要慢，深吸一口气后说"那今天不是求婚，是需求调查"，这句话要有"成长"的感觉——他理解了问题所在。"需求调查"四个字要说得清晰，有一点自嘲。

喜儿笑出声的反应要自然——先是愣一下，然后笑出来，眼角有泪光（被理解的感动）。

**镜头设计**：
喜儿放下戒指特写 → 双人对话中景 → 缘缘恍然表情特写 → 喜儿笑出声特写。

**光影氛围**：
光线逐渐变暖，从之前的紧张感转为温暖但不完全圆满的氛围。

**台词/声音**：
- 喜儿："它很珍贵。但求婚之前，你问过我想不想结婚、喜欢什么戒指吗？"（语气：温柔→认真，重读"问过我"）
- 缘缘："没有……那今天不是求婚，是需求调查。"（语气：愧疚→自嘲）
- 喜儿："这句比情诗有用。"（语气：笑出声，感动）
- 音效：戒指放回桌上的轻响 + 缘缘深吸气声 + 喜儿笑声

**情绪关键词**：温柔的拒绝、恍然、成长、被理解

**音乐方向**：BGM升至60%，温暖有力的钢琴+弦乐

**建议形态**：故事板 | 理由：情感层次复杂（放下戒指+对话+恍然+笑），需要多镜头精确捕捉情绪变化

**上承**：从感动的心意到指出沟通缺失

**下启**：成长认知引出开放式结尾

### P06 开放式收尾（26-30s）| 并肩看设计册

**剧情内容**：
桌上并排放着：左边手工竹叶戒指，右边一本打开的珠宝设计册（喜儿从快递包里掏出的）。两人并肩坐着，一起翻看设计册。团团在后面偷笑。画外音调皮："所以下次是'需求调查2.0'吗？"画面定格在两人的背影。字幕浮现：`求婚戒指的价值，应该由价格、心意，还是双方共识决定？`

**导演阐述**：
这是温暖开放式结尾——不是完美求婚，而是"开始学会沟通"。桌上两个物品并列的构图要清晰：左边是手工竹叶戒指（心意），右边是珠宝设计册（沟通），两者并存，不是替代关系。

喜儿从快递包掏出设计册的动作要自然——她一直背着包，这时打开包拿出册子，翻开放在桌上。两人并肩坐着看册子的画面要有"平等"的感觉——肩膀靠在一起，一起指着册子上的图案讨论（无声，只看动作）。

团团在后面偷笑的画面要可爱——他躲在柱子后面，露出半张脸，眼睛弯成月牙。他的画外音"所以下次是'需求调查2.0'吗"要调皮，带着祝福。

画面定格在两人的背影：缘缘的黑白色+喜儿的蓝黑色，桌上的戒指和册子，团团的偷笑剪影，形成温馨画面。字幕从下方浮现。

**镜头设计**：
桌上两物并列俯拍 → 两人并肩看册子背影 → 团团偷笑剪影 → 定格背影+字幕。

**光影氛围**：
茶馆黄昏光线，柔和温暖，有"新开始"的希望感。

**台词/声音**：
- 团团（O.S.，调皮）："所以下次是'需求调查2.0'吗？"
- 音效：册子翻页声 + 两人低声讨论的模糊人声 + 团团轻笑声

**情绪关键词**：温暖、开放、平等、新开始

**音乐方向**：BGM保持60%音量，温暖收尾，最后2秒淡出

**建议形态**：单镜 | 理由：背影定格需要单一视角保持诗意感和完整性

**上承**：从"需求调查"的认知到实际行动

**下启**：无（收尾剧情点，留给观众讨论）

## 六、剧本医生反馈

**✅ 结构完整性**：开场悬念强，冲突双层（物质 vs 心意 → 心意 vs 沟通），反转自然（团团揭秘 → 喜儿指出沟通缺失），成长合理（缘缘"需求调查"），开放式结尾温暖。

**✅ 戏剧动作完整性**：
- P01-P03：冲突建立（戒指质疑 → 喜儿立场）
- P04：第一层反转（心意的细节）
- P05-P06：第二层反转+成长（指出沟通缺失 → 开始实践）
