| 优化项 | 要求 | 检查状态 |
|--------|------|---------|
| **视角高度标注** | 明确标注"low angle Xcm from ground" | ✓ 所有Cut已标注 |
| **画面边缘元素** | 只选爪子/鼻尖其一，避免同时要求多个 | ✓ 每个Cut只有1-2个元素 |
| **晃动幅度修饰** | 用"subtle"修饰，避免"剧烈"过度 | ✓ 已用"subtle shake"等 |
| **失焦描述** | 用"gradually defocus"而非"blur" | ✓ 已用"gradually defocus" |
| **身体部位虚焦** | 统一标注"虚焦模糊（out of focus）" | ✓ 所有边缘元素已标注 |
