## 一、导演讲戏本

### P01 极强钩子（0-2s）| 你态度能不能好点

**剧情内容**：
喜儿站在一户人家门口，快递包破损，她低头道歉，声音有些疲惫。客户提高音量："你态度能不能好点？笑一个啊！"喜儿愣住，翅膀僵住。字幕：`服务业就该永远微笑？`

**导演阐述**：
开场要有"疲惫被要求微笑"的荒诞感。喜儿站在门口，身体微微前倾（道歉姿态），她的高马尾有些凌乱，快递制服上有汗渍和灰尘。手里的快递包明显破损——纸箱一角压扁，胶带松开。

她说"对不起"时声音疲惫，没有往日的活力，语气是平的、机械的，像说了一百遍。客户的"你态度能不能好点？笑一个啊！"要突然、刺耳，重读"态度"和"笑一个"。

喜儿听到这句话时愣住——表情从道歉的疲惫变成难以置信，眼睛睁大，嘴巴微张，翅膀从自然下垂突然僵住（这是喜鹊受惊的反应）。这个"愣住"要拍清楚，给0.5秒让观众感受她的震惊。

**镜头设计**：
喜儿道歉中景 → 破损快递包特写 → 客户说话特写 → 喜儿愣住表情特写（翅膀僵住）。

**光影氛围**：
门口自然光，客户在门内逆光显得更有压迫感，喜儿在门外光线中。

**台词/声音**：
- 喜儿："对不起，快递在路上可能被挤压了……"（语气：疲惫、平淡、机械）
- 客户："你态度能不能好点？笑一个啊！"（语气：突然提高音量、理所当然，重读"态度"和"笑一个"）
- 音效：破损纸箱的沙沙声 + 喜儿翅膀僵住的羽毛摩擦声

**情绪关键词**：疲惫、荒诞、震惊、愣住

**音乐方向**：无BGM，只有环境音，突出对话的荒诞感

**建议形态**：故事板 | 理由：多个特写（道歉+破损包+客户+喜儿愣住）共同建立"荒诞被要求"的冲击

**上承**：无（开场第一剧情点）

**下启**：喜儿的愣住延续，她被迫微笑

### P02 冲突核心（2-12s）| 被迫的微笑 + 崩溃蒙太奇

**剧情内容**：
喜儿深吸一口气，嘴角扯出一个僵硬的笑容，翅膀紧贴身体（压抑）。客户关门后，喜儿转身，笑容瞬间消失，靠在墙上捂住脸。快速蒙太奇闪过今天的委屈：凌晨5点被催单（"怎么还没到？"），中午被骂（"送得这么慢！"），下午被投诉（"态度不好"），傍晚被要求"笑一个"。屏幕上浮现："凌晨5点：被催单"、"中午12点：被骂"、"下午3点：被投诉"、"傍晚6点：被要求微笑"。最后定格在喜儿捂脸的画面。

**导演阐述**：
这是情绪压抑到爆发边缘的段落。喜儿深吸气的动作要明显——胸口起伏，翅膀微微张开再紧贴身体。她扯出的笑容要"僵硬得可怕"——嘴角上扬但眼睛是空的，脸颊肌肉紧绷，这不是笑而是面具。

客户关门的"砰"声要清脆，像是压垮骆驼的最后一根稻草。喜儿转身后，笑容瞬间消失，这个转换要在1秒内完成——从僵硬笑容到面无表情到捂脸崩溃，表情变化要快而真实。

她靠墙的动作要有"撑不住"的感觉——背靠墙慢慢滑下，双手捂脸，高马尾垂落，翅膀完全收紧。

蒙太奇要快速密集（每个画面1.5秒）：
- 凌晨5点：喜儿在黑暗中看手机，屏幕亮着"怎么还没到？"，她的脸疲惫
- 中午12点：客户对着她大喊"送得这么慢"，她低头道歉
- 下午3点：手机屏幕显示"投诉：态度不好"，她愣住
- 傍晚6点：就是P01的"笑一个啊"

每个画面出现时，屏幕左上角浮现时间+事件白色字幕。蒙太奇结束后回到现在，定格在喜儿捂脸的画面1秒。

**镜头设计**：
喜儿深吸气+僵笑特写 → 客户关门 → 喜儿转身笑容消失 → 靠墙滑下+捂脸 → 蒙太奇4个画面（各1.5秒）→ 回到捂脸定格。

**光影氛围**：
客户关门后光线变暗，喜儿进入阴影区，蒙太奇中每个时段光线不同。

**台词/声音**：
- 蒙太奇中客户们的声音（O.S.）："怎么还没到？" "送得这么慢！" "态度不好" "笑一个啊！"
- 音效：深吸气声 + 门"砰"关上 + 背靠墙滑下的摩擦声 + 捂脸时的压抑呼吸声

**情绪关键词**：压抑、僵硬、崩溃边缘、委屈

**音乐方向**：无BGM，蒙太奇用音效节奏制造压迫感

**建议形态**：故事板 | 理由：僵笑+转身+蒙太奇4画面+回到现在，多镜头组合需要精确控制情绪累积

**上承**：喜儿被要求微笑

**下启**：喜儿的崩溃被缘缘发现

### P03 援军介入（12-18s）| 她也会累也会痛

**剧情内容**：
缘缘路过，看到捂脸的喜儿，停下脚步。他没有立刻说话，而是默默站在旁边，递过一杯竹叶茶。喜儿抬头，眼眶红了，声音哽咽："我是不是不适合做快递员？连笑都笑不好……"缘缘温柔但坚定："谁规定快递员必须一直笑？你不是机器人，你也会累、也会痛。"

**导演阐述**：
这是"被看见"的温暖段落。缘缘路过时脚步声要轻，他看到喜儿的瞬间停住，表情从平静变成心疼。他没有立刻说话（这个"沉默"很重要），而是默默走到喜儿旁边，在她身边坐下或蹲下（和她同一高度，不是俯视），递茶。

递茶的动作要温柔——茶杯慢慢递到喜儿视线范围内，不是突然出现。喜儿抬头看到缘缘时，眼眶是红的但没有流泪，她的声音哽咽，"我是不是不适合做快递员？连笑都笑不好"这句话要说得很慢，"笑不好"三个字带着自嘲和崩溃。

缘缘的回应要分两部分说：第一句"谁规定快递员必须一直笑？"是反问，语气温柔但带力量；第二句"你不是机器人，你也会累、也会痛"要看着喜儿的眼睛说，重读"也会累、也会痛"。

**镜头设计**：
缘缘路过停住中景 → 递茶特写 → 喜儿抬头眼眶红特写 → 双人同高度中景 → 缘缘说话时眼神特写。

**光影氛围**：
缘缘出现时带来一束光（茶馆方向的暖光），喜儿逐渐从阴影走向光亮。

**台词/声音**：
- 喜儿："我是不是不适合做快递员？连笑都笑不好……"（语气：哽咽、自嘲、崩溃）
- 缘缘："谁规定快递员必须一直笑？你不是机器人，你也会累、也会痛。"（语气：温柔但坚定，重读"也会累、也会痛"）
- 音效：缘缘脚步声轻轻停住 + 茶杯瓷器碰撞声 + 喜儿哽咽的呼吸声

**情绪关键词**：被看见、温暖、释然

**音乐方向**：舒缓BGM淡入（缘缘主题，竹笛音色，25%音量）

**建议形态**：单镜 | 理由：缘缘走来到双人对话的连贯场景，单镜保持温暖氛围的完整性

**上承**：喜儿的崩溃被缘缘看见

**下启**：缘缘的理念引发喜儿的反思

### P04 双方观点碰撞（18-25s）| 情绪稳定不是义务是能力

**剧情内容**：
喜儿接过茶，喝了一口，慢慢平静下来。她擦掉眼角的泪，声音依然带着鼻音但坚定了一些："可客户说我态度不好……"缘缘："情绪稳定不是你的义务，是你的能力。而能力会疲劳。"喜儿看着茶杯，若有所思："所以……我可以不笑？"缘缘温柔地笑："你可以不笑。但如果你想笑，那应该是因为快乐，而不是因为害怕。"

**导演阐述**：
这是观念转变的段落。喜儿接茶喝茶的动作要有"获得力量"的感觉——双手捧茶杯，喝一口，热气在脸上散开，表情从崩溃逐渐平静。她擦眼角泪水的动作要轻，用手背擦，留下一道水痕。

她说"可客户说我态度不好"时，声音还带着鼻音（刚哭过），但语气比之前坚定了一点——她在尝试理解缘缘的话。

缘缘的金句"情绪稳定不是你的义务,是你的能力。而能力会疲劳"要分三部分说：前两句对比"义务"和"能力"，第三句"而能力会疲劳"是关键，重读"会疲劳"。

喜儿看着茶杯若有所思的表情要拍出来——眼神从迷茫变成恍然，她轻声问"所以……我可以不笑？"这个问题是试探性的，像个孩子在确认。

缘缘的回答要温柔，他自己先笑了（这个笑是真诚的温柔笑容），然后说"你可以不笑。但如果你想笑，那应该是因为快乐，而不是因为害怕。"对比"因为快乐"和"因为害怕"。

**镜头设计**：
喜儿接茶喝茶特写 → 擦泪特写 → 双人对话中景 → 喜儿若有所思看茶杯 → 缘缘温柔笑特写。

**光影氛围**：
茶杯的热气在光线中可见,光线逐渐变暖。

**台词/声音**：
- 喜儿："可客户说我态度不好……所以……我可以不笑？"（语气：带鼻音→若有所思→试探）
- 缘缘："情绪稳定不是你的义务，是你的能力。而能力会疲劳。你可以不笑。但如果你想笑，那应该是因为快乐，而不是因为害怕。"（语气：温柔但坚定，对比"义务/能力" "快乐/害怕"）
- 音效：喝茶声 + 擦泪的轻微声音 + 茶杯热气的细微声音

**情绪关键词**：平静、恍然、被允许

**音乐方向**：BGM音量提升至40%，温暖的钢琴加入

**建议形态**：单镜 | 理由：喝茶到对话的连贯情绪递进，单镜保持对话的亲密感

**上承**：缘缘的理念输入

**下启**：喜儿的恍然引出行动转变

### P05 快速反转（25-28s）| 真实的笑容

**剧情内容**：
喜儿站起来，拍拍身上的灰尘，翅膀重新展开（恢复活力）。她看向镜头（打破第四堵墙），这次的笑容是真实的、松弛的："以后如果你看到快递员没笑，别急着投诉——可能她只是需要一分钟不当'微笑机器'。"

**导演阐述**：
这是喜儿的觉醒和力量恢复段落。她站起来的动作要有"重新振作"的感觉——先深吸一口气，然后站起，动作比之前有力。拍灰尘的动作要干脆，翅膀从紧贴身体到重新展开，这个展开要拍出"重获自由"的感觉。

她看向镜头（直视观众）是打破第四堵墙的设计——之前的镜头都是"被观察"，这里是"主动发声"。她的笑容要和P02的僵硬笑容形成对比：
- P02的笑：嘴角上扬但眼睛是空的，脸颊肌肉紧绷
- P05的笑：嘴角自然上扬，眼睛也在笑（眼角弯起），脸部肌肉松弛

她说话时语气平静但有力量，"以后如果你看到快递员没笑，别急着投诉"要对着镜头说，"可能她只是需要一分钟不当'微笑机器'"要重读"一分钟"和"微笑机器"。

**镜头设计**：
喜儿站起中景 → 拍灰尘+翅膀展开特写 → 正面看向镜头特写（真实笑容）。

**光影氛围**：
光线完全变暖，喜儿站在光亮中，阴影消失。

**台词/声音**：
- 喜儿："以后如果你看到快递员没笑，别急着投诉——可能她只是需要一分钟不当'微笑机器'。"（语气：平静但有力，直视镜头）
  - **⚠ 执行方式（2026-08-31 修订，见 feedback #1）**：此台词共 31 字，正常口播需 4.2-4.5s，放不进 3.0s 画面。采用**画面句中切 + 后期整句配音跨镜**：画面只生成到"别急着投诉——"（约 2.1s 开口），完整台词作为独立配音轨铺在 25.0s→29.4s，后半句在 P06 分屏画面上说完。台词一字不改，总时长仍为 30.0s。
- 音效：站起声 + 拍灰尘声 + 翅膀展开的羽毛声

**情绪关键词**：觉醒、真实、有力量

**音乐方向**：M04 主旋律进入，有力而温暖。**音量 50%（2026-08-31 修订，见 feedback #2）**——本剧情点有台词，60% 会盖住"可能她只是需要一分钟不当'微笑机器'"这句全片论点落点。执行：25.0s 起 50%，29.4s 她说完最后一个字后允许瞬时涌到 60% 约 0.3s 作为情绪顶点，随即在 P06 内快速淡出至 0%。

**建议形态**：单镜 | 理由：站起到看向镜头的连贯动作，单镜保持力量感的完整性

**上承**：从平静对话到行动恢复

**下启**：真实笑容引出开放式问题

### P06 开放式收尾（28-30s）| 两个笑容对比

**剧情内容**：
屏幕分屏：**上半屏**是P02的僵硬笑容（黑白），**下半屏**是P05的真实笑容（彩色）。字幕叠加：`被要求的微笑和自愿的微笑，你分得清吗？`

> **⚠ 分屏方向已改为上下（2026-08-31 修订，见 feedback #3）**：原设计为左右分屏，但本项目画幅是 9:16 竖版（1080×1920），左右分屏后每半屏仅 540px 宽，两张竖构图特写被压进窄条，脸部尺寸减半，手机竖屏观看时看不清"眼角有没有弯起"——而这正是真笑假笑唯一无法伪造的分界。改为上下分屏后每半屏 1080×960，脸部可用宽度翻倍，且不必裁掉肩部与翅膀顶端（翅膀"紧贴 vs 展开"是第二重对比线索）。语义上"上=被压着的过去 / 下=落地的现在"同样成立，字幕压在最下方不遮脸。**全片统一执行上下分屏。**

**导演阐述**：
这是纯视觉对比收尾——用分屏让观众直观感受两种笑容的区别。上半屏P02的僵硬笑容要处理成黑白（象征压抑），下半屏P05的真实笑容是彩色（象征自由）。

两个笑容上下并置，让观众自己对比：
- 上半屏：嘴角上扬但眼睛空洞，脸颊肌肉紧绷，黑白色调冷
- 下半屏：嘴角自然上扬且眼睛也在笑，脸部松弛，彩色温暖

两张图必须**同一角度、同一构图、同一景别、同一面部占比，唯一变量是表情与光温**——变量一旦不单一，对比就不成立，前 28 秒的铺垫全部作废。

字幕从画面下方缓缓浮现，不遮挡笑容。最后 0.6 秒完全无音乐，只有轻微的风声，留给观众思考空间。

**镜头设计**：
上下分屏对比（上黑白P02/下彩色P05）→ 字幕浮现。**本剧情点 100% 后期剪辑合成，不送 AI 生成**（分屏布局 + 中文字幕 + 去色三件事 AI 都做不对，且重新生成会破坏"单一变量"）。

**光影氛围**：
上半屏冷色黑白（保留原图平光的面具感），下半屏暖色彩色（保留左侧中低角度暖光的立体感），视觉对比强烈。

**台词/声音**：
- 画面内无人开口。29.4s 前继续的是 P05 那句台词的后半句"可能她只是需要一分钟，不当'微笑机器'。"（后期配音轨跨镜，见 P05 修订说明），29.4s 后完全静默
- 音效：轻微风声（<8%）+ 远处茶馆环境底噪 + BGM在前1.0秒内快速淡出至0%

**情绪关键词**：对比、留白、引发思考

**音乐方向**：M04 从 P05 尾部的情绪顶点（约60%）在本剧情点前1.0秒内快速淡出至0%，最后0.6秒完全静默（只剩风声与茶馆环境底噪）。**注**：音乐总监分配表原写"环境音（彩虹+风声）"，其中"彩虹"为跨集串行笔误（本集无彩虹场景），已订正为"风声+茶馆环境底噪"

**建议形态**：单镜 | 理由：分屏对比的视觉设计，单镜保持对比的完整性和冲击力

**上承**：真实笑容引出对比反思

**下启**：无（收尾剧情点，留给观众讨论）
