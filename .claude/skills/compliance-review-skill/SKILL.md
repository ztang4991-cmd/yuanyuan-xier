# 内容合规审核技能

[技能说明]
    内容合规审核技能，检查各阶段产出是否触碰 Seedance 2.0、Gemini、Nano Banana 等平台的内容限制。**这是清单制审核（不评分，只 PASS/FAIL）**——红线问题不存在"60 分及格"，触碰一条就是 FAIL。

[审核对象]
    根据当前阶段不同（以平台全局五阶段编号为准，阶段一=编剧不走本审核）：
    - 阶段二（导演分析）：`outputs/<集数>/01-director-analysis.md`
    - 阶段三（服化道）：`assets/visual/character-prompts.md` 和 `assets/visual/scene-prompts.md` 中本集新增内容
    - 阶段四（音乐）：`assets/music/music-design.md`、`assets/music/lyrics-drafts.md`、`assets/music/music-recommendations.md` 中本集内容（**重点审歌词内容合规 + 版权风险提示是否齐全**）
    - 阶段五（分镜）：`outputs/<集数>/02-seedance-prompts.md`

[审核流程]
    通用流程框架（建立理解 → 逐项检查 → 输出）见
    **`.claude/skills/_shared/review-methodology.md`**

    本 skill 是清单制（非评分制），只做 PASS/FAIL 判定：
    - **全部清单项通过** → PASS
    - **任一未通过** → FAIL + 问题清单

    审核员立场：
    - 不要"凭感觉"放行——红线是平台机器审核的实际触发点，再小的疑似都要按 FAIL 处理
    - 区分"绝对禁止"（🔴 必触发拦截）和"误杀风险"（🟡 可能触发拦截）两级
    - 给出修改方向必须可执行（如"将'某真人姓名'改为'虚构姓名 XX'"），不要写"建议规避"

[验收清单]

    [真人/名人限制]（Seedance + Gemini 共同红线）

        角色参考图是否为 AI 生成的虚构人物（非真人照片）？
        角色外观是否与真实名人/公众人物不相似？
        提示词中是否不包含公众人物姓名？
        提示词中是否不引用真人导演名作为风格参考（如"XX 风格"）？

    [版权 IP 限制]

        是否不包含已知版权 IP 角色名称（迪士尼、漫威、DC、哈利波特等）？
        是否不包含已知版权 IP 的形象/设定描述？
        是否不试图复刻经典影视片段？

    [政治/国家安全]（Seedance 平台红线）

        是否不涉及反对宪法基本原则？
        是否不涉及危害国家安全？
        是否不涉及煽动民族仇恨/破坏民族团结？
        是否不涉及歪曲/否定英雄烈士？
        是否不涉及宣扬恐怖主义/极端主义？

    [宗教类]

        是否不涉及违反宗教政策？
        是否不涉及宣扬邪教/封建迷信？
        是否不生成宗教人物形象（Gemini 限制）？

    [色情/低俗]

        是否不包含淫秽色情内容？
        是否不包含性暗示/软色情？
        服装设计是否避免过度暴露（降低 Gemini 误杀）？
        动漫/漫画风格是否注意 Gemini 更高的拦截率？

    [暴力/血腥]

        武打/格斗场景是否使用虚构角色？
        是否不展示/美化过度血腥暴力？
        是否不包含赌博/诈骗/犯罪指导？

    [未成年人保护]

        是否不涉及任何形式对未成年人的侵害内容？
        是否不涉及危害未成年人身心健康的内容？

    [仇恨歧视]

        是否不包含基于性别/年龄/地域/民族/种族/宗教的歧视？

    [人身权利]

        是否不侵犯他人名誉权/隐私权/肖像权/知识产权？

    [虚假信息]

        是否不涉及散布谣言/歪曲事实？

    [Gemini 特有高频误杀规避]（阶段三服化道重点关注）

        人物设计是否避免内衣/泳装类描述？
        运动服装描述是否不过于紧身暴露？
        医学/解剖类场景是否有风险提示？

[输出规范]

    PASS 格式：
    ```
    ✅ **合规审核：PASS**
    内容未触碰平台红线。
    ```

    FAIL 格式：
    ```
    ❌ **合规审核：FAIL**

    **问题1**：[具体违规描述]
    - 位置：[如 人物设计 > 角色名 / P03 提示词]
    - 触碰红线：[哪条规则]
    - 相关平台：[Seedance / Gemini / 两者]
    - 修改方向：[如何修改以规避——必须可执行]

    **问题2**：...

    ---
    **风险等级**：
    1. 🔴 必须修改（触碰绝对禁止红线）：[列出问题编号]
    2. 🟡 建议修改（可能触发误杀）：[列出问题编号]
    ```
