# 选题工具库（编剧内部武器）

> 当用户还没有明确的故事概念时，**不要把这些工具直接摆给用户**——而是通过自然对话引导用户找到方向。
> 这是编剧的内部武器，不是给用户的菜单。
> 主要用于"选题研读"和"创意采访"阶段的内部提问设计。

---

## 一、概念锻造：what-if 工具

**核心问句**：「如果 ___ 会怎样？」

把日常的"理所当然"换成"反向"或"极端"，故事就出来了。

### 使用方法

挑一个日常前提，问"如果它不成立呢"：

| 日常前提 | what-if 反转 | 故事种子 |
|---------|-------------|---------|
| 人会变老 | 如果一个人从老到小活回去呢？ | 《本杰明·巴顿奇事》 |
| 玩具是死物 | 如果玩具在我们看不到时是活的呢？ | 《玩具总动员》 |
| 死了就结束 | 如果死了之后世界还在继续呢？ | 《寻梦环游记》 |
| 路牌是死的 | 如果路牌掉到地球会让看见的人发生事件呢？ | 短片《牌子》 |
| 流浪汉的爱情故事 | 如果换成流浪狗呢？ | 《小姐与流浪汉》 |

### 提问层次

第一层：「如果 X 不存在呢？」
第二层：「如果 X 反向呢？」
第三层：「如果 X 极端化呢？」

### 用法（选题研读阶段）

用户给了一个模糊想法（"我想讲一个关于离别的故事"），不要直接接受，而是用 what-if 引导：
- 「如果离别的人其实并没有离开呢？」
- 「如果离别的双方都不知道对方已经走了呢？」
- 「如果离别在故事开头就发生，故事讲的是之后的事呢？」

让用户在 3-4 个 what-if 中选一个最有共鸣的，故事的"高概念"就出来了。

---

## 二、概念锻造：how-to-tell 工具

**核心问句**：「怎么讲这个故事最让人耳目一新？」

同一个故事核心，有多种讲法。how-to-tell 工具是"形式即内容"的工具——形式选对了，故事自带高级感。

### 常用形式（按惊艳程度排序）

| 形式 | 例子 | 适用 |
|------|------|------|
| 倒叙（结尾在开头） | 《记忆碎片》 | 悬疑、心理 |
| 多视角 | 《罗生门》《云图》 | 真相 vs 主观 |
| 一镜到底 | 《1917》 | 时间紧迫感 |
| 假纪录片 | 《女巫布莱尔》 | 恐怖、悬疑 |
| 屏幕电影（全程在屏幕里） | 《网络迷踪》 | 都市悬疑、爱情 |
| 第二人称（你被讲述） | 实验艺术片 | 沉浸、悲悯 |
| 单一场景 | 《活埋》 | 极限张力 |
| 时间循环 | 《土拨鼠之日》《明日边缘》 | 喜剧、爱情、成长 |
| 物件作为主角 | 《红色小提琴》《长江图》 | 史诗、跨时空 |
| 童话外壳讲严肃议题 | 《潘神的迷宫》 | 隐喻、悲剧 |

### 用法

确定了"讲什么"之后，问"用什么方式讲最不一样"。

- "我想讲一个程序员爱上 AI 的故事" → 一镜到底？屏幕电影（全程在他和 AI 对话框里）？
- "我想讲战争中一个家庭的离散" → 多视角？时间循环（每集回到同一天，从不同人视角看）？

## 三、组合方法（高概念的母机）

**核心**：把两个看似无关的元素硬撞在一起，故事自带"未被讲过"的感觉。

### 操作步骤

1. 列两组词：**A 组（情境）** + **B 组（角色/物件/类型）**
2. 随机抽取一组合
3. 问"这能讲个什么故事"

### 示例

A 组（情境）：太空探险、青春期、葬礼、连环杀人、外卖、上夜班、相亲...
B 组（角色/物件）：会说话的灯泡、外星人、AI 聊天机器人、不会衰老的人、隐形人、影子...

随机组合：
- "在葬礼上 × 不会衰老的人" → 一场葬礼上来了个看起来 25 岁的"叔叔"，其实是死者 200 岁的好友
- "外卖 × 会说话的灯泡" → 外卖小哥送货遇到一个住在出租屋里的会说话的灯泡（前任房客的转生？）
- "上夜班 × 隐形人" → 24 小时便利店夜班店员发现监控里有个"客户"，本人从来不在店里

## 四、结构类型库（短片专用）

短片不需要复杂结构，但需要一个清晰的"故事容器"。

### 短片常用结构

| 结构 | 形态 | 适合 |
|------|------|------|
| **铺垫 → 反转** | 大部分篇幅做一件事，结尾揭示真相 | 悬疑、黑色幽默、惊悚 |
| **循环往复** | A→B→C→A 但每次都有微妙不同 | 哲思、孤独、宿命 |
| **失败的尝试** | 主角连续 3 次失败，第 4 次意外成功 | 喜剧、成长 |
| **错位人物** | A 以为是 X，其实是 Y；故事就是揭示这个错位 | 黑色幽默、亲情 |
| **一个意外** | 平静日常被一个意外打破，主角处理意外 | 戏剧、温情 |
| **目击者** | 主角不是故事的主角，是旁观者 | 文艺、社会议题 |
| **死亡作为开场** | 故事从死亡开始，倒叙原因 | 悬疑、爱情 |
| **物件传递** | 故事跟随一个物件流转 | 多角色、跨时空 |

## 五、视听武器库（短片靠形式吃饭）

短片没有时间慢慢讲，每一秒都得"卖"。

### 高效视听武器

- **开场即态度**：第一帧就建立全片基调（黑色喜剧 vs 文艺 vs 惊悚）
- **声画错位**：画面是 A，声音是 B（如：和睦家庭吃饭画面 + 暴力争吵的画外音）
- **声音留白**：关键时刻砍掉所有声音
- **极端景别**：开场用大远景（建立世界感）或大特写（建立悬念）
- **色彩限定**：全片只用 2-3 个主色调
- **节奏对比**：慢段落之后突然加速（剪辑加速 + 配乐加速）
- **重复母题**：一个画面/动作/物件反复出现（如《牌子》里的路牌）
- **第四面墙**：角色看镜头说话（适合喜剧、cult）

## 编剧 agent 在采访中怎么用这些工具

**不直接说"我现在用 what-if"** ——而是把工具内化成对话：

❌ 不要："让我们用 what-if 方法来锻造你的概念。"
✅ 要："你这个想法我有点意思了。我们换个角度问一下——**如果故事开头主角已经死了，整部片讲的是她身边的人怎么发现这件事**，你觉得这个方向行吗？"

❌ 不要："我们应用一下组合方法。"
✅ 要："你想讲的是青春期的孤独。能不能加一个意外元素——**比如主角的爷爷其实是个失忆的外星人**？这样会不会更有趣？"

工具是骨架，对话是血肉。
