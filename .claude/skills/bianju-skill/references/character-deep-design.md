# 深度角色方法论：Want / Need / Ghost / Lie / Flaw

> 在 SKILL.md 的 [第六节 子流程五：角色开发] 中提到的深度角色方法。
> 主要用于 **长片** 和 **多集剧集**——这两类格式需要"完整人物小传"。
> 短片/概念片可以简化甚至跳过本文。

---

## 一、Want（外在需求）

**定义**：角色**自己意识到**、**主动追求**的目标。

**特征**：
- 角色知道自己想要它
- 是行动的驱动力（戏剧动作的"目标"部分）
- 通常是具体的、可见的（升职、复仇、找回某人、赢得比赛）

**作用**：
- 提供情节推动力
- 给观众明确的"故事走向"

**示例**：
- 《肖申克的救赎》主角 Andy：洗清冤屈 / 越狱
- 《疯狂动物城》主角 Judy：成为一名优秀的警官
- 《让子弹飞》主角张麻子：在鹅城讨回公道

---

## 二、Need（内在欲望）

**定义**：角色**未曾意识到**的灵魂缺口，通常是 Want 的深层原因。

**特征**：
- 角色一开始不知道自己需要它
- 通常是抽象的、内在的（理解爱、原谅自己、接受失败、重新信任他人）
- 与 Want 表面上无关，深层上互为表里

**作用**：
- 提供"人物弧光"的目的地
- 让故事有"灵魂",不只是情节

**示例**：
- Andy 的 Need：保持希望和尊严（Want 是越狱，Need 是不被监狱毁掉灵魂）
- Judy 的 Need：接受偏见和复杂性（Want 是当好警官，Need 是放下"小镇女孩的天真"）
- 张麻子的 Need：理解"公道"无法仅靠暴力换回

---

## 三、Want vs Need 的张力 = 人物弧光的发动机

故事的张力来自：**Want 想要这个，Need 真正缺的是那个**。

**三种结局对应三种弧光**：

| 结局类型 | Want | Need | 含义 |
|---------|------|------|------|
| **成长弧光** | 放下或修正 | 得到 | 主角完成内在转变（最常见的"正面"故事） |
| **悲剧弧光** | 得到 | 失去 | 主角达成 Want 但失去 Need（如《社交网络》） |
| **反弧光** | 都失去 | 不变 | 主角拒绝 Need，固守原本的认知（如《华尔街之狼》） |

**应用**：
- 写设定时确定主角的 Want 和 Need
- 写大纲时确定结局是哪种弧光
- 写场景时让每一场戏都微妙地"推动" Want 但"考验" Need

---

## 四、Ghost（前史创伤）

**定义**：故事开始之前，角色经历过的、塑造了 TA 当前状态的关键事件。

**特征**：
- 通常是创伤性的（失去、背叛、失败、目睹）
- 不需要在剧本中明说，但编剧必须知道
- 它解释了"为什么这个角色现在是这个样子"

**示例**：
- Andy 在被冤入狱前是个银行家，妻子出轨后被杀，他被栽赃（Ghost = 失去妻子 + 被司法系统辜负）
- Judy 童年被狐狸欺负（Ghost = 童年的种族偏见根源）
- 蝙蝠侠的 Ghost = 童年目睹父母被杀

**用法**：
- Ghost 不需要全部展示——可以通过一个闪回、一句台词、一个反应来暗示
- 它的作用是让角色的行为**有根据**——观众感受到"TA 行动是有原因的"，即使不知道原因

## 五、Lie（角色相信的谎言）

**定义**：因为 Ghost，角色形成了一套"扭曲的认知" —— TA 相信的某个错误信念。

**特征**：
- 是 Ghost 的认知后果
- 是 Want 的隐藏动机
- 是 Need 的阻碍

**示例**：
- Andy 的 Lie：「我必须保持希望，但也只能靠自己」（其实他需要的是建立深层友谊，比如和 Red）
- Judy 的 Lie：「努力工作就能改变世界」（过于天真，没看到结构性问题）
- 张麻子的 Lie：「只要打倒坏人就能讨回公道」（其实公道在更复杂的人性里）

**用法**：
- 故事开始时，角色坚信 Lie
- 故事过程中，Lie 被一次次挑战
- 故事结尾时，角色要么放下 Lie（成长）要么固守 Lie（悲剧）

---

## 六、Flaw（性格缺陷）

**定义**：Lie 在性格层面的具体表现。

**特征**：
- 是 Lie 的行为后果
- 经常以角色的"优点的反面"出现（一个人的优点和缺点常常是一体两面）
- 在故事中需要被反复呈现

**常见 Flaw 类型**：

| 类型 | 表现 | 对应的优点（一体两面） |
|------|------|---------------------|
| 自负 | 看不起别人、不听劝 | 自信、有领导力 |
| 自卑 | 不敢追求、自我贬低 | 谦逊、共情力强 |
| 控制欲 | 干涉他人、不放手 | 责任感强、负责 |
| 逃避 | 遇事躲避、不正面冲突 | 温和、不强求 |
| 完美主义 | 苛责自己/他人、拖延 | 标准高、专业 |
| 不信任 | 难以建立深层关系 | 独立、判断力强 |
| 过度善良 | 容易被利用 | 同理心强、有人情味 |

**用法**：
- Flaw 是观众**看得见**的（不像 Lie 是认知层）
- 每场戏让 Flaw 制造小麻烦，到高潮让 Flaw 制造大麻烦
- 弧光的关键是"Flaw 在结尾被克服 / 仍未克服"

## 七、五要素的产出格式（编剧 agent 在角色开发阶段输出）

每个主要角色的档案应包含：

```markdown
## 角色档案：[角色名]

### 基本信息
- 年龄、性别、职业、外貌关键词

### 五要素

**Ghost**：[1-3 句描述前史创伤事件，可包含具体年代/地点/人物]

**Lie**：[一句话总结角色相信的错误信念]

**Flaw**：[1-2 个具体性格缺陷，每个 + 一句行为表现]

**Want**：[一句话总结角色追求的外在目标 + 这个目标的具体形态]

**Need**：[一句话总结角色真正缺失的内在需求]

### 弧光设计
- 起点（A 状态）：[故事开始时角色的精神状态]
- 终点（B 状态）：[故事结尾时角色的精神状态]
- 弧光类型：成长 / 悲剧 / 反弧光
- 关键转折点：[在故事的哪一幕发生从 A 到 B 的关键变化]
```

## 八、按格式缩放（再次强调）

| 格式 | 五要素应用 |
|------|----------|
| 概念超短片 | 跳过五要素，用 archetype（如"复仇者"、"求救者"、"自负的笨蛋"）即可 |
| 短片 | Want + Need + 简化的 Arc（不需要 Ghost/Lie/Flaw 全部展开） |
| 长片 | 完整五要素，每个主角都做档案 |
| 多集剧集 | 完整五要素 + **弧光预算**（设计每集推进百分之多少的弧光） |

---

## 九、弧光预算（剧集专用）

剧集的人物弧光不能一集完成，需要分配到各集。

**预算示例（一部 12 集的剧）**：

| 集数 | Want 的进展 | Need 的进展 | 主要弧光事件 |
|------|------------|------------|------------|
| 1-2 | 确立 Want | Need 暗藏未现 | 引入角色，建立 Lie/Flaw |
| 3-4 | Want 受阻第一次 | 隐隐感觉到不对 | Flaw 制造第一次大麻烦 |
| 5-6 | Want 进展看似顺利 | 与 Need 短暂相遇 | 一个深夜对话/一次失落 |
| 7-8 | Want 大反转 | Lie 被首次挑战 | 失败、暴露、被识破 |
| 9-10 | 选择 Want 还是 Need | 觉醒的边缘 | 关键的"诱惑"或"试探" |
| 11 | 危机 | 最终选择 | 拐点：放下 Lie / 固守 Lie |
| 12 | Want 失去/达成 | Need 得到/失去 | 弧光收束，主题揭示 |

预算让编剧每集都"知道这一集要走多远"，避免某一集弧光跳得太快、某一集又原地踏步。
