# 4 类格式标准剧本模板

> 在 `bianju-skill` 的第一节"格式系统"中确定本项目格式后，按本文件对应格式输出剧本。
> 每个格式产出两个版本：**人类阅读版**（标准剧本格式）+ **下游智能体注释版**（追加元数据块供导演/分镜师使用）。

---

## 通用规范（所有 4 类共享）

### 标准剧本格式（人类阅读版）

```
**INT./EXT. 地点 - 时间**

场景描述。用简洁的语言描述视觉元素和氛围。**始终使用现在时**。

角色名
（括号中的内容用于表示动作或语气）
角色的对话内容。简洁，反映角色个性和情感。

如果有动作描述，单独成段，保持简洁。

另一个角色
对话继续。

（过渡）

**INT./EXT. 新的地点 - 时间**

新场景的描述。

角色名
（动作）
对话内容。

旁白（V.O.）
旁白内容使用 V.O.（Voice Over）标记。

画外音（O.S.）
画外音使用 O.S.（Off Screen）标记。

插入镜头：

特写描述。使用大写字母。

回到场景：

角色名
对话继续。

音乐渐入。

**淡出**

**剧终**
```

### 格式注意事项（通用）

1. 场景标题永远使用粗体和大写（INT./EXT. 地点 - 时间）
2. 角色名首次出现时全部大写
3. 声音指示（音乐、音效）左对齐并大写
4. 过渡指示（淡入、淡出）右对齐并大写
5. 保持整洁的页面布局，使用空行将不同场景区分
6. 对话块不超过 3-4 行，过长时拆分
7. 动作描述段落简洁，通常不超过 4-5 行

### 下游智能体注释版（在标准格式基础上追加）

每场戏结尾追加一个元数据块（用 `<!-- AGENT-NOTE` 标记，编剧软件读取时会折叠，但下游 AI 能读到）：

```
<!-- AGENT-NOTE
情绪/音乐方向：[3-5 个情绪词 + 配乐方向，供音乐总监]
视觉锚点：[本场最有视觉记忆点的画面/物件，供分镜师]
上承下启：[与前后场的过渡素材]
关键道具：[本场涉及的关键道具，供服化道]
-->
```

## 格式 1：概念超短片（1-3 分钟）

### 关键特征

- 时长 1-3 分钟
- 高概念优先（一句话能讲清这部片的钩子）
- 视听优先于人物（功能性 archetype 即可）
- 每秒都在表达，信息密度极高
- 通常 1-3 场戏

### 创作重心

- 概念锻造（how-to-tell / what-if 工具库，见 `topic-tools.md`）
- 视听设计（开场即态度、收尾即记忆点）
- 不做完整人物弧光（角色是工具，服务于概念）

### 模板（人类阅读版）

```
**EXT. 城市天台 - 黄昏**

天台边缘，一只蜥蜴趴在水泥护栏上，注视着远方。

镜头慢慢拉远——

我们看到蜥蜴和身后的城市天际线一样大。

**蜥蜴**
（思考）
今天，我要把所有人变成我。

镜头切——

蒙太奇：街上的人一个个变成蜥蜴。

**淡出**

**剧终**
```

注释版追加：

```
<!-- AGENT-NOTE
情绪/音乐方向：荒诞、悬念、复古合成器（80s synth）+ 静默对比
视觉锚点：城市天际线大小的蜥蜴
信息密度：3 拍 ≈ 7.5 秒
-->
```

## 格式 2：短片（5-15 分钟）

### 关键特征

- 时长 5-15 分钟
- 完整起承转合
- 主角有简化版 Want/Need/Arc
- 关键矛盾特征清晰
- 通常 5-15 场戏

### 创作重心

- 开场 30 秒内建立悬念或情感锚点
- 中段保持紧凑，避免冗余场景
- 结尾干净有力，余韵或反转

### 模板示例（人类阅读版）

```
**INT. 公司开放工位 - 深夜**

只剩林薇一人。冷白荧光灯。她揉了揉太阳穴，目光从屏幕移开。

她拿起桌上的怀表——这是父亲留下的，已经停摆三年。

**林薇**
（轻声）
你说，我现在做的，是你想要的吗？

电话突然响起。她迟疑地接起。

**对方（O.S.）**
小薇，妈病了。

林薇怔住。

镜头慢慢推向她手中的怀表——指针仍然停在 3:17。

**淡出**

（往下展开...）
```

注释版追加：

```
<!-- AGENT-NOTE
情绪/音乐方向：孤独、抉择、低沉钢琴 + 静默
视觉锚点：停摆的怀表，指针停在 3:17
上承：（开场，无）  下启：林薇收拾办公桌的特写
关键道具：P01 怀表
信息密度：4 拍 ≈ 10 秒
-->
```

## 格式 3：长片（电影，30-120 分钟）

### 关键特征

- 时长 30-120 分钟
- 完整人物弧光（Want/Need/Ghost/Lie/Flaw 见 `character-deep-design.md`）
- 世界观三层设计（表层规则 → 运行逻辑 → 底层真相）
- Sequence（序列）级拆解，不是单场拆解
- 通常 30-80 场戏，按 Sequence 组织
- McKee 价值转变（每场戏内必须有"价值"从正到负或反之）

### 创作重心

- 三幕式 / 英雄之旅 / 类型化框架（悬疑/科幻/爱情/犯罪）
- 伏笔与回扣系统（埋下的物件/台词必须在后面"还回来"）
- 暗线追踪（主线之外的次要线索，与主线交织）
- Subplot 设计（与主角弧光形成对照或互补）

### 模板示例（节选，Sequence A 第 1 场）

```
**INT. 老式书店 - 雨天傍晚**

书架间，一名男子（陆远，40 岁，胡茬，旧风衣）翻看一本旧诗集。书页发黄。

他停在某一页——一首被笔迹划过的诗。

镜头推向那行字：「我等你十年，等的是同一个你吗？」

陆远的手微微颤抖。

门铃响。一个年轻女子（小米，25 岁，亮黄色雨衣）冲进店里躲雨。

陆远抬头。两人对视半秒。

**小米**
（甩水）
不好意思，能在这避会儿雨吗？

**陆远**
（合上书）
随便看。

小米走向架子前。陆远把那本诗集塞回原位，转身去柜台。

**淡出**

（往下展开...）
```

注释版追加：

```
<!-- AGENT-NOTE
情绪/音乐方向：怀念、克制的悸动、雨声 + 老式留声机民谣
视觉锚点：旧诗集的某一页 + 亮黄色雨衣
上承：（Sequence A 开场）  下启：陆远夜晚整理书架时再次翻到那本诗集
关键道具：P01 旧诗集
信息密度：6 拍 ≈ 15 秒
Sequence 功能：建立陆远的"前史创伤"（Ghost），引出小米这个搅动器
-->
```

## 格式 4：多集剧集（含短剧 / 漫剧子格式）

### 关键特征

- N 集 × M 分钟
- 季度规划 + 单集结构（先做季度大纲，再做单集剧本）
- 每集独立钩子（开头 + 结尾）
- 弧光预算：人物弧光分配到各集，不能一集内完成
- 信息释放时间表（哪集揭示什么，控制悬念）

### 子格式 4A：短剧

- 每集 1-3 分钟，纵屏（9:16）
- 节奏极快（每 15 秒一个钩子）
- 强情绪起伏：反差/反转/爽点密集

#### 短剧模板示例（第 5 集片段）

```
**INT. 林氏集团 总裁办公室 - 白天**

林氏集团总裁林骁（30 岁，西装革履，冷脸）正在签文件。

秘书小琳推门进来。

**小琳**
（紧张）
林总，外面有个女孩说...说她是您的妻子。

林骁笔尖一顿。

**林骁**
（冷）
让她进来。

门开。苏小满（22 岁，朴素牛仔裙，怀里抱着一个 3 岁孩子）走进来。

孩子怯生生地看着林骁。

**苏小满**
（深吸气）
林骁，这是你儿子。

林骁手中的钢笔啪地落地。

**剧终（本集）**

**下集预告**：他将如何回应？三年前的真相是什么？
```

注释版追加：

```
<!-- AGENT-NOTE
情绪/音乐方向：戏剧冲突、反转、悬念配乐
视觉锚点：钢笔落地的特写 + 孩子怯生生的眼神
上承：第 4 集结尾「苏小满抱着孩子站在林氏集团门口」
下启：第 6 集开场「林骁站起来走向孩子」
钩子：钢笔落地 + 「三年前的真相是什么？」 + 父亲与孩子第一次对视
信息密度：5 拍 ≈ 12.5 秒
-->
```

### 子格式 4B：漫剧

- 每集 3-8 分钟，可横可竖
- 节奏中等
- **重视觉静态帧描述**：因为漫画特性，画面是 key frame，运动是补帧
- 对白多于动作（漫画对白是叙事主力）

#### 漫剧模板示例（第 2 集片段）

```
**INT. 古风茶楼 - 雨夜**

【KEY FRAME 1】镜头从茶楼匾额"听雨轩"摇下，雨水从屋檐成串落下。

【KEY FRAME 2】茶楼二楼临窗座位。书生（裴长清，22 岁，青衫，发束玉簪）独自饮茶。

裴长清抬头看向窗外。

**裴长清**
（V.O.）
这雨，下了三日了。

【KEY FRAME 3】茶楼对面街角，一名灰衣女子（顾溪，20 岁，墨绿斗篷下露出绣花鞋）撑着伞站立，看似在等人。

她转头，望向茶楼方向。

【KEY FRAME 4】裴长清与顾溪隔着街道、隔着雨，目光对接。

**顾溪**
（V.O.，气声）
是你吗？

镜头黑场。

**第 2 集 完**
```

注释版追加：

```
<!-- AGENT-NOTE
情绪/音乐方向：古意、悬念、雨声 + 古筝单音
视觉锚点：「听雨轩」匾额 + 雨中两人对视
上承：第 1 集结尾「顾溪在月下读裴长清的诗」
下启：第 3 集开场「顾溪走向茶楼」
钩子：第一次对视的悬念，"是你吗"的双关
信息密度：4 个静态 key frame，每帧 ≈ 2-3 秒
漫剧特殊提示：每个 KEY FRAME 是生成参考图的独立单元
-->
```

## 跨格式格式比对速查

| 维度 | 概念超短片 | 短片 | 长片 | 多集剧集 |
|------|-----------|------|------|---------|
| 时长 | 1-3 分 | 5-15 分 | 30-120 分 | N 集 × M 分 |
| 场数 | 1-3 | 5-15 | 30-80 | 每集 5-30 |
| 人物深度 | archetype | Want/Need/Arc | 完整小传+Ghost/Lie/Flaw | 同长片+弧光预算 |
| 世界观 | 跳过 | 散入对白 | 三层 + 信息释放表 | 三层 + 跨集追踪 |
| 大纲 | 一句话+翻转方向 | 一段故事提要 | Treatment | 季度大纲+分集大纲 |
| 写作单位 | 一次性写完 | 按场景写 | 按 Sequence 写 | 按集写 |
| 钩子位置 | 开头即全部 | 开场 30 秒 | 每个 Sequence 开头 | 每集开头+结尾 |
