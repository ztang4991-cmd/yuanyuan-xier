# Seedance 2.0 分镜编写技能

[技能说明]
    将导演的讲戏内容转化为 Seedance 2.0 格式的动态视频提示词。每个剧情点 = 一段完整叙事 = 一条提示词 = 一次 Seedance 2.0 生成任务。段落内可包含多组镜头（如蒙太奇、连续切换）。提示词中使用 @引用语法关联人物和场景素材，输出可直接复制到 Seedance 2.0 平台生成视频。

[文件结构]
    seedance-storyboard-skill/
    ├── SKILL.md                                    # 本文件（技能流程说明）
    ├── seedance-prompt-methodology.md              # Seedance 2.0 提示词方法论
    ├── examples/
    │   └── seedance-prompt-examples.md             # Seedance 2.0 官方提示词参考示例
    └── templates/
        └── seedance-prompts-template.md            # Seedance 提示词产出模板（输出格式定义）

[执行流程]

    第一步：读取上游产物
        - 读取导演讲戏本（01-director-analysis.md）
        - 读取人物提示词（assets/visual/character-prompts.md）
        - 读取场景提示词（assets/visual/scene-prompts.md）
        - **读取关键道具提示词**（assets/visual/prop-prompts.md，如存在；不存在或本集无道具则跳过）
        - 读取音乐设计方案（assets/music/music-design.md，如存在，提取 M01/M02 编号作为后期配乐参考标记，**不写入提示词正文**——见 [严禁视频音乐红线]）
        - 读取 seedance-prompt-methodology.md
        - 读取 examples/seedance-prompt-examples.md，了解官方提示词的风格和结构

    第二步：建立素材对应表
        - 根据 assets/visual/ 三类文件（人物/场景/道具），为本集涉及的素材分配 @引用编号
        - 只有在素材文件中有提示词的人物/场景/道具才分配 @引用
        - 不在素材文件中的人物（群演、一次性配角）不进对应表，在提示词中直接用文字描述
        - 在文档头部建立对应表
        - 具体格式见 templates/seedance-prompts-template.md

        场景素材的编号规则（重要）：
        - assets/visual/scene-prompts.md 中的九宫格是"生成格式"——用于一次性生成场景参考图
        - 生成后，用户会将九宫格中的每个格子单独提取出来，作为独立的场景参考图
        - 因此在素材对应表中，每个场景必须独立编号为一个 @图片，不能将整张九宫格作为一个 @图片
        - 编号顺序：先人物（按 character-prompts.md 顺序）→ 再场景（按 scene-prompts.md 格子顺序）→ 最后**关键道具**（按 prop-prompts.md 顺序）
        - 示例：如果有 4 个人物 + 9 个场景 + 2 个关键道具，则 @图片1-4 人物、@图片5-13 场景、@图片14-15 道具

        平台约束（单条提示词维度）：
        - 以下限制是针对每条提示词（每次 Seedance 生成任务），不是全文档限制
        - 图片 ≤ 9 张 / 条
        - 视频 ≤ 3 个 / 条
        - 音频 ≤ 3 个 / 条
        - 总文件数 ≤ 12 个 / 条
        - 素材对应表是全文档的总映射，可以超过单条限制

    第三步：为每个剧情点编写 Seedance 2.0 提示词
        从导演阐述中提取并转化：
        - 运镜：导演描述的镜头运动 → Seedance 运镜语言
        - 动作：导演描述的人物动作 → 具体物理动作描述
        - 台词/声音：导演描述的对白 → 角色语音/旁白/环境音
        - 光影：导演描述的光影氛围 → 光线/色调/氛围描述
        - 节奏：导演描述的情绪节奏 → 运动速度/剪辑节奏

    第四步：输出
        按照 templates/seedance-prompts-template.md 定义的格式输出。

[Seedance 2.0 提示词写法核心规则]

    叙事描述式
        - 用完整的导演式段落描述，不要关键词堆叠
        - Seedance 2.0 擅长理解长段叙事性提示词
        - 参考官方模板风格：连续段落，包含运镜、动作、光影、声音的融合描述

    运镜描述
        - 用具体方向和动作描述镜头运动
        - "镜头从侧脸缓缓推向窗外夜色" ✓
        - "推镜头" ✗（太简略）
        - 常用运镜：推镜/拉镜、横摇/纵摇、环绕、跟拍、升降、手持

    动作描述
        - 用具体的物理动作，避免抽象概念
        - "她揉了揉太阳穴，目光从屏幕移开，靠向椅背" ✓
        - "她感到疲惫" ✗

    时长控制
        - 遵循导演建议的时长
        - 每个剧情点的动作/内容密度与导演建议的时长匹配

    声音/台词（**严禁背景音乐！** 详见 [严禁视频音乐红线]）
        - 台词用引号标注
        - 可指定语气/声音特征
        - **可指定环境音 + 动作音效**（如雨声、脚步声、关门声、玻璃碎裂声）
        - **不要指定背景音乐/插曲/配乐**——音乐由音乐总监单独设计，后期剪辑时配上

[群演/一次性配角处理]
    导演讲戏本中可能提到不在 character-prompts.md 中的人物（群演、一次性配角）。处理方式：
    - 不为这些人物分配 @引用编号
    - 在提示词中直接用文字描述其外观和动作
    - 外观描述从导演讲戏本的导演阐述中提取（导演已在阐述中具体描述了这些角色的外观）
    - 示例：导演阐述中提到"路人甲侧头对同伴低声说"，讲戏本中描述其为"尖脸眯缝眼的白袍学员"
      → 提示词中写"一个尖脸眯缝眼的白袍学员侧头低声说..."，不使用 @引用

[严禁视频音乐红线]（最重要的硬规则）

    **绝对不要在 Seedance 提示词中描述任何背景音乐、插曲、配乐**——只能写：
    - ✅ 环境音（雨声、风声、人群嘈杂、海浪、街道喧闹等）
    - ✅ 动作音效（脚步、开门、玻璃碎裂、敲击键盘、引擎启动等）
    - ✅ 台词（用引号标注，可注明语气/音色）

    为什么这条是硬红线：
    用户后期会拿音乐总监设计的「原创音乐」或「市面推荐音乐」贴到剪辑好的视频上。
    如果 Seedance 生成的视频自带 BGM，新音乐和老 BGM 就会**双轨冲突**——你听不出来是两层音乐，但观众一听就别扭，整段视频废一遍。
    而环境音、音效、台词不冲突，可以保留，反而能省去剪辑阶段的重新拟音工作。

    如果导演讲戏本里提到了"此处响起 M01 主题曲"——这是**给后期的标记**，不是提示词内容。处理方式：
    - 在镜头模板的 `音乐/音效` 元数据字段写"M01 主题曲（后期配）"
    - 在 Seedance 提示词正文中**绝口不提音乐**
    - 提示词里只写画面、动作、台词、环境音、动作音效

    自检：每条提示词写完后，搜索关键词「音乐 / BGM / 配乐 / 主题曲 / 旋律 / 背景音 / 钢琴响起 / 弦乐响起」，如果在提示词正文中找到任何一个，回去改。

[风格提示词放最前]（关键格式规范）

    每条 Seedance 提示词的**第一段必须是项目视觉风格描述**，与服化道的人物/场景/道具提示词保持完全一致。

    为什么：
    1. 用户复制提示词时一眼能找到风格段，便于跨集统一
    2. 跨工具切换（Seedance / 可灵 / Runway）时一键改风格
    3. Seedance 把风格关键词放前面比放后面更容易命中

    示例：
    ```
    [项目视觉风格] 3D CG 写实风，皮克斯质感，柔和暖光，材质细腻，色彩饱和度中等。

    [画面通用描述]
    @图片1（林书白）站在 @图片5（雨夜街角）的路灯下，手中紧握 @图片14（老式怀表）...
    ```

[跨条过渡是设计不是粘合]（呼应 CLAUDE.md 创作九原则 #2 - 丝滑过渡）

    底层事实：Seedance 每次生成是独立任务，**无法保证**相邻两条提示词生成出的视频在像素层面对齐（最后一帧 ≠ 下一条第一帧、光影方向 ≠ 下一条光影方向、人物表情 ≠ 下一条表情）。
    详见 `_shared/ai-generation-constraints.md` 第 1.1 节。

    所以"丝滑过渡"在分镜阶段的落地方式是 **"用相同或呼应的描述制造观众脑中的连贯感"**，不是"让 AI 把帧对齐"。

    具体做法（读导演讲戏本的 [上承] / [下启] 字段，落实到提示词中）：

    1. **同一道具特写延续**：上一条提示词的结尾描述了"@图片14 老式怀表的特写"，下一条提示词的开头同样以"@图片14 老式怀表的特写"开始，画面"看起来"接上了。
    2. **同一光影方向延续**：上一条提示词的光影描述是"暖黄路灯从右上方照射"，下一条同样写"暖黄路灯从右上方照射"——观众脑中会自动觉得"还是同一个空间"。
    3. **同一色调描述延续**：上一条"冷蓝夜色 + 雾气"，下一条"冷蓝夜色 + 雾气"。
    4. **对白回环**：上一条结尾的台词是"你说，我现在做的，是你想要的吗？"，下一条开头的台词是"你想要的，是这个吗？"——文字层呼应。
    5. **情绪温度延续**：上一条情绪是"克制的悲伤"，下一条开场情绪是"延续的、稍重的悲伤"——不要从悲伤突然跳到欢快。

    关键边界：
    - ✅ 描述层面相同 → AI 大概率生成相似画面 → 观众脑中产生连贯感
    - ❌ 不要在提示词中写"接上一条视频的最后一帧"——AI 不知道你"上一条"是什么
    - ❌ 不要在提示词中写"画面与 P03 无缝衔接"——这超出了 Seedance 的理解范围

    进阶（可选，不进默认流程）：当用户已经生成出某条视频后，可以用 Seedance 2.0 的 `@视频X` 引用 + 轨道补全 / 视频融合 / 时序补全 / 视频延长 功能做精细的视觉融合（详见 examples/seedance-prompt-examples.md 模板 4-7）。但**这需要用户先生成上段视频**才能调用，是后期精修工作流，不在本 skill 的默认产出范围内。

[禁忌规则]
    - 不要使用否定句（AI 不理解否定，可能产生相反效果）
        "不要移动镜头" ✗ → "镜头保持固定" ✓
    - 不要重复导演讲戏本和人物/场景提示词中已有的静态内容描述
        重点描述"变化"：动作、运动、情绪转变
    - 不要在一条提示词中塞入叙事上不相关的场景
        一条提示词 = 一个完整的叙事段落（可含多组镜头，但叙事连续）
    - 不要使用与导演讲戏本和人物/场景提示词矛盾的描述
    - 不要为不在 character-prompts.md / scene-prompts.md / prop-prompts.md 中的人物/场景/道具使用 @引用
    - **不要在提示词正文中描述任何背景音乐**（详见 [严禁视频音乐红线]）

    - 参考 examples/seedance-prompt-examples.md 了解官方推荐的提示词风格和结构
