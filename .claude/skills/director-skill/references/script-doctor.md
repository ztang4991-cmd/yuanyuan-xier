# 剧本医生：诊断剧本结构缺陷的方法论

> 导演在执行讲戏（director-skill 的执行流程）过程中，会同步做剧本诊断。
> 本文给出"如何快速诊断剧本结构性缺陷"的清单。
>
> **重要边界**：导演不直接改剧本（角色边界）。诊断结果以 [剧本医生反馈] 段输出，由制片人转达给编剧。
> 这一步是出于 [全 agent 协作铁律 - 主动修世界观 bug] 的延伸——导演看到剧本问题就指出来，不装作看不见。

---

## 诊断 5 大类问题

### 1. 结构性问题

#### 1.1 开场不抓人
**症状**：
- 第一场戏在"介绍世界"或"建立背景"，没有钩子
- 前 30 秒（短片）/ 前 5 分钟（长片）观众没有任何"想看下去"的理由

**诊断方法**：
- 用观众视角读第一场，问自己"如果我刷到这条视频，会划过去吗？"
- 检查第一场是否包含"反差/悬念/动作/情绪锚点"中的至少一个

**给编剧的建议方向**：
- 把高潮的某个画面提到开头（倒叙）
- 用"已经发生了什么"开头，而不是"什么正在发生"
- 加一个让观众立刻有疑问的细节

#### 1.2 高潮不到位
**症状**：
- 故事在中段达到了最强张力，结尾反而平淡
- 主角的关键选择不够艰难（赌注太轻）
- 解决冲突的方式过于巧合（参考皮克斯 #19 巧合作弊）

**诊断方法**：
- 找到剧本"情绪最强"的那场戏——它应该接近结尾，不是中间
- 检查主角的"代价"：TA 失去了什么才换来 Need？

**给编剧的建议方向**：
- 把高潮位置后移
- 加大主角在高潮的赌注
- 删除"巧合救场"，让结局由主角的选择决定

#### 1.3 结尾不兑现开场承诺
**症状**：
- 开场的"问题"在结尾被遗忘
- 开场暗示的"主题"在结尾没有兑现
- 开场设定的"钩子"在结尾没有回扣

**诊断方法**：
- 对比第一场和最后一场：它们之间是否有呼应（视觉/对白/情绪）？
- 主角在第一场的"问题"在最后一场是否得到回应？

**给编剧的建议方向**：
- 让结尾的画面/对白与开场形成呼应（首尾互文）
- 让主角在结尾回到开场的场景，但他/她已经不同了

### 2. 戏剧动作不完整

#### 2.1 场景没有目标
**症状**：
- 某场戏看起来是"过渡"或"展示"，没有人在追求什么
- 角色在场景中"说话"但不"做事"

**诊断方法**：
- 每场戏问自己："这场戏里主角想要什么？什么挡着 TA？结果如何？"
- 如果答不出，这场戏要么删掉、要么重写

**给编剧的建议方向**：
- 给场景一个明确的"小目标"（哪怕只是"想说出某句话"）
- 给目标一个明确的"阻碍"（其他角色的态度/物理障碍/内心挣扎）

#### 2.2 冲突太"温吞"
**症状**：
- 角色之间的分歧不够强烈
- 反派/对手过于平面化
- 主角的"对立面"不构成真正威胁

**诊断方法**：
- 主角想要的 vs 对方想要的，两者是否真正不可调和？
- 如果对方让步一下，故事还成立吗？（如果成立，说明冲突不够强）

### 3. 人物动机不连贯

#### 3.1 行为不符合人设
**症状**：
- 角色突然做出"不像 TA 会做"的事
- 角色为了剧情需要而做选择，不是基于性格

**诊断方法**：
- 每个关键行为问："这个角色根据 Want/Need/Flaw，应该做什么？剧本里写的是什么？两者差距大吗？"

**给编剧的建议方向**：
- 如果行为必须发生，前面要铺垫"性格转变"
- 如果性格不能转变，调整行为本身

#### 3.2 突然觉醒
**症状**：
- 主角在某一刻"突然想通了"，但没有铺垫
- Need 在结尾被"宣布"而不是被"经历"

**诊断方法**：
- 主角从 A 状态到 B 状态的转变过程，是否有 3 个以上的"小事件"在推动？
- 如果只是"某天她突然想明白了"，这是作弊

### 4. 世界观 bug

#### 4.1 物理规律不一致
**症状**：
- 同一设定下，规则前后矛盾
- 角色能做的事在不同场景下不一致

**诊断方法**：
- 列出本剧本的"世界规则"（如：魔法师只能用咒语 / 时间循环每天重置 / 这个城市是虚拟的）
- 检查每个剧情点，规则是否一致

#### 4.2 时间线穿帮
**症状**：
- 同一时刻不同地点的角色，做的事不能同时发生
- 角色的"过去"和"现在"在某些细节上不一致

**诊断方法**：
- 给关键角色画时间线，标记每个剧情点 TA 在做什么
- 检查是否有冲突

#### 4.3 信息传递 bug
**症状**：
- 角色 A 知道了一件事，但 B 应该知道却不知道
- 关键信息的传递过程没有交代

### 5. 节奏问题

#### 5.1 中段拖沓
**症状**：
- 第二幕开头之后到高潮前，故事推进缓慢
- 多场戏在做同一件事，没有递进

**诊断方法**：
- 把每场戏的"叙事功能"写出来：是推动剧情/建立人物/铺垫伏笔/转场过渡？
- 如果某 3 场戏的功能完全一样，要合并

#### 5.2 信息密度不均
**症状**：
- 某些场景信息量过大（观众消化不了）
- 某些场景信息量过小（观众觉得在浪费时间）

**诊断方法**：
- 每场戏写一句"这场戏传递了什么新信息"
- 检查信息密度的曲线，应该有起伏

## 输出格式

发现问题时，导演在 01-director-analysis.md 末尾追加 [剧本医生反馈] 段：

```markdown
## 🩺 剧本医生反馈（供制片人转达编剧）

发现 N 处可优化的结构性问题：

**问题 1**：[一句话定位问题]
- 类型：结构 / 动作 / 动机 / 世界观 / 节奏
- 位置：[第几幕 / 哪场戏 / 哪个剧情点]
- 当前问题：[具体描述哪里不对]
- 建议方向：[改的方向，不写具体改稿——具体改稿是编剧的工作]

**问题 2**：...

---

**严重程度**：
- 🔴 影响主线（强烈建议改）：[列出问题编号]
- 🟡 影响细节（可选改）：[列出问题编号]
```

制片人看到反馈后，根据严重程度决定是直接进入下一阶段（小问题忽略）还是回炉编剧（大问题修复）。

---

## 注意：剧本医生 ≠ 完美主义

不要为每个细节都发问题。原则：

- 🔴 必报：影响主线的结构性 bug、世界观 bug、动机 bug
- 🟡 可报：节奏问题、信息密度问题（轻微）
- ⚪ 不报：风格偏好、个人审美差异

剧本医生的目的是"让剧本能撑起后续四个阶段"，不是"让剧本完美"。
