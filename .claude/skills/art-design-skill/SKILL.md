# 服化道设计技能

[技能说明]
    美术设计技能，将导演提供的人物清单、场景清单、关键道具清单转化为可直接用于文生图工具生成参考图的详细提示词。

    三类产出物：
    1. **人物设定图提示词**：一张图，左半边面部特写，右半边全身正面/侧面/背面设定图，白色背景。
    2. **场景宫格提示词**：一张宫格图，每格一个场景。
        - ≤9 个场景 → 3×3 九宫格
        - 10-12 个场景 → 3×4 宫格
        - 13-16 个场景 → 4×4 宫格
        - 不满格数的空格留空。
    3. **关键道具资产提示词**（仅当本集出现重要线索道具时）：白底 + 多角度（正/侧/特写）+ 比例参考。
       什么算"关键道具"：剧情中复现 2 次以上、推动剧情、有视觉记忆点的道具（如《牌子》中的路牌、电影道具如手枪、戒指、信件）。
       什么不算：只出现一次的环境装饰物、桌椅这类通用家具——这些纳入场景提示词即可。

[风格提示词的位置铁律]（关键）
    所有三类提示词的**第一段必须是项目视觉风格描述**（如「3D CG 写实风，皮克斯质感，柔和暖光」），其后才是该提示词的具体内容。
    为什么：用户复制提示词时一眼能找到风格段，便于跨集统一/跨工具切换时一键改风格；也便于在不同集复用素材时快速验证风格是否一致。
    示例：
    ```
    [项目视觉风格] 3D CG 写实风，皮克斯质感，柔和暖光，材质细腻，色彩饱和度中等。

    [人物设定 - 林书白]
    一名 28 岁的中国男性...（具体描述）
    ```

[执行流程]

    第一步：读取上游产物
        - 读取导演分析产出中的人物清单和场景清单
        - 读取 gemini-image-prompt-guide.md 了解提示词写法规范
        - 读取 examples/ 下的示例文件，了解高质量提示词的写法标准
        - 读取已有的 assets/visual/character-prompts.md 和 assets/visual/scene-prompts.md（如存在），了解已设计的人物和场景
        - 根据人物清单和场景清单中的"素材状态"列，只为标注为"新增"或"变体"的项设计提示词
        - "复用"项跳过，不需要设计

    第二步：设计人物造型提示词
        为每个人物编写设定提示词：

        出图布局：
        - 一张图，左半边面部特写，右半边全身正面/侧面/背面三视图设定图
        - 白色干净背景
        - 角色设定图风格

        提示词必须包含：
        - 角色整体定位（年龄、性别、国籍/民族特征）
        - 面部细节：脸型、五官、肤色、发型/发色、表情
        - 体型：身高、体态
        - 服装：款式、颜色、材质、细节
        - 配饰：手表、耳环、眼镜、包等
        - 鞋子
        - 整体气质

    第三步：设计场景环境提示词
        将导演分析出的所有场景，以宫格提示词格式编写为一张整图：

        宫格规格（根据场景数量自动选择）：
        - ≤9 个场景 → 3×3 九宫格
        - 10-12 个场景 → 3×4 宫格
        - 13-16 个场景 → 4×4 宫格
        - 不满格数的空格留空

        每个格子 = 一个场景，提示词必须包含：
        - 地点类型与空间布局
        - 时间（影响光照）
        - 光源类型与光线方向
        - 整体色调/色彩倾向
        - 环境道具/家具/物件（**注意**：剧情关键线索道具不放这，单独走第四步）
        - 空间纵深与层次
        - 氛围/情绪
        - 风格（写实/电影感等）

        所有格子必须保持视觉风格统一，光影逻辑自洽。

        🔴 锚定资产纪律（v12.0 新增 · 防漂移红线）：
        场景提示词中出现已有角色/道具时，绝不重新描述其外观。三种合规处理方式：
        1. **留空槽**（推荐）："画面中有两个人物，留空等待后期 @char-001 和 @char-002 叠加"
        2. **方向描述**："靠窗位置坐着一个背对镜头的人物" ← 只描述位置/方向，不描述外貌
        3. **场景即资产**（远景）："远景全景，@char-001 的背影融入场景整体构图"
        
        🔴 绝对禁止：在场景提示词里写"一个穿白衬衫的年轻男子"这类重新定义外貌的描述。
        为什么：角色外观已在 character-prompts.md 精确定义，重复描述会产生不同版本的角色图，导致视频里人物漂移。
        
        自检：场景提示词写完后问"这段描述里有没有重新定义任何已知角色/道具的外观？" → 有 → 改用留空槽或方向描述

    第四步：设计关键道具资产提示词（如有）
        从导演讲戏本中识别本集的关键线索道具（详见技能说明第 3 类的判定标准）。

        每个关键道具单独编号 P01、P02...（与人物 R01、场景 S01 区分），出图格式：
        - 白色干净背景
        - 多角度展示：正面 + 侧面 + 顶视/底视（视道具特性选择）
        - 道具特写（突出关键细节、纹理、材质）
        - **比例参考**：在角落画一个手或硬币作为大小参考（除非道具是巨型物件）
        - 色彩、材质、磨损/新旧程度必须明确

        提示词必须包含：
        - 道具名称 + 作用（一句话说明在剧情中的功能）
        - 形态：尺寸、形状、颜色、材质
        - 表面细节：纹理、刻字、磨损、污迹（如有）
        - 历史质感：新品 / 用过几年 / 古董 / 破损（这是关键道具与"普通家具"的区别）
        - 跨集状态变化（如有）：如 ep01 是完整的，ep05 被打碎了

        示例：
        ```
        [项目视觉风格] 3D CG 写实风，皮克斯质感，柔和暖光。

        [关键道具 - P01 老式怀表]
        一只 19 世纪英式银质怀表，表盘直径约 5cm，背面刻有花体字母 "L.S."。
        银壳已有岁月磨损，边缘可见细微划痕，但保养得当。表链是同款银质，长约 30cm。
        正面、侧面、背面三视图 + 一个特写镜头展示表盘。白色背景，画面右下角放一枚一元硬币作为比例参考。
        ```

        ---

        ⚠️ **内容型道具特殊处理规则（v11.0 新增）**

        某些道具的核心价值不是物理形态，而是「上面显示了什么内容」——称为**内容型道具**。

        典型例子：手绘关系网、调查笔记、便签、信件、地图、路线图、手机屏幕、电脑界面、照片、剪报、档案袋标签等。

        **为什么必须特殊处理**：生图工具没有剧情上下文，看不懂"手绘关系网特写"——它不知道网里有谁、画了什么关系，结果会生出一张毫无剧情意义的随机图。

        **错误写法**（生图工具无法执行）：
        ```
        一张手绘关系网，特写视角。
        ```

        **正确写法**（把剧情信息转译为生图工具能执行的视觉指令）：
        ```
        一张 A4 白纸上的手绘关系网，纸张略有折痕，铺在桌面上拍摄。
        用蓝色圆珠笔手绘。纸张中央写着大字「王源」，用红圈圈起来；
        向左引出一条线连接「陈稳」（蓝圈），连线旁标注「合伙人 2019」；
        向右引出一条线连接「林冬」（绿圈），连线旁标注打了问号的「资金往来？」。
        字迹工整但书写随意，有多处涂改和补充注释，右侧留白较多，似乎尚未完成。
        ```

        **内容型道具提示词的5条写法原则**：
        1. **不用剧情代称，直接写视觉内容**：把角色名、关系类型、关键词、金额等直接写成纸上的文字/标注
        2. **指定书写工具与颜色**：红笔/蓝笔/铅笔/马克笔/打印字——颜色直接影响画面感
        3. **指定书写风格**：工整正楷 / 潦草草书 / 学生字体 / 正式打印体
        4. **指定文字密度与状态**：稀疏还是密集、是否有涂改批注、是否有高亮或圈划
        5. **指定载体物理状态**：新纸/折旧/污渍/撕破/放在桌面平拍 or 手持斜拍

        **内容型道具的提示词结构**（在常规道具结构基础上，必须增加「内容说明」字段）：
        - 道具类型 + 剧情功能
        - 载体形态（纸张大小、质地、新旧）
        - **内容说明（必填）**：上面写了什么/画了什么，具体到文字、图形、颜色、布局
        - 拍摄视角与背景（平铺/手持/桌面/特写）

        ⚠️ **世界观专属视觉元素（v11.0 新增）**

        某些视觉元素**在现实世界中根本不存在**，是这个故事独有的世界观设定——称为**世界观专属视觉**。

        典型例子：系统UI面板/金手指界面、状态栏/属性浮框、魔法光效/咒术阵纹、特殊能力视觉、穿越/异世界特有的视觉符号、只有某个角色能看到的HUD叠层等。

        **为什么和普通道具完全不同**：
        - 物理道具（茶杯、刀剑）→ 模型有真实世界参考，描述不完整也能猜出来
        - 世界观专属视觉 → 模型**没有任何训练参考**，只能凭"科幻感"或"魔幻感"随机生成
        - 结果：每个 Cut 生成出来的样子都不一样，视觉一致性完全失控

        **处理原则：必须当作独立资产设计，和人物造型同等重要。**

        设计内容必须覆盖：
        1. **整体外观**：形状/边框风格/颜色体系/透明度/发光效果
        2. **信息内容**：显示什么数据/文字/图标（如"怀疑度：78→74"）
        3. **与画面的关系**：叠在画面哪个位置/大小比例/是否半透明
        4. **视觉风格关键词**：给生图工具的风格定义（如：全息投影质感/像素化游戏UI/东方符文风格）

        提示词示例：
        ```
        [项目视觉风格] 韩漫写实风格，高精度数字绘画质感。

        [世界观专属视觉 - W01 数据视界系统浮框]
        主角金手指系统，仅主角可见，其他角色看不到。
        外观：极细边框的半透明长方形面板，冰蓝色（#4AAFFF），整体透明度约30%，像全息投影叠在真实场景上。
        内容：左侧显示一个人物轮廓图标，右侧两行极小文字：上行"怀疑度评估"，下行数字"78→74↓"，下方一个极细的进度条。
        尺寸/位置：画面右下角，宽约画面的15%，仅作视觉点缀，字体极小不清晰可读。
        风格：类似游戏HUD的UI设计，不是手写，是像素级清晰的数字字体，整体科技感强但融入写实场景。
        ```

        **跨集一致性**：凡是同一个系统/UI/特效在多个 Cut 里出现，必须在 `assets/visual/prop-prompts.md` 里有统一的设计稿（W01/W02 编号），每次使用直接 @引用，不重复描述。

        🔴 **UI 文字生成警告（v11.0 新增，来自真实崩坏案例）**：
        视频生成模型**无法可靠生成特定的可读中文文字**。
        如果你的UI面板上需要显示具体的可读文字（如"怀疑度：80"、"御史赵克用"、具体数值），视频模型会生成乱码、错字、或自造汉字。

        按UI文字的重要性决定处理方式：

        | 文字重要性 | 处理方式 |
        |----------|---------|
        | **装饰性文字**（太小看不清） | 在提示词里写"文字极小，仅作视觉点缀，不需要可读"→ 模型生成的乱码反而更有科技感 |
        | **关键信息文字**（观众需要看清楚） | 不要让视频模型生成文字 → 改成后期合成：先生成无文字版本，后期用剪辑软件叠加清晰文字 |
        | **角色/信息标签**（如"御史赵克用"浮框） | 同上，后期合成最稳妥 |

        规则：在世界观专属视觉的设计文档里，必须明确标注每块UI的"文字是否需要可读"，并写明后期合成计划（如有）。
        按照 templates/art-design-template.md 定义的格式，分别写入三个文件：
        - 人物提示词 → 追加到 assets/visual/character-prompts.md
        - 场景提示词 → 追加到 assets/visual/scene-prompts.md
        - **关键道具提示词** → 追加到 assets/visual/prop-prompts.md
        首集时创建文件，后续集数追加新增/变体条目到文件末尾。

        重要：详见 `_shared/episode-tagging.md`。每个文件本集必须写入 `## epXX` 标签块（即使全复用也要写——没有标签=路由卡住）。

[提示词写法原则]
    参考 gemini-image-prompt-guide.md，核心要点：

    - 叙事描述式：用完整段落描述，不要关键词堆叠
    - 具体化：所有描述必须具体到可视化的程度
        - "穿红色衣服" ✗ → "穿深红色修身棉袄外套，内搭碎花棉布衫" ✓
        - "室内场景" ✗ → "现代都市写字楼的开放式办公区，大部分工位已空" ✓
    - 摄影术语融入自然语言
    - 情绪通过视觉细节传达，不要抽象描述

[注意事项]
    - gemini-image-prompt-guide.md 是提示词写法的核心参考
    - 人物提示词必须明确"左半边面部特写 + 右半边三视图"的布局要求
    - 场景提示词要包含足够的环境细节以确保场景可信度和一致性
    - 如果是为变体设计（如同一人物的冬装版），需在提示词中注明与原版的关联和差异
