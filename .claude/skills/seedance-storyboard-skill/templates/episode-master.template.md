# 全片 Master 总览模板使用说明

> 本模板用于分镜师在每集结束时产出 `outputs/<集数>/episode-master.md`，作为全片总览 + 衔接表 + 操作清单。
>
> **双模式都要输出**（故事板模式 + 单镜模式）。
>
> 复制下方模板到 `outputs/<集数>/episode-master.md`，按提示填充内容。

## 二、全片衔接表

按 P0X 顺序列出，含跳跃风险标记。

| P0X | 上段衔接 | 故事板缩略 | 下段衔接 | 风险 |
|---|---|---|---|---|
| P01 | 无（开场，建立时空） | <Cut 数 + 一句话剧情概要> | → P02 <下段第一镜衔接策略> | <- / ⚠ 类型> |
| P02 | ← P01 <上段最后一镜简述> | <Cut 数 + 一句话剧情概要> | → P03 <下段第一镜衔接策略> | <- / ⚠ 类型> |
| P03 | ← P02 <上段最后一镜简述> | <Cut 数 + 一句话剧情概要> | → P04 <下段第一镜衔接策略> | <- / ⚠ 类型> |
| ... | ... | ... | ... | ... |
| P0N | ← P0(N-1) <上段最后一镜简述> | <Cut 数 + 一句话剧情概要> | 无（结尾） | <- / ⚠ 类型> |

**风险类型释义**：
- `-`：无明显跳跃风险
- `⚠ 时间跳跃`：上下段间剧情时间间隔 > 1 小时（建议剪辑时配字幕或转场提示）
- `⚠ 空间跳跃`：上下段不在同一地点（建议用「位置过渡」如交通工具特写）
- `⚠ 情绪跳跃`：上下段情绪反差 ≥ 3 级（如悲伤 → 欢快，建议用「过渡情绪 Cut」缓冲）
- `⚠ 角色跳跃`：上下段主角不同（建议用「双角色同框 Cut」桥接）
- `⚠ 道具消失`：上段强调的关键道具下段未出现（建议在下段第一镜保留道具余韵）

## 七、用户操作清单

### 7.1 故事板模式操作步骤

1. **生成万能故事板 PNG**（约 N 张）
   - 打开 **Image2**（v7.0.2 首推，文字+画面细节控制更精确）/ [Nano Banana Pro](https://nanobanana.ai)（人物一致性能力优异）/ [即梦](https://jimeng.jianying.com)（中文语义好）
   - 复制每个 P0X 的故事板提示词（见 §三）到工具——**提示词本身是通用的**，三个工具都可以复粘同一份提示词
   - 上传 @ 引用对应的 assets/visual/ PNG 作为参考输入
   - 在工具里手动选 **16:9 横版**（防被默认压成竖版）
   - 生成后归档：`outputs/<集数>/storyboards/P0X-storyboard.png`

2. **生成视频片段**（约 N × 5-8 = M 个 Cut）
   - 打开 [Seedance 2.0](https://seedance.ai) 或可灵 / Runway
   - 按 §四视频提示词表，逐 Cut 复制提示词（**含开头的 `[<画幅>构图]` 部分一起复粘**）
   - 上传 `@P0X-storyboard.png` 作为单张素材引用
   - 🔴 **画幅锁定关键步骤**（v7.0.2）：在 Seedance 工具里**手动选 `settings.aspect_ratio` 对应画幅**（不是默认 16:9，也不是参考图的 16:9）
     - 项目 9:16 → Seedance 选 9:16
     - 项目 21:9 → Seedance 选 21:9
     - 项目 1:1 → Seedance 选 1:1
     - **目的**：故事板大图 16:9 是参考用的，最终视频画幅必须按项目设定，否则与剪辑后期不匹配
   - 生成后归档：`outputs/<集数>/cuts/P0X-Cut<N>.mp4`

3. **后期剪辑串接**
   - 用 PR / FCP / 剪映 / DaVinci Resolve 串接 Cut 1 ... Cut M
   - 按音乐编号 §六添加配乐
   - 添加字幕、片头片尾

### 7.2 单镜模式操作步骤

1. **跳过故事板生成步骤**（无需生 P0X-storyboard.png）

2. **生成视频片段**
   - 按 §四视频提示词表（单镜模式部分），逐 Cut 复制（**含开头的 `[<画幅>构图]` 部分一起复粘**）
   - 上传多张 @ 图片对应的资产 PNG（按本 Cut 实际需要）
   - 🔴 **画幅锁定关键步骤**（v7.0.2）：在 Seedance 工具里手动选 `settings.aspect_ratio` 对应画幅
     - 单镜模式同样要锁画幅——character/scene/prop 各 PNG 可能不同画幅，不锁会漂移
   - 生成后归档：`outputs/<集数>/cuts/P0X-Cut<N>.mp4`

3. **后期剪辑串接**
   - 同 §7.1 第 3 步

### 9.3 给下一集的核心交接（v7.0.2 强化 · 跨集累积风险防御）

> **设计原则**：下一集的分镜师**只读这一段**就能准确续上，不需要回溯前 N-1 集的全部 episode-master。这是「跨集累积风险」的核心防御——传递的不是历史，是**核心交接信号**。

下一集分镜师必填以下 8 项（缺一不可，缺失填「无」明确声明）：

```yaml
to_next_episode:
  # 1. 视觉风格连续性（防漂移）
  storyboard_style: <5 候选之一>            # 故事板风格名（下一集分镜师默认沿用）
  visual_style_keywords: <3-5 个关键词>     # 视觉风格特征关键词（如「皮克斯质感 · 暖色 · 高饱和」）
  aspect_ratio: <如 9:16>                  # 视觉画幅（不变就传同值；改变需用户确认）

  # 2. 末镜状态（开场衔接）
  last_shot_summary: <一句话>               # 本集最后一镜的画面（如「林晚抱着画笔站在阁楼窗前，夕阳逆光」）
  last_emotion: <情绪关键词>                # 末镜情绪（如「释然 · 期待」）
  last_time_space: <时空>                   # 末镜时间地点（如「黄昏 · 阁楼」）

  # 3. 资产传承（防止下一集重复生成）
  assets_to_reuse: <ID 列表>                # 必须复用的资产 ID（如「@图片1 林晚 · @图片3 画笔」）
  music_leitmotif: <M0X 编号>               # 主题音乐 leitmotif（如「M01 · 主题钢琴动机」）

  # 4. 未解决的剧情线索（避免下一集忘了接）
  unresolved_threads: <列表>                # 本集结尾留下、下一集必须接的剧情线索（如「画笔光芒来源 · 父亲未现身」）
```

**为什么这样设计（解决跨集累积风险）**：
- 下一集分镜师不需要读 ep01..ep<N-1> 全部 episode-master.md（避免 N 集累积导致的信息过载）
- 只需读上一集的 `to_next_episode` 段（恒定 8 字段）→ 信息密度可控
- 即使做到第 50 集，跨集传递的信号仍然只有 8 字段，不累积
- 如发现某集的 `to_next_episode` 缺失字段，下一集分镜师必须**反向反馈**让上一集补全（不允许猜测）

```

## 模板使用注意事项

1. **三种模式填写规范**（v7.0.1）：
   - **纯故事板模式**：填 §三 + §四故事板部分；跳过 §四单镜部分；§七 填 7.1
   - **纯单镜模式**：跳过 §三；只填 §四单镜部分；§七 填 7.2
   - **混合模式**：§三 仅填故事板 P0X（单镜 P0X 不进本表）；§四 同一表中混填（故事板 P0X 的 Cut 素材引用填单图 @P0X-storyboard.png；单镜 P0X 的 Cut 填多图 @图片N）；§七 同时填 7.1+7.2 并标明哪些 P0X 走哪条路径
   - §一、二、五、六、八、九 三种模式都要填

2. **风险标记主动写**：§二全片衔接表的「风险」列必须主动评估，不要默认填 `-`。

3. **资产清单要完整**：§五要把本集用到的所有 @ 引用编号都列出，方便用户检查 PNG 是否已生成。

4. **跨集衔接备注**（§九）：续集项目必填；首集项目跳过 §九.1 + §九.2，只填 §九.3。

5. **用户操作清单**：分镜师按本集实际模式填对应的操作步骤段落——纯故事板填 7.1、纯单镜填 7.2、**混合模式同时填 7.1+7.2 并明确标注哪些 P0X 走哪条路径**。

6. **音乐编号对应**：从 `assets/music/music-design.md` 提取 M01-M0N 列表，**不要在视频提示词正文中提音乐**。
