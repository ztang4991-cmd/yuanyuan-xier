# 万能故事板衔接机制

> **底线**：衔接靠**前期一次性设计**，不需要等上一段视频生出来再写下一段。
>
> 衔接保障来自：
> 1. 资产复用（assets/visual/ 跨集一致）
> 2. 风格锁定（settings.visual_style + 故事板风格决策树）
> 3. 剧情连贯（编剧/导演前期已设计）
> 4. 后期剪辑（用户用剪辑工具串接 Cut 1...Cut M）
> 5. **衔接 frontmatter（M6 from_previous + to_next）**

## 一、四层衔接保障

| 层级 | 保障内容 | 落地位置 | 状态 |
|---|---|---|---|
| 1. 资产一致性 | 角色 / 服装 / 道具 PNG 跨集复用 | `assets/visual/` | ✓ 现有 |
| 2. 场景一致性 | 场景 PNG 跨集复用 | `assets/visual/` | ✓ 现有 |
| 3. 风格一致性 | settings.visual_style + 故事板风格决策树 | `references/storyboard-style-decision-tree.md` | ✓ v7.0 新增 |
| 4. **运动 / 情绪衔接** | from_previous + to_next 字段 + episode-master 衔接表 | M6 frontmatter + `episode-master.md` | **v7.0 新增** |

## 二、衔接 frontmatter（M6 字段规范）

每张万能故事板提示词的 YAML 头部，必须包含以下 6 个字段：

```yaml
---
剧情点 ID: P01
故事板 ID: P01-storyboard
时长: 约 15 秒
镜头数: 6（Cut 1 至 Cut 6）

承接上段:
  上段 ID: P00（首段填「无（开场）」）
  上段最后一镜简述: 小敏转身向左走，背影消失在街角，右手握紧黑伞
  本段第一镜衔接策略: 接续小敏走在湿润街道远景，方向左前，雨势相同，光影方向延续

引出下段:
  下段 ID: P02
  本段最后一镜简述: 黑伞独自留在路灯下，雨水打湿
  下段第一镜衔接策略: 镜头从黑伞拉远到全景街道，时间略过 5 分钟，路灯仍亮

风格: cinematic_realism
模块组合: [M1, M2, M3, M4, M5, M6, O1]
---
```

### 2.1 字段释义

| 字段 | 必填 | 用途 |
|---|---|---|
| 剧情点 ID | ✓ | 关联导演讲戏本的剧情点编号（P01, P02, ...） |
| 故事板 ID | ✓ | 文件名 + 视频提示词 @引用键 |
| 时长 | ✓ | 通常 15s ± 2s，超长时本字段记 P01.A=15s（拆分提示） |
| 镜头数 | ✓ | Cut 总数 + 编号范围 |
| **承接上段** | ✓ | 含 3 子字段：上段 ID / 上段最后一镜简述 / 本段第一镜衔接策略 |
| **引出下段** | ✓ | 含 3 子字段：下段 ID / 本段最后一镜简述 / 下段第一镜衔接策略 |
| 风格 | ✓ | 5 候选风格之一（见 storyboard-style-decision-tree.md） |
| 模块组合 | ✓ | 启用的模块列表（M1-M6 + 选用的 O1-O4） |

### 2.2 「上段最后一镜简述」写法

要求：**捕捉 5 维度信息**

1. **主体位置**：人物在画面哪里、面朝哪里、身体姿势
2. **关键道具状态**：道具在哪、什么状态（如「黑伞被握紧 / 黑伞落地 / 黑伞独自留下」）
3. **光影方向**：主要光源方向（如「路灯右上方」「夕阳左前方」）
4. **环境状态**：天气、时间、人群密度（如「雨势中等 / 街道无人」）
5. **情绪锚定**：情绪关键词（如「克制悲伤」「释怀」「震惊」）

**优秀示例**：
```
小敏转身向左走，背影消失在街角，右手握紧黑伞，路灯右上方暖黄光，雨势中等，情绪：克制悲伤
```

**糟糕示例**（信息不全）：
```
小敏走了
```

### 2.3 「本段第一镜衔接策略」写法

要求：明确告知 Seedance / 后期剪辑师，本段第一镜如何**视觉延续**上段最后一镜：

- **延续什么**：道具特写 / 光影方向 / 色调 / 情绪 / 对白
- **变化什么**：景别 / 机位 / 时间 / 角色位置

**优秀示例**：
```
延续：路灯暖黄光（同光影）+ 雨势中等（同环境）+ 克制悲伤（同情绪）
变化：景别从中景拉远到广角全景，时间略过 5 分钟（路灯仍亮，街道无人）
```

### 2.4 首段与末段的特殊处理

**首段（如 P01 是开场）**：
```yaml
承接上段:
  上段 ID: 无（开场）
  上段最后一镜简述: 无
  本段第一镜衔接策略: 用「建立镜头」开篇，明确时空（XXX 时间 / XXX 地点 / XXX 氛围）
```

**末段（如 P0N 是结尾）**：
```yaml
引出下段:
  下段 ID: 无（结尾）
  本段最后一镜简述: <写本段最后一镜>
  下段第一镜衔接策略: 无（结尾画面定格 / 渐黑 / 渐显字幕）
```

## 三、分镜师工作流（保证衔接质量）

```
分镜师收到导演讲戏本（含 P01 - P0N 所有剧情点）
   ↓
读取上一集（如有）的 episode-master.md
   ├─ 沿用故事板风格
   └─ 提取衔接习惯
   ↓
循环每个 P0X：
   ├─ 读 P(X-1) 的最后一镜描述（来自导演讲戏本）
   ├─ 读 P(X+1) 的第一镜描述（来自导演讲戏本）
   ├─ 写本 P0X 的「承接上段」3 子字段
   ├─ 写本 P0X 的「引出下段」3 子字段
   └─ 设计本 P0X 的 Cut 1-N
   ↓
全部 P0X 写完后，生成 episode-master.md：
   ├─ 列衔接表（每个 P0X 一行）
   ├─ 高亮潜在跳跃风险
   └─ 输出全片资产清单
```

**关键**：所有衔接设计在**前期一次性完成**，不需等任何视频生成结果。

## 四、跳跃风险标记

衔接表中可能出现的「跳跃风险」类型：

| 风险类型 | 触发条件 | 标记 | 解决建议 |
|---|---|---|---|
| 时间跳跃 | 上下段间剧情时间间隔 > 1 小时 | ⚠ 时间跳跃 | 用「转场提示」（如时钟特写、太阳轨迹、字幕） |
| 空间跳跃 | 上下段不在同一地点 | ⚠ 空间跳跃 | 用「位置过渡」（如交通工具、建筑物特写） |
| 情绪跳跃 | 上下段情绪反差 ≥ 3 级（如悲伤 → 欢快） | ⚠ 情绪跳跃 | 用「过渡情绪 Cut」缓冲，或用「相同物件特写」当锚点 |
| 角色跳跃 | 上下段主角不同 | ⚠ 角色跳跃 | 用「双角色同框 Cut」当桥接 |
| 道具消失 | 上段强调的关键道具下段未出现 | ⚠ 道具消失 | 在下段第一镜中保留道具余韵（如背景虚化的道具） |

**记录方式**：在 episode-master.md 的衔接表中专门列「风险」列，AI 主动标出。

## 五、episode-master.md 衔接表示范

```markdown
## 二、全片衔接表

| P0X | 上段衔接 | 故事板缩略 | 下段衔接 | 风险 |
|---|---|---|---|---|
| P01 | 无（开场） | 6 镜雨夜街角，男女主对视，递伞被拒 | → P02 黑伞特写拉远 | - |
| P02 | ← P01 黑伞特写 | 5 镜咖啡店内，独自饮咖啡，雨声回忆 | → P03 转家中夜深 | ⚠ 时间跳跃（5h） |
| P03 | ← P02 咖啡杯余温 | 7 镜家中夜，翻看老照片，决定告别 | → P04 第二天清晨 | ⚠ 时间跳跃（隔夜） |
| P04 | ← P03 决心眼神 | 5 镜清晨阳光，整理屋子，扔旧物 | → P05 散步公园 | ⚠ 情绪跳跃（沉重 → 释怀）|
| P05 | ← P04 阳光与笑容 | 6 镜公园树荫，遇见新朋友，重生开端 | 无（结尾） | - |
```

**风险列含义**：
- `-`：无明显跳跃风险
- `⚠ 时间跳跃`：需要剪辑时配字幕或转场提示
- `⚠ 情绪跳跃`：建议在 Cut 1 设计「过渡情绪缓冲」

## 六、Cut 与 Cut 之间的微观衔接（每个 P0X 内部）

故事板内的 Cut 1 → Cut 2 → ... → Cut N 之间也要衔接。

### 6.1 微观衔接 5 招（11 案例归纳）

1. **同道具特写延续**：Cut 1 结尾「黑伞特写」→ Cut 2 开头「黑伞特写另一角度」
2. **同光影方向延续**：Cut 1「路灯右上方暖黄光」→ Cut 2「同样路灯右上方暖黄光」
3. **同色调延续**：Cut 1「冷蓝雨夜」→ Cut 2「冷蓝雨夜」
4. **对白回环**：Cut 1 结尾台词「绝对不行」→ Cut 2 开头「不行也得行」
5. **情绪温度延续**：Cut 1「克制悲伤」→ Cut 2「延续的、稍重的悲伤」（不要从悲伤突跳欢快）

### 6.2 故事板中如何体现微观衔接

在 M4 分镜网格的每个 Cut 描述中，**显式写「承接 Cut <N-1>」**：

```
Cut 2 | 时长 1.6s | 焦距 85mm | 中景特写 | 静态 |
描述：女主目光坚定，对男主说「绝对不行」，雨水打湿头发
对白：「绝对不行」
承接：Cut 1（同雨夜街角，路灯右上方暖黄光延续）
```

## 七、视频提示词如何使用衔接信息

视频提示词表中每个 Cut 都有「承接」字段，引用故事板的衔接信息：

| Cut | 剧情点 | 承接 |
|---|---|---|
| Cut 1 | P01 | 承接上段：P00 最后一镜延续（首段填无） |
| Cut 2 | P01 | 承接 Cut 1（同雨夜街角，路灯延续） |
| Cut 3 | P01 | 承接 Cut 2（同色调，景别从中景到特写） |
| ... | ... | ... |
| Cut N | P01 | 承接 Cut N-1，引出 P02（黑伞特写拉远） |

让 Seedance 在生成时**显式知道前后帧的延续策略**。

## 九、底线

> **衔接是「描述层面相同 + 观众脑中产生连贯感」，不是「让 AI 把帧对齐」**
>
> Seedance 每次生成是独立任务，无法保证相邻两条提示词生成出的视频在像素层面对齐。
>
> 所以衔接的落地方式是：
> - ✅ 描述层面相同 → AI 大概率生成相似画面 → 观众脑中产生连贯感
> - ❌ 不要在提示词中写「接上一条视频的最后一帧」（AI 不知道你「上一条」是什么）
> - ❌ 不要在提示词中写「画面与 P03 无缝衔接」（超出 Seedance 理解范围）
>
> **最终的视觉连贯感来自「资产 + 风格 + 描述 + 后期剪辑」的合力**。
