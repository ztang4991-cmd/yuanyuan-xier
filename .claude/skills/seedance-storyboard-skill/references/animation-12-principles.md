# 迪士尼动画 12 原则在 Seedance 提示词中的应用

> 1981 年由迪士尼老动画师 Ollie Johnston 和 Frank Thomas 在《The Illusion of Life》一书中总结的 12 条动画原则。
> 虽然源自 2D 手绘动画，但**对所有动态视频生成同样适用**——包括 AI 视频生成（Seedance / 可灵 / Runway）。
> 分镜师在编写 3D CG 风格、动画风格、动作密集的提示词时调用本文。

---

## 12 原则速览

| # | 原则 | 一句话核心 | Seedance 提示词应用 |
|---|------|-----------|---------------------|
| 1 | 挤压与拉伸 | 物体受力时形变 | 描述弹性物体的形变 |
| 2 | 预备动作 | 大动作前必有小预备 | 在主动作前加预备描述 |
| 3 | 演出表现 | 动作要清晰可读 | 镜头/构图突出关键动作 |
| 4 | 直接动作 vs 姿势对应 | 创作方法的选择 | 描述运动方式 |
| 5 | 跟随和重叠动作 | 不同部位不同步停止 | 描述衣袂/头发的延迟运动 |
| 6 | 缓入缓出 | 起步/停止时慢，中间快 | 描述加速度感 |
| 7 | 弧线 | 自然运动都是弧线 | 描述运动轨迹 |
| 8 | 次要动作 | 主动作之外的支撑动作 | 加入呼吸/眨眼/微表情 |
| 9 | 时间节奏 | 不同速度=不同重量/情绪 | 控制动作时长 |
| 10 | 夸张 | 强化关键瞬间 | 描述夸张程度 |
| 11 | 实体感的素描 | 物体有体积感 | 描述材质/重量 |
| 12 | 吸引力 | 角色有"魅力" | 设计独特的视觉记忆点 |

## 详细说明 + Seedance 应用

### 1. 挤压与拉伸（Squash and Stretch）

**原则**：物体在运动和受力时会发生形变（弹起的球会被压扁，跳起时会被拉长）。

**用法**：在描述弹性、有生命力的物体时，明确写出形变。

**示例**：
```
❌ 弱：「皮球落地。」
✅ 强：「皮球落地的瞬间被压扁成扁圆形，紧接着弹起时拉长成椭圆，最终回到圆形。」
```

**适用**：动画风格、卡通风格、Q 版角色、有弹性的物体（皮球、气球、果冻、卡通角色脸部）

### 2. 预备动作（Anticipation）

**原则**：任何主动作前都有一个反向的预备动作（要往前冲，先后退半步；要跳起，先下蹲）。

**用法**：在 Seedance 提示词中，明确写出"主动作之前的预备小动作"。

**示例**：
```
❌ 弱：「她转身跑掉。」
✅ 强：「她先猛地一愣，肩膀紧绷半秒，然后才转身飞奔。」
```

**为什么重要**：Seedance 容易把动作生成得"突兀"，预备动作给观众"预测时间"，让动作看起来自然。

### 3. 演出表现（Staging）

**原则**：构图、镜头、姿势让关键动作"一眼看懂"。

**用法**：描述镜头位置 + 角色姿势，让动作位于画面"读图焦点"。

**示例**：
```
❌ 弱：「主角举起剑。」
✅ 强：「侧面中景镜头，主角面向画面右侧的对手，将剑高举过头顶；阳光从右上方照射，剑刃反光成为画面亮点。」
```

### 4. 直接动作 vs 姿势对应（Straight Ahead vs Pose-to-Pose）

**原则**：两种动画创作方法：
- 直接动作：从头到尾逐帧画（流畅但难控）
- 姿势对应：先画关键姿势再补帧（可控但可能僵）

**Seedance 应用**：影响"运动方式描述"
- 流体性强的运动（液体流动、火焰、烟雾）→ "直接动作"风格描述（连续的过程）
- 角色动作（走路、打斗）→ "姿势对应"风格描述（明确写出关键姿势）

**示例**：
```
液体（直接动作）：「水流从瓶口涌出，先呈弧形抛物线，然后散成水珠，最后聚成一滩水洼。」
打斗（姿势对应）：「他先做出格挡姿势，左臂横在胸前；下一秒右脚发力踢出；最后落地呈防御站位。」
```

### 5. 跟随和重叠动作（Follow Through and Overlapping Action）

**原则**：身体的不同部位不会同时停止——主体停下时，附属物（头发、衣袂、披风、尾巴）还在动。

**用法**：在描述角色停止动作时，加上附属物的延迟运动。

**示例**：
```
❌ 弱：「她停下脚步。」
✅ 强：「她停下脚步——但身上的丝质长裙还在向前飘了半秒，肩上的发丝迟到地落下。」
```

### 6. 缓入缓出（Slow In and Slow Out）

**原则**：运动的开始和结束都慢，中间快。物体不会突然加速到最大速度。

**用法**：在描述镜头运动、角色移动时，写出加速感。

**示例**：
```
❌ 弱：「镜头推向她的脸。」
✅ 强：「镜头从远景缓缓启动，逐渐加速推向她的脸，在抵达特写前半秒减速，最终稳稳停在她的眼睛上。」
```

### 7. 弧线（Arcs）

**原则**：所有自然运动的轨迹都是弧线（手臂挥舞是弧线，头部转动是弧线，球被抛出也是弧线）。

**用法**：在描述运动时强调弧形轨迹。

**示例**：
```
❌ 弱：「她转头看向他。」
✅ 强：「她的头从左侧画一道弧线转向右侧，目光最终停在他身上。」
```

### 8. 次要动作（Secondary Action）

**原则**：主动作之外的次要动作能强化角色生命感（说话时眨眼、走路时摆手、思考时摸下巴）。

**用法**：每个关键动作配 1-2 个次要动作。

**示例**：
```
❌ 弱：「他在思考。」
✅ 强：「他靠在椅背上思考——同时手指无意识地敲击桌面，眼睛偶尔扫过窗外，喉结上下滑动了一次。」
```

### 9. 时间节奏（Timing）

**原则**：动作的速度决定了观众的感受：
- 慢动作 = 庄重、重量、悲伤
- 快动作 = 兴奋、紧张、轻盈
- 急促 = 慌乱、惊吓

**用法**：在 Seedance 提示词中明确写出动作速度。

**示例**：
```
重量感：「他缓缓抬起锤子——锤头沉甸甸的，每移动一寸都要花两秒。」
轻盈感：「她快速点了三下脚尖，整个人轻盈得像羽毛。」
急促感：「他猛地推开门，脚步连珠般冲下楼梯。」
```

### 10. 夸张（Exaggeration）

**原则**：动画不是"复制现实"，而是"加强现实"。关键瞬间适度夸张能让观众感受到"被强调的真实"。

**用法**：在情绪 / 冲击 / 反差的关键瞬间，写出"略超出现实"的描述。

**示例**：
```
❌ 弱：「她惊讶地睁大眼睛。」
✅ 强：「她的眼睛瞬间瞪到极限，连瞳孔都收缩成一个点。」
```

**度的把握**：现实风格的项目适度夸张，卡通风格可大幅夸张。

### 11. 实体感的素描（Solid Drawing）

**原则**：物体在画面中应有体积感、重量感，不是"扁平的图"。

**用法**：描述物体时加入材质 + 重量 + 光影。

**示例**：
```
❌ 弱：「桌上有一本书。」
✅ 强：「桌上摊开着一本厚重的精装古书，书页发黄、纸质粗糙、边缘卷曲，左上角压着一只青铜镇纸。」
```

### 12. 吸引力（Appeal）

**原则**：角色必须有"魅力"——不是一定要好看，而是要有让人想看下去的视觉特征。

**用法**：每个角色设计至少一个独特的视觉记忆点（一道疤、一种姿势、一件配饰、一个口头禅性的动作）。

**示例**：
- 男主角：左眉骨上的旧疤痕 + 习惯性用右手捏左耳垂
- 反派：始终戴着白手套 + 说话前会先笑一秒
- 配角：随身带一个生锈的怀表 + 总是用拇指摩擦表面

**与 [创作九原则 - 超绝创意] 配合**：吸引力是"高概念"在角色层面的体现。

## 实际应用示例（一段完整的 Seedance 提示词）

**原始（弱版本，未应用 12 原则）**：

```
[项目视觉风格] 3D CG 写实风。

[画面通用描述]
@图片1（林书白）站在 @图片5（雨夜街角）的路灯下，看着 @图片14（怀表）。
然后他放进口袋，转身离开。
```

**优化（应用了多条 12 原则）**：

```
[项目视觉风格] 3D CG 写实风，皮克斯质感，柔和暖光。

[画面通用描述]
中景镜头【演出表现 #3】，@图片1（林书白）站在 @图片5（雨夜街角）的橙色路灯下。
他的右手缓缓抬起【缓入缓出 #6】，掌心朝上，@图片14（怀表）静静地躺在掌心，
表链在他指间缓慢晃动【跟随和重叠 #5】，呈现弧形轨迹【弧线 #7】。
镜头逐渐推近怀表特写【缓入缓出 #6】，雨水落在表面上溅起小水花【挤压与拉伸 #1】，
此时林书白的眼睛在镜头边缘闪过，瞳孔短暂收缩了一下【夸张 #10】。
他先深呼吸一次（胸腔起伏明显）【预备动作 #2】，
然后才合上表盖、放入大衣口袋——大衣下摆延迟半秒才向后摆动【跟随和重叠 #5】。
转身离开时，他的脚步缓慢沉重，每一步都像有铅块【时间节奏 #9 - 重量感】，
雨水打在他的肩膀上、滑过脖颈、最终在大衣前襟汇成一滴水珠落下【次要动作 #8】。
```

## 怎么用本文

- **现实风格的短片/长片**：选择性应用 #2, #5, #6, #7, #8, #9, #11（避免 #1 #10 的夸张）
- **动画风格的项目**：可应用全部 12 条
- **卡通/Q 版风格**：重点应用 #1 #2 #5 #10 #12
- **写实但有奇幻元素的项目**：用 #1 #10 强化奇幻部分，其余写实

不需要每条提示词都套用全部 12 条。原则是**让生成的视频"看起来像真的运动"**——选用最适合当前剧情点的几条即可。
