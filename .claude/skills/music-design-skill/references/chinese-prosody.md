# 中文词作 Prosody（韵律与旋律配合）

> Prosody = 歌词的韵律 + 旋律的关系。中文词有四声、入声、压韵规则，与英文词的处理方式不同。
> 本文给出中文项目的词作进阶技巧，与 SKILL.md 第二节"词作人素养（中英文双库）"配合使用。

---

## 一、中文韵律基础（音律）

### 1.1 四声与旋律走向

普通话有 4 个声调：
- 阴平（1 声）：高平 ─
- 阳平（2 声）：上扬 ／
- 上声（3 声）：先降后升 ∨
- 去声（4 声）：下降 ＼

**核心原则**：旋律走向应该**呼应字的声调**（不能完全反着来）。

**反例**：把"再见"（zài jiàn，两个 4 声）配在上扬的旋律上——听起来会变成"灾见"或"在见"（音变）。

**正例**：把"再见"配在下降的旋律上，听者一耳就听清楚。

**实操**：
- 写完歌词后，按当前预期的旋律走向哼一遍
- 听起来"变音"的字，要么换字、要么改旋律

### 1.2 入声字（特殊处理）

普通话没有入声，但粤语、闽南语、客家话保留入声。入声字短促、收束感强（如"白""黑""得""说"）。

**应用**：
- 普通话项目：入声字可以用在节奏的"重拍"上（增强冲击感）
- 粤语项目：尊重入声字的短促感，不要拉长

### 1.3 押韵规则

中文流行歌的押韵比英文宽松，但**有些位置必须押**：

| 位置 | 押韵要求 |
|------|---------|
| 副歌的最后一字 | 必押 |
| 每段主歌的最后一字 | 必押 |
| 副歌内部的句尾 | 多数押韵（可以 ABAB / AABB / AAAA） |
| 主歌内部的句尾 | 可松可严 |

**中文常用韵脚**（13 辙 + 通押）：

中华辙韵 13 辙：
1. 中东辙：东、风、空、虫
2. 江阳辙：江、阳、强、唱
3. 一七辙：一、七、起、心
4. 灰堆辙：飞、悲、贵、累
5. 言前辙：天、年、面、间
6. 人辰辙：人、心、新、深、温
7. 怀来辙：来、海、爱、白
8. 梭波辙：歌、过、说、火
9. 姑苏辙：路、苏、出、孤
10. 由求辙：游、求、走、留
11. 摇条辙：摇、潮、走、笑
12. 麻沙辙：麻、家、花、爬
13. 乜斜辙：街、邪、月、写

**实操**：
- 写副歌前先确定韵脚（如"言前辙"）
- 副歌的句尾都用言前辙的字（天、年、间、面、远、变、念...）
- 主歌可以换韵，但全篇不要超过 2-3 个韵脚（容易乱）

## 二、句中押韵（Internal Rhyme）

中文流行词除了句尾押韵，还可以做**句中押韵**——同一句内部的某些字相互押韵。

**示例（唐恬风的句中押）**：
```
《孤勇者》
都　不　怕　/　战　吗　战　啊　/　以　最　卑　微　的　梦
   (a)        (a)  (a)  (a)
```

句中押让歌词的"韵律感"更密集，听起来"上头"。

**实操**：写副歌句子时，每句内部刻意安排 1-2 个押韵字。

## 三、字数与节奏对齐

中文每个字 = 1 个音节。歌词的字数直接决定演唱的节奏。

### 3.1 同位置字数对齐

副歌的对应位置（如 4 句副歌的每句）字数应**对齐**或**呈梯度变化**：

✅ 对齐：
```
我想你时风也轻 (7)
我念你时月也明 (7)
我爱你时光也暖 (7)
我等你时心也静 (7)
```

✅ 梯度变化（短-长-短-长）：
```
你来了 (3)
带着春天的脚步 (7)
你走了 (3)
留下整片荒芜 (6)
```

❌ 乱：
```
我想你时风也轻 (7)
月色让我心动 (6)
爱你十年 (4)
我等你回来的那一天 (9)
```

### 3.2 拖音字（让旋律拉长的字）

中文歌的副歌经常用一个字拉长 2-4 拍，让旋律延展。

**适合拖音的字**：
- 韵母开口大的字（爱、暖、远、念）
- 单字成义的字（你、我、爱、痛、家、梦）
- 韵母圆润的字（梦、空、风）

**不适合拖音**：
- 入声字（白、黑、说、得）
- 短促的字（且、跌、突）

**实操**：每段副歌的最后一字最好是"适合拖音"的字。

## 四、唐恬风：叙事凝练（重点参考）

唐恬的代表作《孤勇者》《赢》《誓言》《魂》。她的词作有几个鲜明特征，中文流行词写作必学：

### 4.1 高高举起轻轻放下

副歌前用很激烈/夸张的铺垫，副歌反而用一个朴实的字句收回来。

**示例**：
```
都 不 怕 / 战 吗 战 啊 / 以 最 卑 微 的 梦
（铺垫激烈）       （副歌反而轻轻一句）

致 那 黑 夜 中 的 呜 咽 与 怒 吼
（情绪推到顶）

谁 说 站 在 光 里 的 才 算 英 雄
（一句反问收回来，反而最有力）
```

### 4.2 为后半句造势

整段歌词的能量都在"为最后一句"造势——前面所有铺垫，都是为了让最后一句"落"得最重。

### 4.3 拒绝"高级感"堆词

唐恬绝不堆这类词：
- "月光""温柔""心跳""誓言"（空转词）
- "繁星""夜空""无尽""永远"（套路词）

她用的是"具体到一个动作/一个画面"的词。

### 4.4 事件叙事 vs 情绪堆叠

唐恬的歌词更像"小故事"——有人物、有动作、有时间。不是只有情绪宣泄。

**对照**：
```
❌ 情绪堆叠：「我好难过 我好想你 我好寂寞 我好无助」
✅ 事件叙事：「我又走过了那条街 你的店铺已经关门 / 玻璃上还有你写过的字 / 已经被雨水冲淡」
```

## 五、方文山风：意象拼贴（古风画面）

方文山的代表作《青花瓷》《菊花台》《东风破》《千里之外》。他的词作有这些特征：

### 5.1 意象堆叠

不直接说情绪，用意象组合传达。

**示例**：
```
天 青 色 等 烟 雨 / 而 我 在 等 你
（天青色 + 烟雨 = 等待的意象；不说"我在等"而说"天青色在等"）
```

### 5.2 以象代言

用物件代替人物的情绪。

**示例**：
```
炊 烟 袅 袅 升 起 / 隔 江 千 万 里
（炊烟 + 隔江 = 远方家的意象；不说"我想家"而说"炊烟在升起"）
```

### 5.3 古风词汇染色

用古典词汇让歌词整体"色调"古旧：
- 兰亭、青花、烟雨、芙蓉、宣纸、墨笔...
- 等候、相思、暮春、晓风、残月...

### 5.4 跨主语的诗化句法

方文山经常省略主语或转移主语：

**示例**：
```
天 青 色 等 烟 雨 而 我 在 等 你
（天青色等 / 我在等——主语跨越，诗意感）
```

## 六、其他风格：第三种轨迹的词人

中文项目的"歌词三版"中，建议第三版用与唐恬+方文山都不同的轨迹，扩大用户选择空间。备选：

### 6.1 林夕：哲思口语型
- 代表作：《富士山下》《漩涡》《暗里着迷》
- 特征：把哲学思考写成口语；副歌经常是一个反问句
- 适用：成熟、克制、需要思考层的项目

### 6.2 黄伟文：总体叙事型
- 代表作：《喜帖街》《光辉岁月》
- 特征：用"宏观叙事"写时代/城市/群体
- 适用：史诗感、集体记忆、社会议题

### 6.3 罗大佑：时代反思型
- 代表作：《童年》《亚细亚的孤儿》《光阴的故事》
- 特征：把时代写进个人故事，把个人故事写成时代切片
- 适用：怀旧、社会变迁、跨代主题

### 6.4 互联网作词人：现代口语型
- 代表（不指名某人）：网易云热门歌词、抖音热门歌
- 特征：口语化、年轻态、流行符号、自嘲幽默
- 适用：年轻向、互联网气质、轻松基调的项目

## 八、Suno 中文发音矫正

> ⚠️ **本节给出中文专属的发音矫正**。双语通用的发音诡计（拼音化、CAPS 加重、拉长元音、戏剧停顿、连字符断音等）详见 `vocal-pronunciation-tricks.md`——英文项目和双语项目都需要参考那份文档。

Suno 对中文的发音有时会出错，几种应对方法：

### 8.1 把易错字改写

| 原字 | 改写 | 适用 |
|------|------|------|
| 一（多音字 yī/yí/yì） | 改成具体声调标注或用同义字 | 标题位 |
| 得（多音字 dé/de/děi） | 在 Style 中说明 | 关键句 |
| 还（多音字 hái/huán） | 在 Style 中说明 | 副歌句 |
| 好（多音字 hǎo/hào） | 改用近义字 | 高频字 |

### 8.2 在 Style 中加发音提示

```
Style: ..., Mandarin pronunciation, particularly note that "得" should be pronounced "děi" (must)
not "de" (particle).
```

### 8.3 拉长字的元音矫正

如果想让某个字"拖长"，在歌词中可以这样写：

```
我 爱 你 ❌
我 爱 你 - - - ✅（中间的破折号 Suno 会理解为延长）
我 爱-i-i 你 ✅（拼音重复，强制拉长 i 音）
```

### 8.4 试听 → 修正

Suno 生成后试听，发音错的字回到歌词中改写——**生成前改比生成后改容易**。
