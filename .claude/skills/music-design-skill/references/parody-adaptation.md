# Parody / Adaptation：改编已有歌词的方法论

> 当用户拿一首已有歌的旋律，要求重写新歌词（用于配本项目的剧情/人物/情绪），就属于 **Parody / Adaptation 改编场景**。
>
> 这场景特殊：原歌的旋律、节奏、押韵、重音都已经定了，新歌词必须"严丝合缝"贴上去，否则 Suno 唱出来会跑调、卡顿、错位。
>
> 本文给出改编的完整方法论。当 SKILL.md 第五节工作流的研读上下文阶段发现"用户带了已有歌的旋律"，调用本文。

---

## 一、改编场景的典型情况

### 1.1 用户的常见诉求

- "我用《孤勇者》的旋律，但词要改成本片的故事"
- "把《See You Again》的副歌改成中文版，用在本片片尾"
- "MV 用《房间》的旋律，但词要按本片角色名重写"
- "致敬经典 + 致敬情怀 + 借势记忆度"

### 1.2 为什么这场景需要专门方法论

- 普通歌词创作：只要符合内部押韵和节奏感
- 改编创作：**必须**贴合原歌的：
  - **音节数**（每句字数）
  - **重音位置**（哪些字落在重拍上）
  - **押韵格式**（ABAB / AABB / 复杂内押）
  - **拖音位置**（哪些字被拉长，对应原歌的长音）
  - **元音音色**（拖长的音上元音是否与原歌一致）

少了任何一条，唱出来都会"违和"。

---

## 二、改编 5 步法

### 第 1 步：解剖原歌（先做骨架分析）

**操作**：把原歌歌词逐句拆解，标注 4 个维度：

1. **音节数**：每句多少字（中文）/ 多少音节（英文）
2. **重音位置**：哪些字/音节落在重拍上（通常是动词/名词/形容词）
3. **押韵格式**：每句末尾字的韵脚，标记 A/B/C/D
4. **拖音字**：哪些字被拉长（通常在句末或副歌高潮）

**示例（《青花瓷》主歌前两句）**：

```
原句：素胚勾勒出青花笔锋浓转淡  （11 字，韵脚"淡"=A，"勒""花""锋"重音，"淡"拖音）
原句：瓶身描绘的牡丹一如你初妆  （11 字，韵脚"妆"=A，"身""绘""丹""妆"重音，"妆"拖音）
```

骨架分析结果：
- 每句 11 字
- A 韵（an / ang，言前+江阳通押）
- 重音位置基本相同
- 句末拖音

### 第 2 步：确定改编的"核心概念"

**核心问题**：你要把这首歌的情感容器装上什么新内容？

**思考方向**：
- 原歌的情感是什么？（《青花瓷》：含蓄温柔的等待 / 古典美的怀念）
- 本项目的情感是什么？是否能挂在原歌的情感容器里？
- 二者之间的桥梁是什么？

**判断准则**：如果情感方向与原歌完全相反（原歌温柔，本项目暴烈），不建议改编——会有违和感。改编最适合"同基调 + 不同主题"的迁移。

### 第 3 步：填新词（核心难点）

**操作**：逐句替换原词，遵循以下铁律：

#### 铁律 1：音节数对齐

- 原句 11 字 → 新句必须 11 字
- 容许浮动：可弹性 ±1-2 个不重读音节
- 不要超过 ±2，否则会唱不下

#### 铁律 2：重音位置对齐

- 原句的重音字（例"勒""花""锋"）在新句的对应位置也必须是重音字
- 如果原句的重音字在第 3/6/9 字位，新句的第 3/6/9 字位也必须是动词/名词/形容词

#### 铁律 3：押韵格式严格对齐

- 原歌 ABAB → 新歌也必须 ABAB
- 韵脚位置（每句末/隔句末/句中）保持一致

#### 铁律 4：拖音字的元音对齐（关键！）

- 这是改编最容易翻车的地方
- 原歌拖长的字 "love"（O 音），新词的对应字必须也是 O 音（"go"/"so"/"hope"）
- 中文同理：原歌拖长 "天"（an 音），新词对应字必须也是 an 音（"远"/"念"/"残"）

**为什么这条最重要**：拖长音的元音不对齐，唱出来会从"圆润"变成"尖锐"或"沉闷"，破坏整首歌的音色质感。

#### 铁律 5：单音节核心词替换

- 在关键位置（钩子、副歌首句、副歌末句）做"一字易词"
- 原词 "Crime" → 新词 "Code"（同韵母）
- 原词 "Love" → 新词 "Hope"（同韵母 + 同情感空间）
- 这种"单字替换"是改编最干净有力的手法

### 第 4 步：试唱验证（不可跳过）

**操作**：拿原歌的伴奏（去人声版本，找 instrumental），把新词唱上去。

**检查清单**：
- ✅ 每句能不能唱完？（音节数对齐）
- ✅ 是否有"卡顿"？（重音位置错位）
- ✅ 拖长音是否"圆润"？（元音对齐）
- ✅ 押韵处是否有回响感？（韵脚对齐）

**如果任何一项失败**：回到第 3 步那一句重写，不要将就。

### 第 5 步：留下"原歌的影子"（情怀加分项）

**操作**：保留原歌中 1-3 个"标志性元素"不改：

- **标志性短句**：例《青花瓷》的"如传世的青花瓷自顾自美丽"，改编时可以保留"自顾自美丽"4 字
- **结构性 hook**：例《See You Again》的"It's been a long day without you my friend"，改编可保留前半句节奏 + 替换后半句
- **关键意象**：例"月光""青花""星空"等，保留 1 个作为锚点

**作用**：观众会感到"既新又熟"的双重快感——这是改编最大的情感优势。

## 三、改编的 Suno 提示词调整

改编场景的 Suno 提示词与原创场景有 3 处不同：

### 3.1 Style 字段必须**精确匹配原歌**

不能写"类似 XX 风格"——会被 Suno 误判为模仿艺人。要描述声音特征：

```
❌ "Periwinkle Style"  / "致敬周杰伦 R&B"
✅ "early 2000s Chinese R&B ballad with mid-tempo groove, soft male vocal in chest voice with breathy passages, traditional Chinese pentatonic melody over R&B chord progression, electric piano + sparse guzheng accents, 75 BPM, melancholic and intimate atmosphere, like East-meets-West fusion popular in early 2000s Mandopop"
```

详见 `chinese-prosody.md` 和 SKILL.md 第八节红线（不用艺人名/商标）。

### 3.2 Lyrics 字段加 [Adapted] 标记（可选）

如果是公开改编（参考原歌但完全重写），在 Lyrics 开头加：

```
[Adapted - inspired by classic Chinese R&B ballad arrangement]
[Verse 1]
（新歌词）...
```

这告诉 Suno：保留原歌的"风格 DNA"，但生成全新的旋律编曲。

### 3.3 试听后的"扩展生成"（Extend）

改编最大的风险：Suno 生成的旋律虽然贴近，但偶尔会偏离原歌结构。

**操作**：生成 3-5 个版本后，找最接近原歌结构的那一个，用 **Suno Extend 功能**延长——延长时再次输入相同 Style，能让风格不漂移。

## 四、改编的合规底线

⚠️ **以下情况是法律 / 平台风险，不要做**：

1. **直接使用原歌旋律配新词，对外发布**：除非取得版权方授权，否则属于改编权侵权
2. **以"翻唱"名义但实际改了歌词**：版权方可能投诉
3. **商用项目改编经典歌曲**：必须先购买改编授权（俗称 "publishing rights"）
4. **改编作品里保留原歌歌词片段 + 新歌词**：属于"二次创作"，法律风险大

**安全做法**：
- 自用 / 学习 / 创作参考：OK
- 短视频平台个人发布（非商用 + 标注致敬）：低风险
- 商用 / 客户项目：必须取得授权

## 五、改编的产出物格式

写入 `assets/music/music-design.md` 时，改编模块用如下格式：

```markdown
## M01 - <用途说明>（改编自《XX 原歌》）

⚠️ **改编模块**：本曲基于 <原歌名> 的旋律 / 节奏 / 押韵骨架改编。
⚠️ **版权提示**：商用前必须取得原歌版权方授权（改编权 + 同步权）；非商用建议在视频中标注"致敬 XX"。

- 对应剧情：<剧情点编号 / 场景描述>
- 改编原歌：<原歌名> / <原歌演唱者>
- 改编理由：<为什么改编这首，1-2 句>
- 保留元素：<原歌中保留的标志性短句 / 钩子 / 意象>
- 修改幅度：<完全重写新词 / 部分保留原词 / 仅替换关键字>

[骨架分析]
（粘贴第 1 步的解剖结果）

[新歌词]
（粘贴改编后的歌词，附 meta-tags）

━━━ 🎵 复制这里到 Suno ━━━
Style: <精确描述声音特征，不用艺人名>

[Adapted - inspired by ...]
[Verse 1]
（新歌词）...
━━━ 复制到此为止 ━━━
```

## 六、与 SKILL.md 主体的关系

- **触发时机**：SKILL.md 第五节"第一步：研读上下文"——当发现用户提供了已有歌作为参考，且明确"用这首歌的旋律改编"时，调用本文
- **路由**：本文不替换 SKILL.md 主体的工作流，而是作为"改编子流程"嵌入
- **歌词三版的处理**：如果是改编场景，三版可以是"改编程度不同的三版"（A 完全重写 / B 保留 30% 原词 / C 仅替换关键字），让用户在改编幅度上做选择

## 一句话总结

> 改编 = 旧瓶装新酒。瓶子（音节/重音/押韵/拖音）一颗螺丝都不能松；酒（情感/概念/意象）必须装得让人觉得"既熟悉又新鲜"。
