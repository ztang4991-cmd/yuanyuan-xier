# Gemini 音频分析指南（MV模式专用）

## 背景

Claude 系列模型目前不支持直接处理音频文件。当你有一首现成的歌曲想做MV时，需要先用 Gemini 分析音频，再把分析结果给Claude的音乐总监Agent继续工作。

这不是"绕路"——这是用最合适的工具做最合适的事：Gemini负责"听懂歌"，Claude负责"把歌变成画面"。

---

## 第一步：用Gemini分析你的歌曲

### 把这段话复制给Gemini（替换「歌曲名」部分）：

```
我正在为这首歌制作MV，需要你帮我做一份详细的音乐结构分析文档。

请分析这首歌并输出以下内容：

## 基本信息
- 歌曲名称和演唱者（如知道）
- 总时长
- BPM（节奏）
- 调性/整体情绪

## 歌曲结构（时间轴）
按时间列出每个段落：
- [00:00-00:XX] 段落名称（如前奏/主歌/副歌/间奏/尾奏）
- 每段的情绪描述（激昂/平静/压抑/释放等）
- 每段的能量等级（1-10分）
- 乐器主导（鼓/弦乐/钢琴/吉他/人声等）

## 情感弧线
- 全曲情绪变化的整体走向（如：压抑→爆发→释放→余韵）
- 最有冲击力的3个时间点（适合画面高潮/冲击）
- 最安静/留白的3个时间点（适合慢镜/抒情画面）

## 歌词关键意象（如有歌词）
- 反复出现的核心意象
- 最金句/记忆点的歌词（用于字幕/画面文字）
- 叙事视角（第一人称/第三人称/旁观者）

## MV视觉方向建议
- 3个可能的MV视觉叙事方向（简短描述即可）
- 哪种方向最适合这首歌的气质

请用Markdown格式输出，我会把这份文档放入项目文件夹。
```

### 如何上传歌曲给Gemini：
- 在 [Gemini.google.com](https://gemini.google.com) 网页版直接上传音频文件
- 或在Gemini API中使用 `inline_data` 传入音频
- Gemini支持的音频格式：MP3 / WAV / AIFF / AAC / OGG / FLAC

---

## 第二步：保存分析结果

把Gemini输出的文档复制，存到项目目录：

```
input/参考/music-structure.md
```

---

## 第三步：告诉制片人文档已准备好

回到Claude，输入：
```
music-structure.md已经放好了，可以开始MV流程
```

制片人会让音乐总监Agent读取这份文档，基于它做视觉编排分析，然后交给导演和分镜师。

---

## 音乐总监读取这份文档后会做什么

音乐总监**不会**重新创作音乐（歌已经有了），而是：
1. 读取时间轴，转化为"视觉情绪时间轴"（每个时间段建议什么样的画面气质）
2. 标出关键节拍点（画面切换的最佳时机）
3. 提供人声/乐器段落的视觉处理建议（有人声时是否需要人物出现）
4. 给导演提供"音画对位方案"

这份"视觉情绪时间轴"会存入 `assets/music/mv-visual-timeline.md`，成为后续导演和分镜师的工作基础。

---

## 注意事项

- Gemini分析的质量取决于音频清晰度；压缩严重的MP3效果可能差一点
- 如果歌曲有版权限制，在生成的MV里注意使用场景
- 这个流程同样适用于纯器乐（没有歌词的配乐），只需跳过"歌词关键意象"那部分
