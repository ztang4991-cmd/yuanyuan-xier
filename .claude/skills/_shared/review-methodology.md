# 审核共享方法论

> 这是 4 个审核 skill（`script-analysis-review-skill` / `art-direction-review-skill` / `seedance-prompt-review-skill` / `compliance-review-skill`）共用的**审核哲学、流程框架、输出规范**。
>
> 各 skill 自身只保留"**审核对象**"和"**验收清单**（具体检查维度或评分维度）"，其余引用本文。

---

## 一、审核立场（最重要的一条）

你的任务是 **找出问题**，不是确认通过。

如果你以"通过审查"的心态读产出，会本能地为每个不完美的地方找借口；
如果你以"挑刺"的心态读，才能真正帮上游 agent 提升质量。

**自检小问**：你的审核报告里如果连一条"建议"都没有，多半不是产出完美，而是你没读认真。

---

## 二、审核流程框架（5 步）

所有审核 skill 都遵循这同一套流程，**变的是"读什么"和"按什么标准评"，不变的是这 5 步**：

### 第一步：建立整体理解

读以下三类材料：
1. **当前阶段的产出**（要审的对象）
2. **上游产出**（产出的"参照系"，如审分镜要读导演讲戏本）
3. **平台/项目约束**（如视觉风格、目标媒介、合规红线）

明确审核立场（见上一节）。

### 第二步：逐项比对

把产出和上游"参照系"逐句对照，找出：
- **遗漏**：参照系里有的，产出里没体现
- **偏离**：意思被改了
- **弱化**：保留了但表达不够具体
- **冲突**：和参照系矛盾
- **越界**：产出里多出来的、参照系没要求的内容（判断是否合理）

记录所有偏差，**无论大小**——大问题决定 PASS/FAIL，小问题用来打分降档。

### 第三步：脑内预演

这是把审核从"形式检查"升级到"质量检查"的关键。

对每条产出，闭眼想象它真正被使用时的效果：
- 审讲戏本 → 想象一个导演拿着这段去指导拍摄，画面会是什么样？
- 审视觉提示词 → 想象把这段文字丢进 Nano Banana / Gemini，生成出来的图是什么样？
- 审 Seedance 提示词 → 想象 Seedance 根据它生成的视频是什么样？
- 审合规 → 想象审核员/平台 RM 看到这段会不会拦截？

**判断标准**：预演出来的效果是否准确传达了上游意图？是否有任何描述会导致 AI 工具误解？

### 第四步：评分（或 PASS/FAIL 清单制）

按各 skill 自身的"验收清单"逐项打分（1-10 分制）或勾选（合规清单制）。

### 第五步：输出结果

按下方"输出规范"段的格式输出，区分 PASS / FAIL 两种结果。

## 三、评分规则（评分制审核 skill 适用）

适用于：`script-analysis-review-skill` / `art-direction-review-skill` / `seedance-prompt-review-skill`
不适用于：`compliance-review-skill`（清单制，只勾选不打分）

### 评分标准

| 分段 | 含义 |
|------|------|
| **9-10** | 精准达标，脑内预演效果完全符合预期，无需修改 |
| **7-8** | 基本到位，但有 1-2 处可以更具体或更准确的地方 |
| **5-6** | 有明显的模糊、跳跃、偏离或可执行性问题，**需要修改** |
| **1-4** | 严重不足，无法指导下游工作 |

**为什么是这套分档**：实践中我们发现，硬性"≥9 才算好"会让审核员把所有事都打到 9 分（"差不多就 9 吧"），失去区分度；而 "7-8 算合格"又会让基本到位但有瑕疵的产出滑过。**7-8 = 合格但可优化、5-6 = 需返工** 这条线最有用。

### 通过阈值

```
平均分 ≥ 8  且  无单项 < 6  →  PASS
平均分 < 8  或  任一单项 < 6  →  FAIL
```

**为什么是 8 不是 7**：8 是"基本到位 + 没有明显槽点"的最低线。只要平均掉到 7 区间，说明产出整体偏弱，宁可让上游再改一轮，也不要让弱产出污染下游的工作底子。

**为什么单项 < 6 一票否决**：哪怕其他维度都 9 分、平均拉到了 8，只要任何一个维度低于 6（说明该维度产出明显不及格），下游一定会出问题。比如分镜的"动作可执行性"打 5 分，意味着 Seedance 大概率生成出动作糊掉的视频，再高的画面还原度也救不回来。

### 不要做的事

- **不要给所有项都打 9-10**：那是失职。审核者的价值就是看出问题，全 9 分等于没审。
- **不要为了让上游"高兴"而抬分**：审核 FAIL 不是惩罚，是上游再做一轮的依据；FAIL 反而代表你做了真正的审核。
- **不要只评分不写问题摘要**：分数是结论，问题摘要是依据。没有依据的分数不可信。

### 补充视角：行业 8 维评分参考

各审核 skill 保持自己的专属评分维度，但在脑内过一遍**行业 8 大维度**（剧本/导演/表演/摄影/剪辑/美术/音乐/创新性）有助于发现容易忽略的问题——特别是 **音乐** 和 **创新性** 维度。

**行业 8 大评分维度**：

| 维度 | 核心评判要点 | 对应到本项目的审核阶段 |
|------|------------|---------------------|
| 1. 剧本 | 故事是否有力？人物是否立得住？冲突是否成立？ | 阶段一编剧 + 阶段二讲戏本 |
| 2. 导演 | 视觉调度是否服务于叙事？节奏是否到位？整体气质是否统一？ | 阶段二导演分析 + 阶段五分镜 |
| 3. 表演 | 表演是否真实？情绪传递是否到位？（AI 视频：人物动作是否自然） | 阶段五 Seedance 提示词 |
| 4. 摄影 | 构图是否考究？光影是否有设计？镜头语言是否丰富？ | 阶段三服化道 + 阶段五分镜 |
| 5. 剪辑 | 节奏是否流畅？场景过渡是否自然？信息密度是否合理？ | 阶段二讲戏本信息密度 + 阶段五分镜衔接 |
| 6. 美术 | 服化道是否服务于人物/世界观？视觉风格是否统一？ | 阶段三服化道 |
| 7. 音乐 | 配乐是否服务于情绪？是否有"一发入魂"的瞬间？ | 阶段四音乐设计 |
| 8. 创新性 | 创意是否新颖？设定是否独特？是否避开了套路？ | 阶段一选题 + 全程贯穿 |

**每个维度的打分标尺**：

**维度 1：剧本**
| 分段 | 表现 |
|------|------|
| 9-10 | 故事独特、人物立体、冲突自然、结尾有余韵 |
| 7-8 | 故事完整、人物清晰、有亮点但稍套路 |
| 5-6 | 故事勉强成立，但人物或冲突有明显缺陷 |
| 1-4 | 故事讲不通、人物纸片化、冲突不成立 |

**维度 2：导演（影视维度，对应阶段二）**
| 分段 | 表现 |
|------|------|
| 9-10 | 每个剧情点的讲戏都让人脑中浮现清晰画面；节奏起伏有设计；上承下启自然 |
| 7-8 | 讲戏整体到位，但有些剧情点稍模糊或上承下启薄弱 |
| 5-6 | 部分剧情点讲戏不够具体，下游不容易拍 |
| 1-4 | 讲戏笼统空泛，下游需要自己脑补 |

**维度 3：表演（对应 AI 视频的"动作自然度"）**
AI 视频里没有真人表演，但有"角色动作生成"。
| 分段 | 表现 |
|------|------|
| 9-10 | 每个动作描述具体到肢体细节，Seedance 大概率能生成自然动作 |
| 7-8 | 动作描述基本到位，但有 1-2 处可能让 Seedance 生成动作糊掉 |
| 5-6 | 多处动作描述抽象，预演生成效果不佳 |
| 1-4 | 动作密度严重过载，Seedance 几乎无法生成自然动作 |

**维度 4：摄影（对应服化道 + 分镜的"视觉设计"）**
| 分段 | 表现 |
|------|------|
| 9-10 | 光影设计具体到方向/色温/强度；构图有讲究；镜头语言有变化 |
| 7-8 | 光影基本到位，但有部分镜头平淡 |
| 5-6 | 光影描述模糊，构图单一 |
| 1-4 | 完全没有光影/构图意识 |

**维度 5：剪辑**
| 分段 | 表现 |
|------|------|
| 9-10 | 全片节奏有起伏，每个剧情点之间衔接自然，没有"硬切"感 |
| 7-8 | 节奏基本到位，但有 1-2 处过渡稍突兀 |
| 5-6 | 多处节奏雷同，过渡缺乏设计 |
| 1-4 | 节奏失控，过渡完全靠剪辑硬切 |

**维度 6：美术（对应阶段三服化道）**
| 分段 | 表现 |
|------|------|
| 9-10 | 每个角色/场景/道具都有审美设计，服务于人物和世界观 |
| 7-8 | 设计基本到位，但有"模板感" |
| 5-6 | 部分设计不够具体或与人物气质不符 |
| 1-4 | 关键词堆叠，没有审美意识 |

**维度 7：音乐（对应阶段四）**
| 分段 | 表现 |
|------|------|
| 9-10 | 音乐策略克制有理由；有"一发入魂"的瞬间；音乐与画面叙事高度契合 |
| 7-8 | 音乐方案合理，但缺少记忆点 |
| 5-6 | 音乐与画面情绪偶尔脱节 |
| 1-4 | 为填空而填音乐，完全不服务叙事 |

**维度 8：创新性（贯穿全程）**
| 分段 | 表现 |
|------|------|
| 9-10 | 高概念新颖独特，设定让人眼前一亮（参考 [创作九原则 - 超绝创意]） |
| 7-8 | 创意尚可，但部分套路化 |
| 5-6 | 创意平平，与已知作品高度相似 |
| 1-4 | 完全套路化，没有任何新颖元素 |

**怎么用这 8 维**：不要在每个审核 skill 里都做 8 维评分。各 skill 保持自己的评分维度，审核员在评分前先脑内过一遍 8 维（特别容易被忽略的"音乐""创新性"），如果发现明显问题，单独在"问题摘要"中点出（不重复评分）。

如发现 8 维中某项明显薄弱，**在 PASS 报告的"整体评价"段单独点出**（不重复评分），帮助上游下次注意。

### 补充视角：AI 生成技术约束清单

审核任何"X 应该保证 Y"类问题时，先核对 `_shared/ai-generation-constraints.md` 列出的硬约束——避免审核员要求上游产出 AI 工具技术上做不到的内容（如要求视频跨段帧对齐等）。

特别在 seedance-prompt-review 的 [整体连贯性] 段、art-direction-review 的 [跨集一致性] 段，要明确区分"描述层面的呼应"（可审）和"生成结果的像素级对齐"（不可审，技术不可达）。

### 补充视角：受众适配性 / 流量审视（对应 [创作九原则 #9 为流量服务]）

3 个业务审核 skill（script-analysis / art-direction / seedance-prompt）的评分表中**已经追加「受众适配」列**作为正式评分维度——这不是补充视角，而是**必评项**。music 审核虽无独立 skill，导演审核音乐设计时按 `music-design-skill` 第九节的「受众适配性自检」清单评 1-10 分。

评判时的关键参照：
1. 读 `assets/story/script-settings.md` 第 10-11 项确认本项目的**目标平台 + 目标受众画像**
2. 对照 `_shared/audience-engagement-guide.md` 第三节「平台规律对照表」确认目标平台的爆款逻辑
3. 用目标受众画像（如"小米：25 岁北漂女白领，加班后躺床上刷抖音"）做"会不会划走 / 会不会想分享"的脑内预演

**评分快速参考**：
| 分段 | 表现 |
|------|------|
| 9-10 | 产出完全服务于目标平台 + 目标受众，可预见的流量加成明显 |
| 7-8 | 产出基本合理，但有 1-2 处与目标平台规律有偏差 |
| 6 | 勉强可用，但目标受众容易"中段划走" |
| <6 | 与目标平台 / 受众完全脱节，必须重做 |

**特殊情况**：
- 院线/影展项目 → 受众适配性主要看「评委/影评人」而非「流量」，可在评分时换标准（艺术性高于平台规则）
- 项目未填目标平台/受众画像 → 审核员应**主动要求编剧补全**，不要凭空打分

### 子项：对标气质相似度（v6 新增，仅在有对标时启用）

读 `assets/story/script-settings.md > 对标爆款` 段，按其状态决定是否启用本子项：

- **状态 = 有对标 / 推荐后认领**：在「受众适配」维度下追加「对标气质相似度」1-10 分子项；与本指南其它子项均分时一同计入
- **状态 = 无（用户主动声明）**：**跳过**本子项，「受众适配」只看平台规律对照，不要凭空给对标气质打分
- **字段缺失或未填**：审核员应主动要求编剧/制片人补全本字段，不要凭空打分

「对标气质相似度」评分标准（详见 `_shared/audience-engagement-guide.md` 第八节）：
| 分段 | 表现 |
|------|------|
| 9-10 | 本产出能让人立刻联想到对标的气质（不是抄，是同频） |
| 7-8 | 基本对得上，个别地方偏离 |
| 5-6 | 能看出努力但气质错位明显 |
| < 5 | 完全跑偏，建议重审 |

注意：**评的是"气质同频"不是"形似"**。如果上游产出和对标在镜头/台词上一模一样、但气质偏离，应低分 + 在问题摘要里点出抄袭风险。

## 四、输出规范

### 评分表

每个 skill 按自己的评分维度填表。基础格式：

```markdown
| 项目 | 维度1 | 维度2 | ... | 均分 | 问题摘要 |
|------|-------|-------|-----|------|----------|
| 项 A | 9     | 9     | ... | 8.8  | 无       |
| 项 B | 7     | 8     | ... | 7.6  | 镜头切换方式未说明 |
| ...  |       |       |     |      |          |

**平均分：X.X / 10**
```

### PASS 格式

```markdown
✅ **业务审核：PASS**

[评分表]

整体评价：[1-2 句总结，指出最闪光的地方和仍可优化但不影响通过的小点]
```

### FAIL 格式

```markdown
❌ **业务审核：FAIL**

[评分表]

**需要修改的问题**：

**问题 1**：[一句话定位问题]
- 位置：[如 P03 导演阐述 / 人物设计 > 林书白]
- 当前问题：[具体描述哪里不对]
- 脑内预演：[想象生成/拍摄效果会出什么问题，仅适用于"画面/生成"类审核]
- 修改方向：[具体建议怎么改，避免空话如"加强叙事"]

**问题 2**：...

---
**修改优先级**：
1. 🔴 必须修改（单项低于 6 的）：[列出问题编号]
2. 🟡 建议修改（单项 6-7 的）：[列出问题编号]
```

### "问题描述"的好坏对照

| ❌ 不合格的问题描述 | ✅ 合格的问题描述 |
|------|------|
| "P03 镜头不够好" | "P03 提示词里要求镜头先推到主角面部再环绕走位，同时还要固定机位——这三个运动互相矛盾，建议保留推镜+环绕中的一个，或明确分镜头处理" |
| "建议加强情绪" | "原剧本中 P05 是'女主第一次意识到孤独'的情绪转折，但讲戏本里只写了'她坐在窗边看雨'，缺少眼神/动作的具体描写，建议补一句'她伸手想去摸窗上的雨痕，又顿住缩回'" |
| "颜色不对" | "服化道里林书白的内搭被写成'红色衬衫'，但角色档案里强调他刻意低调，应改为'深灰立领针织衫'" |

**核心**：每个问题必须能让上游 agent 不需要追问就能动手改。

## 五、合规审核的特殊性

`compliance-review-skill` 不评分，只过清单（PASS/FAIL）。原因：

- 合规是"红线"问题，没有"60 分及格"的概念——触碰一条就是 FAIL
- 合规审核需要明确告诉上游"哪条规则、哪个平台、怎么改"，比分数更有用
- 合规问题分两级：🔴 绝对禁止（如真人/版权 IP）、🟡 误杀风险（如服装暴露度）

合规 skill 的输出模板见 `compliance-review-skill/SKILL.md` 自身的"输出规范"段。

## 六、跨集一致性检查（ep02+ 时）

阶段三服化道审核、阶段四音乐审核、阶段五分镜审核都需要做这步：

- **复用素材** 是否正确标注为"已有"，避免重复设计？
- **变体素材** 是否标注了与原版的关联和差异？
- **新设计** 风格是否与已有素材协调？
- **跨集编号** 是否延续（如音乐 M07 不能跳到 M09）？

跨集一致性检查不单独评分，但发现冲突直接 FAIL。

## 七、审核 FAIL 后的循环

1. 审核员产出 FAIL + 修改清单
2. 上游 agent 根据清单修改
3. 审核员**只检查修改的部分**（不重复审已 PASS 的部分）
4. 直到 PASS

**避免无限循环**：如果同一处问题修改 3 次仍未达标，升级给制片人，由制片人决定是降低预期通过、还是降级返工到更上游阶段。
