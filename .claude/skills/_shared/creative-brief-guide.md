# 创作基准方法论（v10.0）

## 什么是创作基准

项目最早产出的一份文档（`assets/story/creative-brief.md`），包含三个层面：

1. **情感蓝图**：观众视角——他们最终感受到什么
2. **导演视野**：作者视角——用什么镜头语言去实现
3. **全片视觉风格基准段**：技术基准——服化道和分镜师直接复制嵌入提示词的那段文字

三者缺一不可。只有情感蓝图没有导演视野，下游agent知道目标但不知道手法；只有导演视野没有基准段，跨资产风格仍然漂移。

---

## 产出时机

**叙事类**：在选题研读和创意采访之后、剧本设定之前，由编剧产出。用户确认后才开始写剧本。

**MV类**：在音乐结构分析之后，由导演产出（没有剧本，以音乐情绪为基础定视觉风格）。

**VJ类**：在项目启动时，由导演直接产出（纯视觉，无叙事）。

---

## 产出格式（存入 `assets/story/creative-brief.md`）

```markdown
# 创作基准 — [项目名]

## 一、情感蓝图

**核心情感**：[观众看完最后一帧，内心应有什么感受？一句话]

**情感节拍**：
1. [开场：此时观众感受到什么]
2. [第一个情绪转折点：...]
3. [中段高潮：...]
4. [情绪落点：...]
5. [片尾余韵：...]

**核心视觉隐喻**：[贯穿全片的视觉符号，如「一双总是空着的手」「越来越近的镜头」]

## 二、导演视野

**作者风格**：[写实克制 / 奇观尺度 / 冷峻精密 / 诗意写意 / 黑色冷硬 等]
**风格锚**（可选）：[可挂一位导演署名，如「Fincher式冷峻精密」「王家卫式情绪光色」]
**拍法核心**：[这个导演怎么拍——具体到镜头行为，如「长焦压缩、人物始终不在画面中心、灯光永远单向」]

## 三、全片视觉风格基准段（服化道和分镜师直接复制使用）

> ⚠️ 这是核心。下面这段文字要被逐字嵌入所有服化道提示词开头和分镜师的【氛围与画质】块。

```
[全片视觉风格基准]
画风：[写实/胶片/3D动画/水墨国风等，1-2句，承接导演视野]
调色板：[2-3个主色调，说明冷暖如何编码叙事，如「暖黄=记忆，冷蓝=现实」]
质感：[胶片颗粒/数字干净/光晕/轻微畸变等]
光逻辑：[主光源类型/方位/对比度/色温走向，如「顶侧光为主，逆光收束轮廓，阴影不压死」]
```

## 四、音乐情绪基调（供音乐总监参考）

**整体情绪色彩**：[如「压抑→爆发→余韵」或「温柔到底不需要高潮」]
**禁忌风格**：[不要什么，如「不要煽情弦乐，不要激励鼓点」]
```

---

## 各 agent 如何使用创作基准

| Agent | 使用方式 |
|---|---|
| 编剧 | 以情感蓝图为剧本创作的北极星，每场戏问「这场服务哪个情感节拍」|
| 导演 | 以导演视野为讲戏风格的底色，讲戏时体现这套作者视野 |
| 服化道 | **每张提示词开头逐字嵌入「全片视觉风格基准段」** |
| 音乐总监 | 以音乐情绪基调为配乐策略的出发点 |
| 分镜师 | **【氛围与画质】块承接全片视觉风格基准段**，不另起一套风格 |

**铁律**：所有 agent 在读取上游资料时，必须先读 `assets/story/creative-brief.md`。这份文档是最高优先级的参照，高于任何单集的具体导演建议。

## 好的基准段示例

**差的写法（太抽象）**：
```
画风：电影感
调色板：温暖
质感：好看
光逻辑：柔和
```

**好的写法（可以直接进提示词）**：
```
[全片视觉风格基准]
画风：写实胶片质感，35mm 手持镜头风格，偶发镜头晃动增加真实感
调色板：主色为焦糖棕和雾蓝，暖色编码过去的记忆，冷色编码当下的孤独
质感：轻微胶片颗粒，阴影处细节保留，不压死暗部
光逻辑：窗光为主要光源，左侧斜入，逆光在人物轮廓形成光晕，不用正面补光
```

## 跨资产一致性的底层原理

服化道生成3张图（角色/场景/道具），分镜师生成50条视频提示词——如果没有共同的视觉基准段，每个agent各自发挥，最终产出必然漂移。

解决方案不是"让AI猜"，而是**把这段文字作为物理插入项**：

```
[全片视觉风格基准] 写实胶片质感，35mm...（来自creative-brief.md）

[人物设定 - 林书白]
...具体角色描述...
```

每张提示词的第一段永远是这段基准，不是装饰，是让所有生成任务共享同一个视觉起点。
