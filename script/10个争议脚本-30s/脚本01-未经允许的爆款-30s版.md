# 脚本01《未经允许的爆款》30s版

## 基本信息
- **时长**：30秒
- **镜头数**：6个
- **核心议题**：帮内向的人"被看见"，是成全还是侵犯？
- **核心角色**：缘缘/喜儿/暖暖
- **场景**：缘缘茶馆、浮云城街道
- **封面大字**：她让他的诗爆火，他却要求立刻下架
- **发布文案**：作品火了，作者为什么不高兴？

## 完整分镜脚本

特写：云朵屏幕上，缘缘的诗点赞数从1000疯狂跳到50000。

缘缘的手猛地按住屏幕，第一次提高音量。

**缘缘**
你凭什么发我的东西？

屏幕字幕浮现：`别人求都求不来的爆火，他为什么不要？`

- **场景**：缘缘茶馆内景，竹制茶桌，柔和自然光透过竹叶窗洒落，茶馆温馨安静
- **角色**：缘缘（青年熊猫，圆润温柔，天然柔和黑眼圈，竹青色围裙，动作慢但此刻眼神锐利）站在云朵屏幕前，手按住屏幕

- **情绪**：震惊→愤怒，音调从低到高
- **音效**：屏幕数字跳动的"嘀嘀"声 + 缘缘按屏幕的"啪"声

茶馆的缘缘！他写得这么好，就该让全浮云城听见！

### 镜头3（7-12s）观点A - 喜儿的委屈

喜儿把不断增长的数据推到缘缘面前，眼神不解。

**喜儿**
十万个人喜欢你，你还不高兴？

缘缘低下头，声音很轻。

**缘缘**
可我没有同意。

喜儿愣住，随后语气变得不服气。

**喜儿**
我是在帮你！没有我，你的诗只会一直锁在抽屉里。

屏幕字幕：`好东西就该被看见，这有错吗？`

**【AI视频生成提示词】**
- **视觉风格**：二维新国风治愈系动画，温暖明亮竹青色调，柔和描边，9:16竖屏
- **场景**：缘缘茶馆内景，竹制茶桌，两个角色对坐，桌上茶杯和云朵屏幕
- **角色**：喜儿（站立姿态，翅膀微张，眼神不解转为委屈）；缘缘（坐姿，低头，手指轻轻握紧）

- **音效**：茶馆安静的背景音 + 喜儿语气从疑惑到激动的变化

诗人缘缘！再写一首失恋的！

缘缘下意识后退，茶杯在手里轻轻发抖。

暖暖从门口挡住外面的人。

**暖暖**
（温和但坚定）
喜欢一个人的作品，不代表拥有这个人。

屏幕字幕：`未经允许的"好意"，还算好意吗？`

**【AI视频生成提示词】**
- **视觉风格**：二维新国风治愈系动画，温暖明亮竹青色调，柔和描边，9:16竖屏
- **场景**：缘缘茶馆内景+门口，暖暖挡在门口背光剪影，缘缘在室内后退

### 镜头5（18-25s）反转 - 删除与授权

喜儿沉默了几秒，低头开始逐条删除自己上传的视频。

删除进度条：100%...80%...50%...完成。

喜儿删完后，抬起头，眼眶也红了。

**喜儿**
（小声）
对不起。

缘缘却从抽屉里拿出一张新诗稿，递到喜儿面前。

**缘缘**
这一首...我想自己发。你能教我吗？

喜儿愣住，接过诗稿。

屏幕字幕：`她删掉了所有，他却给了新的`

**【AI视频生成提示词】**
- **视觉风格**：二维新国风治愈系动画，温暖明亮竹青色调，柔和描边，9:16竖屏
- **场景**：缘缘茶馆内景，茶桌，柔和光线，气氛从紧张转为温暖
- **角色**：喜儿（低头操作云朵屏幕，表情从坚定到哽咽）；缘缘（从抽屉取出诗稿，递给喜儿，眼神温柔但坚定）

- **音效**：删除视频的"嘀嘀"声 + 纸张翻动声 + 安静的呼吸声

画面定格：缘缘的手指悬在按钮上方1厘米处。

屏幕字幕浮现：`没有恶意的公开，还算不算越界？`

**【AI视频生成提示词】**

## 无限画布适配说明

### 布局建议
本脚本为**线性主线**叙事，因为是对话冲突递进，必须按时间顺序展开。建议画布从左到右排列6个节点，用箭头连接。

```
节点1 ──→ 节点2 ──→ 节点3 ──→ 节点4 ──→ 节点5 ──→ 节点6
钩子      闪回      观点A      观点B      反转      收尾
(红)      (灰)      (蓝)       (蓝)       (绿)      (?)
```

### 节点颜色编码建议
- **红色**：钩子（镜头1）— 吸引注意力的起点
- **灰色**：闪回（镜头2）— 时间跳跃标识
- **蓝色**：冲突双方（镜头3-4）— 观点对立
- **绿色**：反转（镜头5）— 情绪转折点
- **问号图标**：开放结局（镜头6）— 留给观众思考

### 核心节点数
6个节点，每个节点对应1个镜头，时长分配：2s/5s/5s/6s/7s/5s = 30s

### 推荐画布模板
**controversy-debate（争议性辩论模板）**
- 适用于有明确正反方观点的短视频
- 画布自动高亮冲突节点（镜头3-4）
- 结尾自动添加评论区引导

### Codex Agent 对接说明
1. **导入方式**：将本脚本的6个镜头标题作为节点名称导入
2. **连线规则**：按镜头顺序单向箭头连接，节点2标注"闪回"，节点5标注"反转"
3. **时长标注**：每个节点附加时长信息（如"镜头1 | 2s"）
4. **衔接点标注**：在箭头上标注衔接方式（如"视觉衔接：屏幕→街道"）
5. **争议问题**：在节点6后添加分支节点"评论区"，引出A/B两个观点节点
