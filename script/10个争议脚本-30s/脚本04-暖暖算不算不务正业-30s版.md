# 脚本04《暖暖算不算"不务正业"？》30s版

**争议议题**：无偿劳动（志愿服务）是否低于有偿工作的价值？不赚钱的付出是否"不务正业"？  
**建议时长**：30秒（严格控制在28-32秒）  
**核心角色**：暖暖、熊出租车司机、缘缘、喜儿  
**场景**：浮云城集市、云桥  
**封面大字**：`"天天做志愿者，你赚了几个钱？"`  
**发布文案**：不赚钱的工作，就等于没有价值？

---

## 一、标准剧本格式（人类阅读版）

**EXT. 浮云城集市 - 傍晚**

集市渐散，暖暖疲惫地帮最后一位老居民搬完东西，橙色马甲上沾满了一天的尘土。胸前的服务徽章在夕阳下有些暗淡。

熊出租车司机靠在车旁，半开玩笑地看着暖暖。

熊出租车司机  
（吊儿郎当）**天天做志愿者，你赚了几个钱？**

暖暖手里的急救包停住。他看着自己磨破的手套，没有立刻回答。

熊出租车司机  
我说真的，早上看你给老太太送早餐，中午调解纠纷，下午陪受伤的小孩……（停顿）可这些又不能换成钱。

快速蒙太奇闪过：凌晨4点，暖暖给独居老人送早餐；上午，他蹲在地上调解两个商户的争吵；下午，他背着受伤的小熊猫去医务站；傍晚，他协调社区活动布置……

屏幕上逐行浮现：  
`凌晨4点：送早餐 - 0元`  
`上午10点：调解纠纷 - 0元`  
`下午3点：陪护受伤小孩 - 0元`  
`傍晚6点：协调活动 - 0元`

暖暖  
（小声）我……我知道不赚钱，但……

缘缘从茶馆方向走来，手里端着两杯竹叶茶。他把一杯递给暖暖。

缘缘  
（平静）所以不能换成钱的，就不算贡献？

熊出租车司机愣了一下，挠挠头。

喜儿的快递车突然停在旁边，她跳下来，风风火火地接话。

喜儿  
（指着暖暖）我能放心送急件，是因为暖暖随时待命接应紧急情况。上周那个走失的小孩，是暖暖找回来的；上上周集市失火，是暖暖组织居民撤离的。

喜儿看向熊出租车司机。

喜儿  
你开出租车赚钱，但你敢说暖暖的工作不如你重要？

熊出租车司机张了张嘴，没说出话。

暖暖却把志愿者徽章摘下，放在手心看着。

暖暖  
（温和但坚定）**我不要被叫伟大，我只要我的劳动也被看见。**

远处，一个小孩跑过来，大喊："暖暖哥哥！"

小孩跑到暖暖面前，仰着头问。

小孩  
暖暖哥哥不领工资，那暖暖哥哥的工作是谁发工资？

所有人沉默。

特写：暖暖手心的徽章，夕阳的光透过徽章上的爱心图案，投射在地面上。

字幕浮现：**没有收入的工作，等于没有价值吗？**

**淡出**
