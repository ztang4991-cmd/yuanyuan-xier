# 《家属签收》｜60 秒四川话版

## EP003-SC001 内外 · 浮云城茶馆门口 · 白天

**成片时长：约 60 秒 ｜ 建议 14 镜（每镜 3.5-5 秒）**
所有角色台词使用四川话口语；动作说明、场记、画面文字不计入台词。

**人物**
- **缘缘（男）**｜圆润拟人熊猫，茶馆掌柜。金色圆框眼镜、米白中式盘扣上衣（金色云纹＋竹叶刺绣）、深色长裤、棕色皮鞋。嘴上讲规矩，心里最先乱。
- **喜儿（女）**｜浮云城快递员。黑色高髻配红发带、发尾蓝紫渐变、额心红印、蓝白红中式快递服、红靴、蓝白羽翼、红色「浮云城快递」斜挎包。全程不动声色，只有羽翼会出卖她。

**场景** 暖色中式茶馆门口。门槛内是茶馆，门槛外是街巷。今日门内右柱**没有卷轴**（空柱，留白）。核心道具是喜儿手上的签收单——一张竖式纸单，三个方框选项与一条空白横线全程必须清晰可读。

---

**0:00-0:04**

**动作：** 茶馆内景。缘缘双爪端着一整盘青花瓷茶具，小心地往门口走，眼镜上蒙了一层茶汽。

缘缘（自言自语，嘴里含着话）：稳当点…稳当点噻…

**0:04-0:09**

**动作：** 喜儿落在门槛外右侧，羽翼收拢。左手托快递盒，右手举着签收单和一支笔。

喜儿（利落）：缘掌柜，签收！

缘缘（两只爪都占着，抬不起来）：爪爪没空噻！你帮我签一哈。

**0:09-0:14**

**动作：** 喜儿低头看单子。特写签收单上半部分：三个并排方框，文字清晰可读——**「□ 本人　□ 家属　□ 代收」**。

喜儿：单子上头三个格。本人、家属、代收。你哪个？

缘缘（隔着茶汽根本没听清，随口）：随便勾嘛！

**0:14-0:19**

**动作：** 喜儿笔尖在三个格上方停了一拍，视线抬起来看了一眼门内的缘缘，然后落笔，勾了**中间那一格**。

喜儿（很轻）：……要得。

[SFX] 笔尖点在纸上，一声清脆的「嗒」。

**0:19-0:24**

**动作：** 缘缘把茶盘放到门内茶桌上，抹掉眼镜上的雾气，凑到门槛前一看，整只熊猫定住。特写单子：「家属」格里一个墨勾。

缘缘（眼镜往下滑）：等哈儿！你勾滴是「家—属」？

**0:24-0:29**

**动作：** 喜儿把单子往前递了半寸，让他看得更清楚，表情毫无波动。

喜儿：你说滴随便勾。

缘缘（耳朵尖开始发红，转移话题）：那…那下头还有一栏噻！

**0:29-0:34**

**动作：** 特写签收单下半部分：一条空白横线，前面印着文字，清晰可读——**「家属关系：＿＿＿＿」**。

缘缘（结巴着念）：家—属—关—系。……你打算写啥子？

**0:34-0:39**

**动作：** 喜儿笔尖悬在空白横线上方，没有落下。她抬头看向门内的缘缘。两人隔着门槛静了一整拍。她背后收拢的羽翼轻轻抖了一下。

喜儿（看着他）：你想我写啥子？

缘缘（耳朵完全竖起来，喉咙里没出声）：……

**0:39-0:44**

**动作：** 缘缘慌忙摘下眼镜，用衣袖来回擦，眼睛不敢看门外。

缘缘（假装忙）：按…按规矩写噻。规矩咋个写，就咋个写。

**0:44-0:49**

**动作：** 喜儿低下头，落笔写了两个字。特写空白横线上出现墨字：**「暂定」**。

**0:49-0:54**

**动作：** 喜儿从快递包取出红色快递印章，在「暂定」下方稳稳盖下。特写印文：**「明日生效」**。

喜儿（盖完，抬头）：暂定。明儿生效。

[SFX] 印章落纸，一声脆响。

**0:54-0:58**

**动作：** 喜儿把快递盒照常放在门槛外右侧地面，把签收单递进门槛内，转身羽翼展开升空。升到一半，回头。

喜儿（飞在半空，回头）：明儿我来确认哈！

**0:58-1:00**

**动作：** 缘缘一个人站在门槛内，双爪捧着那张签收单，耳朵红透。门内茶桌上茶盘里一只茶杯自己晃了一下，「叮」一声磕在盘边。

缘缘（小声，对着空门口）：……确认啥子噻。

**[连续性锁定]**
- 门内右柱**全片空着**（无卷轴），与 ep01 / ep02 区分。
- 签收单：喜儿右手 → 全程由喜儿持有并书写 → 0:54 递进门槛内交到缘缘爪中；缘缘从头到尾**没有在单子上写过一个字**，所有字都是喜儿写的。
- 「□ 本人 □ 家属 □ 代收」三格与「家属关系：＿＿」横线自 0:09 起就在同一张单子上，位置不变。
- 茶盘：缘缘双爪 → 0:19 放在门内茶桌 → 结尾仍在茶桌上（结尾茶杯磕响用的就是这盘）。
- 快递盒：喜儿左手 → 0:54 放在门槛外右侧地面；**全片不进茶馆**。
- 印章：只由喜儿持有，不交给缘缘。
- 门槛为固定轴线：缘缘始终在门内画面左侧，喜儿始终在门外画面右侧；喜儿全片未跨门槛，只有单子越过门槛。
- 情绪线：缘缘从「没在意」→「反应过来」→「乱」；喜儿全程平静，**只有 0:34 那一拍的羽翼轻抖是她唯一的破功**，这一下不能删。
- 不出现猫、草莓、额外角色、现代城市元素。
