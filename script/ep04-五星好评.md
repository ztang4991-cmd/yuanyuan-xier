# 《五星好评》｜60 秒四川话版

## EP004-SC001 内外 · 浮云城茶馆门口 · 白天

**成片时长：约 60 秒 ｜ 建议 15 镜（每镜 3.5-4.5 秒）**
所有角色台词使用四川话口语；动作说明、场记、画面文字不计入台词。

**人物**
- **缘缘（男）**｜圆润拟人熊猫，茶馆掌柜。金色圆框眼镜、米白中式盘扣上衣（金色云纹＋竹叶刺绣）、深色长裤、棕色皮鞋。要面子，更要五星。
- **喜儿（女）**｜浮云城快递员。黑色高髻配红发带、发尾蓝紫渐变、额心红印、蓝白红中式快递服、红靴、蓝白羽翼、红色「浮云城快递」斜挎包。有一说一，绝不留情。

**场景** 暖色中式茶馆门口。门槛内是茶馆，门槛外是街巷。门内右柱今日挂新卷轴，画面文字清晰可读：**「好评五星 返现五元」**。另一核心道具：一块中式木牌样式的评价板（充当"点评页面"），板面星星与文字全程必须清晰可读。

---

**0:00-0:04**

**动作：** 缘缘挂好卷轴，后退一步，双爪互相搓了搓，满意点头。

缘缘（得意）：五星好评，返现五块！

**0:04-0:08**

**动作：** 喜儿落在门槛外右侧，羽翼收拢，双手托着快递盒。

喜儿（利落）：缘掌柜，到付三十。

**0:08-0:13**

**动作：** 缘缘飞快把三十钱递出门槛，另一只爪顺势把那块木质评价板也塞了出去。

缘缘（付完钱，顺手推销）：付咯付咯——顺手给个五星噻！

**0:13-0:18**

**动作：** 喜儿接过评价板，低头看了两秒，抬手在板上点了四颗星，第五颗留空。特写：**四颗满星＋一颗空星**。

喜儿：四星。

缘缘（原地跳起来）：为啥子扣我一星？！

**0:18-0:23**

**动作：** 喜儿抬起红靴的靴尖，点了点两人之间那道木门槛。

喜儿（平静）：门槛恁个高，拖箱子费劲。

缘缘（急得直摆爪）：五块！返你五块！补成五星噻！

**0:23-0:28**

**动作：** 喜儿收下五块，抬手把第五颗星点满，然后**没有停手**，继续在板下方的空白处写字。特写：五颗满星。

喜儿（收钱）：要得。

缘缘（松一口气，凑到门槛边看）：巴适！

**0:28-0:34**

**动作：** 缘缘隔着门槛念板上刚写的评语。特写评价板下方墨字逐字浮现：**「老板人不错，就是抠。」**

缘缘（念，脸一亮）：老—板—人—不—错……

缘缘（继续念，整张脸垮掉）：……就—是—抠。

**0:34-0:39**

**动作：** 缘缘慌忙又摸出五块钱，从门槛上方硬塞过去。

缘缘（急）：再返五块！后头那三个字删咯！

**0:39-0:44**

**动作：** 喜儿没有接钱，只是把评价板转过来，正对着缘缘。特写板面右下角一行小字：**「评价已发布，不可修改」**。

喜儿：评价发咯，改不成。

缘缘（傻眼）：那咋个办？！

**0:44-0:48**

**动作：** 喜儿用笔尖点了点评价板最下方另一处，那里有一个中式木刻小按钮样式的位置，文字清晰可读：**「追评」**。

喜儿：只能追评。

缘缘（眼睛一亮，一把把五块塞进她手里）：那你追一条好滴噻！

**0:48-0:53**

**动作：** 喜儿收钱，落笔写追评。缘缘趴在门槛内侧，尾巴翘着等。特写板面新一行墨字：**「追评：老板返现两次。」**

缘缘（念完，僵住）：……这句更凶噻！

**0:53-0:57**

**动作：** 缘缘扑到右柱前，双爪一把把卷轴扯下来。

缘缘（崩溃）：这条规矩，先扯咯！

**0:57-1:00**

**动作：** 喜儿站在门外，已经抬手在评价板上写下一行。缘缘举着扯下的破卷轴回头。特写板面第三行墨字：**「再追评：返现牌牌撕咯，扣一星。」**

喜儿（一边写一边说）：再追评——返现牌牌撕咯，扣一星。

缘缘（举着破卷轴，声音破音）：喜儿——！

---

**[连续性锁定]**
- 卷轴：门内右柱 → 0:53 由缘缘双爪扯下 → 结尾仍在缘缘爪中。
- 评价板：缘缘门内爪中 → 0:08 递出门槛 → **此后全程留在喜儿手里，直到结尾都没还给缘缘**。这是本集最重要的一条连续性——板子回不来，所以他改不了评价。
- 评价板文字为**累加式**，只增不减，每次露出必须包含之前所有内容：
  1. 0:13 四星（四满一空）
  2. 0:23 五星（五满）
  3. 0:28 五星 ＋「老板人不错，就是抠。」
  4. 0:48 五星 ＋ 上句 ＋「追评：老板返现两次。」
  5. 0:57 五星 ＋ 上两句 ＋「再追评：返现牌牌撕咯，扣一星。」
- 钱：缘缘共付三次（0:08 到付三十 / 0:18 返现五块 / 0:44 再返五块）；0:34 那次**被拒收，钱要回到缘缘爪里**，不能算进喜儿手上。
- 快递盒：喜儿手中 → 放在门槛外右侧地面；**全片不进茶馆**。
- 笔与印章：只由喜儿持有，不交给缘缘；本集不盖「明日生效」章（留给 ep02 / ep03）。
- 门槛为固定轴线：缘缘始终在门内画面左侧，喜儿始终在门外画面右侧；喜儿全片未跨门槛。
- 不出现猫、草莓、额外角色、现代城市元素、真实手机／屏幕（评价板一律做成中式木牌质感）。
