| `01_剧本设定/` `02_故事大纲/` `03_角色开发/` `04_分集剧本/` `04_完整剧本/` | 编剧 agent **从零创作**（路径 A）时的版本管理区（v01/v02…） | **空**。本项目是路径 B，用户直接提供了剧本，这些阶段未经过；设定/角色已直接提取到 `assets/story/` |
