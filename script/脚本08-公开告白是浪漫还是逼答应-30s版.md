# 脚本08：《公开告白，是浪漫还是逼答应？》30秒版

**争议议题**：当众告白会不会把拒绝成本全部转嫁给被告白者？  
**建议时长**：30秒  
**核心角色**：缘缘、喜儿、围观居民（群演）  
**场景**：七夕鹊桥  
**封面大字**：`全城都喊"答应他"，她却后退了`  
**发布文案**：「公开告白到底是勇敢，还是情感施压？」

---

## 三、画布适配说明

### 3.1 画布流程图骨架

```
[极强钩子：喜儿被围观] 
        ↓ 
[冲突核心A：缘缘走来，喜儿后退] 
        ↓
[观点碰撞A：缘缘叫停镜头] 
        ↓
[观点碰撞B：人群散去，只剩两人] 
        ↓
[快速反转：缘缘给选择权] 
        ↓
[争议收尾：勇敢不该由为难买单]

主线结构：线性叙事（单链条）
情绪曲线：压迫（镜1-2）→ 意外转折（镜3）→ 舒缓（镜4）→ 真诚（镜5）→ 温暖开放（镜6）
```

### 3.2 关键衔接点标注

| 衔接点 | 过渡类型 | 具体机制 |
|--------|---------|---------|
| 镜1→镜2 | 视觉+对白 | 人群喊声延续 + 喜儿视线转向缘缘 |
| 镜2→镜3 | 动作 | 缘缘脚步声停止 + 转身动作 |
| 镜3→镜4 | 视觉+音效 | 灯光逐一熄灭声音 + 人群散去脚步声 |
| 镜4→镜5 | 环境音 | 嘈杂→寂静的环境音对比 |
| 镜5→镜6 | 动作 | 缘缘低头动作作为情绪转折点 |

### 3.3 画布节点属性

**节点1（钩子）**：
- 类型：冲突起点
- 情绪：紧张/压迫
- 视觉权重：高（需要大尺寸展示喜儿被围观的压力）

**节点2-3（冲突呈现）**：
- 类型：压力升级
- 情绪：不安→意外
- 视觉权重：中高（双人互动+群演反应）

**节点4（观点碰撞）**：
- 类型：价值观表达
- 情绪：温柔/尊重
- 视觉权重：中（灯光熄灭过程需要视觉呈现）

**节点5-6（反转+收尾）**：
- 类型：情感高潮+开放式结局
- 情绪：脆弱→温暖
- 视觉权重：高（核心台词+争议问题字幕）

### 3.4 Codex Agent 对接建议

**推荐布局**：线性主线（vertical flow）

**理由**：
1. 本脚本是单线叙事，无分支情节
2. 情绪曲线呈阶梯式递进（压迫→转折→舒缓→温暖）
3. 每个镜头依赖上一镜头的情绪积累，不适合并行展示

**核心节点数量**：6个

**画布模板类型**：情感议题型（线性叙事+开放式结局）

**特殊标注**：
- 镜头3的"缘缘转身"是全片情绪转折点，建议在画布中用高亮/特殊标记
- 镜头6的争议问题字幕需要在画布中单独标注为"用户互动触发点"

## 六、评论区站队设计

**A. 当众表达更有仪式感**  
理由：真心就该大声说出来，藏着掖着反而不真诚

**B. 私下告白才尊重被告白者**  
理由：公开告白把拒绝成本转嫁给对方，是情感绑架

**中立观察**：  
缘缘的做法（安排仪式但保护对方选择权）是否是最优解？
