## 1. 这是什么

一个由 5 个 AI agent 组成的影视制作团队（编剧/导演/服化道/音乐总监/分镜师），从**选题或剧本**出发，自动协作产出三套**工业级可直接使用**的提示词：

- 🎬 **分镜提示词** → 喂给 Seedance / 可灵 / Runway 生成视频
- 🎨 **视觉提示词** → 喂给 Nano Banana Pro / 即梦生成参考图
- 🎵 **音乐提示词** → 喂给 Suno 生成音乐

你只需要：放素材 → 输入指令 → 拿提示词 → 自己去 AI 工具生成 → 剪辑成片。

🎯 **v5.0 核心能力**：内置 7 大短视频平台规律对照（抖音/快手/小红书/视频号/B站/YouTube/TikTok）+ 受众参与度审视——所有产出都为"在目标平台被看到"服务，不只是"获奖短片"。

## 3. 项目类型对照表

| 项目类型 | 路径 | 介入模式 | 音乐策略 | 备注 |
|---|---|---|---|---|
| **短片**（3-5 分钟） | A 或 B | key_node（默认）| 极简型（1 首主题曲）| 大部分情况 |
| **短剧**（多集） | A | key_node | 标准型 | 编剧采访时选"短剧模式" |
| **MV / 音乐驱动** | B（先放歌词）| key_node | 主题曲先做 | 把歌词放 input/剧本/ |

| **改编（小说→片段）**| B | full_control | 极简型 | 重要项目精雕细琢 |
| **批量出片** | A | autonomous | 标准型 | 让团队全自动跑 |

## 4. 提示词怎么用（最重要的一节）

### 拿到交付清单后的标准工作流

```
第 1 步：生成参考图（先做这个，因为后面要用）
   assets/visual/character-prompts.md  →  Nano Banana Pro / 即梦
   assets/visual/scene-prompts.md      →  Nano Banana Pro / 即梦
   ↓
   保存所有参考图到本地

第 2 步：生成视频片段
   outputs/<集数>/02-seedance-prompts.md  →  Seedance / 可灵 / Runway
   ↓
   每条提示词上传"对应的人物图 + 场景图"作为参考
   注意素材对应表里 @图片1/@图片2... 的编号顺序

第 3 步：生成/获取音乐（可与第 2 步并行；音乐采用「双文档」体系）

   📄 原创音乐（少而精，喂给 Suno 自己生成）
   assets/music/music-design.md  →  Suno
   - 复制 ━━━ 复制这里到 Suno ━━━ 之间的内容粘贴
   - 人声歌曲含 [Verse]/[Chorus] 等 meta-tag
   - 纯配乐含 [Instrumental] 标记
   - 对应歌词在 assets/music/lyrics-drafts.md（三版风格的终选稿）

   📄 市面已有音乐（多而精，去音乐平台直接搜）
   assets/music/music-recommendations.md  →  网易云 / QQ 音乐 / Spotify / YouTube Music 等
   - 每条推荐含：多平台搜索名 + 服务于本项目的理由 + 推荐使用片段（时间码）+ 版权提示
   - 适用场景：场景气氛、转场配乐、片尾曲——这些位置用市面成品比 Suno 原创更省力且效果稳定
   - 商用项目：版权提示中标注"商用需采购"的曲目，先去版权方/CC 授权目录确认再用

   选择原则：主题曲/记忆点 OST 用原创（让 Suno 写专属歌）；氛围/场景配乐用市面推荐（直接搜现成的）。

第 4 步：剪辑
   导出所有视频片段、音乐
   按 outputs/<集数>/01-director-analysis.md 的剧情顺序剪
   按 outputs/<集数>/02-seedance-prompts.md 的镜头时长建议参考节奏
   音乐分轨：原创主题曲 + 市面氛围曲分轨混音，便于单独调音量
```

### 关键技巧

- **视频时长不必精确对齐音乐**：视频以 15 秒为单位生成，音乐让 Suno 完整生成，剪辑时 trim/loop 即可
- **参考图很重要**：分镜提示词里的 `@图片1` 等引用必须有真实参考图，否则 Seedance 生成质量差
- **多次生成取最佳**：Suno/Seedance 都建议同一提示词生成 3-5 次选最佳
- **歌词三版要选一**：音乐总监会停下等你选 A/B/C，回复字母即可
- **视频生成时不要在提示词里加配乐描述**：视频 AI 不会输出配乐，写了会和后期 Suno/市面音乐双轨冲突——配乐统一在剪辑期叠加

## 5. 介入模式怎么选

启动时会问你 1/2/3，按以下场景选：

| 模式 | 适合 | 行为 |
|---|---|---|
| **1. 全自动** | 不重要的项目、批量产出、你很忙 | 全程不停，仅在歌词三版时停一下让你选 |
| **2. 关键节点**（默认）| 大部分项目 | 每个大阶段完成后等你确认才进入下一阶段 |
| **3. 全程介入** | 重要作品、需要精雕细琢 | 子步骤都停下问你 |

中途想改？输入 `~mode`（下一阶段生效）或 `~mode 立即`（立刻重启当前阶段）。

## 7. 跨集与多集项目

### 多集复用机制

第 2 集开始，团队会**自动判断**哪些人物/场景是新的、哪些是复用的。
- **新增** → 服化道会重新设计提示词
- **复用** → 直接引用已有的，不重复设计
- **变体**（如冬装版） → 在原版基础上加变化说明

### 全复用集（罕见但要知道）

如果某一集所有人物/场景/音乐都复用前集，团队会写一个空标记块（如 `## ep05（本集全部复用 ep04，无新增）`），保证路由顺畅。

### 修改某一集

```
想重做 ep02 的服化道：
   删除 assets/visual/character-prompts.md 里的 ## ep02 区块
   输入 ~design ep02
```

## 8. 故障排除

| 现象 | 原因 | 解决 |
|---|---|---|
| 编剧采访问太多次还没结束 | 你的回答信息密度低 | 一次回答多个问题，或换 full_control 模式逐步推进 |
| 导演审核反复不通过 | 上游产出确实有问题 | 看 FAIL 反馈针对性修改，或手动 ~start 重新触发 |
| Suno 生成的歌不像唐恬风 | Suno 模型理解 Style 描述有限 | 用更具体的乐器/BPM/年代词，而非"唐恬风"三个字 |
| Seedance 视频里人物不对 | 参考图没传或编号错 | 检查 @图片N 的编号顺序，重新上传对应参考图 |
| 进度卡在某个阶段 | 缺少分集标签 | 检查 assets/ 下是否有该集的 `## epXX` 标签 |
| 想完全重来 | 项目跑歪了 | 删除 script/、outputs/、assets/ 内容（保留 .gitkeep） |

1. 整个项目目录复制到 `archive/<项目名>/` 备份

## 10. 进阶技巧

### 让团队产出更"高级"
- 在 `input/参考/` 里多放高品质参考素材（豆瓣高分电影截图、风格图、参考歌曲）
- 编剧采访时**多说"不要什么"**（拒绝套路化的具体描述比"要什么"更有效）
- 关键场景用 full_control 模式逐子步骤把关

### 引导编剧方向
- 选题文件里写明"参考作品"和"风格基调"
- 采访时直接说出参考的导演/作家/编剧名字（编剧会消化风格不直接抄）

### 修改单个 agent 的产出
- 编剧产出：直接编辑 `script/` 下的版本文件，输入 `~定稿` 晋升
- 导演产出：删除 `outputs/<集数>/01-director-analysis.md`，输入 `~start <集数>` 重新生成
- 服化道：删除 `assets/visual/` 下对应集数标签块，输入 `~design <集数>`
- 音乐：删除 `assets/music/` 下对应集数标签块，输入 `~music <集数>`
- 分镜：删除 `outputs/<集数>/02-seedance-prompts.md`，输入 `~prompt <集数>`

### 想要质量综合报告
分镜完成后会自动生成 `outputs/<集数>/00-quality-report.md`，包含全片各维度评分和改进建议。

## 11. 哲学

这个团队的核心信条：

- **少即是多**：能用静默说的不用音乐说，能用一个镜头说的不用三个
- **细节即灵魂**：90% 的高级感来自被认真对待的细节
- **反流水线**：拒绝套路化处理，每一个镜头都要有存在的理由
- **情绪优先**：技术服务于情感，不为炫技而炫技
- **整体感**：从第一帧到最后一帧，每一秒都属于同一个作品的呼吸

如果某次产出让你觉得"还行"但不"惊艳"——回头看是不是这五条没做到。
