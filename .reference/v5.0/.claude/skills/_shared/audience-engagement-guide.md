# 受众参与度指南（流量审视方法论）

> 本配置最终目的是让用户做出**被看到**的视频——而不只是被评委欣赏的"获奖短片"。
> 本文是所有 agent 在产出前后都应参考的"流量审视总闸"，与 `ai-generation-constraints.md` 并列。
>
> **谁需要查这份文件**：
> - 编剧在采访阶段确认目标平台 / 受众画像时
> - 导演在讲戏阶段评估开场钩子是否符合平台前 3 秒规律时
> - 服化道在选视觉风格时评估是否符合目标受众审美时
> - 音乐总监在选音乐策略时评估是否符合平台听觉习惯时
> - 分镜师在写提示词时评估镜头节奏是否适配竖屏/横屏时
> - 4 个业务审核 skill 在评判「受众适配性」维度时

---

## 一、核心理念

**流量不是结果，是被设计的。**

但"被设计"不等于"低俗化"——是**用观众听得懂的语言讲你想讲的故事**。

一个好的"流量审视"应该让创作者问自己 5 个问题：

1. 这个故事我想讲（艺术追求）
2. 但谁在看（目标受众）
3. 在哪看（目标平台）
4. 在什么状态下看（注意力 / 情绪 / 设备 / 时机）
5. 我怎么讲才能既忠于自己又被他们看到（设计平衡点）

> **底层原则**：[创作五原则 #9 为流量服务] ≠ 牺牲艺术，而是"艺术的呈现方式必须考虑被看到的可能性"。

## 二、观众心理学基础

### 2.1 马斯洛需求层次（应用于内容设计）

观众在不同需求层次时，会被不同类型的内容打动：

| 需求层 | 观众状态 | 适配内容类型 |
|--------|---------|-------------|
| **生理需求** | 累、饿、困、刚下班 | 治愈、ASMR、美食、慢节奏、放松 |
| **安全需求** | 焦虑、不安、对未来恐惧 | 励志、答案、确定性、生活技巧、避坑 |
| **归属需求** | 孤独、想被理解、找同类 | 共鸣、群体认同、亚文化、"懂我" |
| **尊重需求** | 想被看到、想被认可、要面子 | 装 X、身份认同、阶层符号、奢华 |
| **自我实现** | 想成长、想超越、追求意义 | 深度内容、哲思、艺术、创造、突破 |

**应用方法**：
- 写给一个**具体的人**（不是"年轻人"，而是"25 岁北漂打工人，加班后 11 点回到合租房刷手机"）
- 这个人**正在哪一层**？你的内容打中那一层吗？
- 不同需求层的观众在不同时段刷视频——你的内容发布时段也要匹配

### 2.2 注意力经济学（每秒都在和"划走"赛跑）

短视频时代的观众有 3 种状态：
- **打开就划**（最常见）：前 0.5-3 秒不抓人就划走
- **看一会儿就划**（中等）：前 5-15 秒没新东西就划走
- **从头看到尾**（少见但是目标）：完播

**完播率 ≈ 平台分发量**。这是几乎所有短视频平台的核心算法基准。

### 2.3 多巴胺设计（让观众"上瘾"看完）

好的视频在多个时间点触发多巴胺：

| 触发器 | 时机 | 设计 |
|--------|------|------|
| **好奇** | 第 0-3 秒 | 一个奇怪的画面/反差话/未交代的悬念 |
| **悬念** | 中段每 5-10 秒 | "接下来会发生什么"的钩子 |
| **反差** | 任意位置 | 期待 vs 实际、外表 vs 内心、平静 vs 爆发 |
| **共鸣** | 中段到结尾 | "这说的不就是我？"瞬间 |
| **金句** | 高潮位置 | 一句能被截图/收藏/分享的台词 |
| **反转** | 结尾 | 推翻前面的认知 |
| **余韵** | 结尾后 | 留一个让观众想 1 分钟的画面/话 |

## 三、平台规律对照表（核心干货）

不同平台的爆款逻辑完全不同。本表是创作团队的必备认知。

### 3.1 抖音（短视频之王）

| 维度 | 参数 |
|------|------|
| 视频比例 | 9:16 竖屏（强制） |
| 前几秒决定划走 | 0.5-1 秒 |
| 前几秒必爆点 | 3 秒 |
| BGM 策略 | 跟随平台热门 BGM（流量加成） |
| 主流时长 | 15s / 30s / 1 分钟 |
| 算法偏好 | 完播率 + 点赞 + 评论 + 分享 + 关注，五率合一 |
| 内容偏好 | 强反差/反转/爽点；快节奏；情绪直接 |
| 文字处理 | 字幕全程必需（80% 用户静音刷视频）|
| 黄金时段 | 11:00-13:00、17:00-19:00、21:00-23:00 |

**爆款公式**：前 3 秒钩子 + 每 5 秒一个新刺激 + 结尾反转 + 强情绪共鸣点

### 3.2 快手（下沉市场之王）

| 维度 | 参数 |
|------|------|
| 视频比例 | 9:16 竖屏 |
| 前几秒决定划走 | 1-2 秒（略宽松于抖音）|
| 内容偏好 | 强地域感、接地气、真实、不装；主角魅力优先 |
| 受众画像 | 下沉市场（三四线 + 县城）|
| 算法偏好 | 完播 + 评论 + 老铁互动 |
| 文字处理 | 字幕必需 |
| 主流时长 | 30s / 1-3 分钟 |

**爆款公式**：真实人物 + 强烈情绪 + 一句金句 + 共鸣

### 3.3 小红书（治愈+生活化）

| 维度 | 参数 |
|------|------|
| 视频比例 | 9:16 竖屏（主流） / 3:4 |
| 封面 + 标题 | 决定打开率（远比视频本身重要） |
| 内容偏好 | 治愈 / 情感 / 生活化 / 美感 / 实用 |
| 节奏 | 慢热可以（用户进来就有耐心看完）|
| 算法偏好 | 收藏率 + 评论 + 关注（实用价值优先）|
| 主流时长 | 1-3 分钟 |

**爆款公式**：精美封面 + 钩子标题（"必须知道的 5 件事" / "我后悔的 3 件事"）+ 实用价值或情绪治愈

### 3.4 视频号（强社交属性）

| 维度 | 参数 |
|------|------|
| 视频比例 | 横竖均可 |
| 算法偏好 | **分享是关键**（基于微信社交关系链分发）|
| 内容偏好 | "想分享给朋友 / 群"的内容 |
| 主流时长 | 1-5 分钟 |
| 受众 | 中老年用户占比高、家庭场景 |

**爆款公式**：让观众觉得"必须发给爸妈/朋友"——情感共鸣 / 价值传递 / 身份认同 / 信息传播

### 3.5 B 站（深度内容 + 知识密度）

| 维度 | 参数 |
|------|------|
| 视频比例 | 16:9 横屏（主流） / 9:16 竖屏（动态/番剧）|
| 前几秒决定划走 | 5-15 秒（用户耐心最强的平台）|
| 内容偏好 | 知识 / 创意 / 深度 / 二次元 / 长视频 |
| 算法偏好 | 完播率 + 三连（点赞投币收藏）+ 弹幕 |
| 主流时长 | 5-30 分钟（中长视频）|
| 受众 | 学生 / 年轻白领 / 二次元爱好者 |

**爆款公式**：信息密度 + 创意 + 弹幕互动设计 + "值得三连"

### 3.6 YouTube（国际化 + 长尾流量）

| 维度 | 参数 |
|------|------|
| 视频比例 | 16:9 横屏（主流） / 9:16 Shorts |
| 算法偏好 | 完播率 + 订阅 + 后续点击 |
| 内容偏好 | 全球化、信息密度、深度内容、教学 |
| 主流时长 | 8-15 分钟（长视频区间最佳） / 60s 以内（Shorts）|
| 长尾价值 | 高（视频可以一直被搜到，常青）|

**爆款公式**：明确价值（教程/分析/故事）+ 优质 Thumbnail + 信息密度高

### 3.7 TikTok（国际短视频）

| 维度 | 参数 |
|------|------|
| 视频比例 | 9:16 竖屏 |
| 前几秒决定划走 | 0.5 秒（最严苛）|
| 内容偏好 | 反差 / 反转更极致 / 全球文化共鸣 |
| 算法偏好 | 完播 + 互动 + 分享 |
| 主流时长 | 15-60s |
| 受众 | 全球年轻用户 |

**爆款公式**：抖音公式 ×1.5（反差更强、反转更急、节奏更快）

### 3.8 院线 / 影展（非短视频路径）

| 维度 | 参数 |
|------|------|
| 视频比例 | 16:9 / 2.35:1 / 1.85:1 |
| 关注点 | 艺术性优先于流量 |
| 评判维度 | 剧本深度 / 摄影 / 表演 / 立意 / 创新 |
| 适用 | 影节投稿、独立电影、艺术片 |

**爆款公式**：本路径不追流量，追评委 + 影评人认可——按 `_shared/film-rating-rubric.md` 的 8 维评分优先级

## 四、完播率优化（最关键单项指标）

### 4.1 三段式完播设计

```
前 3 秒：钩子段（让人不划走）
中段：钩子链（每 5-10 秒一个新刺激）
结尾：钩子收（反转 / 悬念 / 余韵）
```

### 4.2 前 3 秒钩子设计清单

每条短视频的前 3 秒必须包含至少 1 种：

- **反差话**：「我恨这份工作」+ 含泪的眼神
- **奇怪动作**：主角在做一件看起来不合理的事
- **未交代悬念**：观众立刻产生"为什么？"
- **意外画面**：观众第一眼"咦？"
- **强情绪**：直接给到一个极端情绪
- **金句**：一句直击人心的话
- **冲突**：两个对立的事/人/态度同框

### 4.3 中段钩子链设计

每 5-10 秒安插一个"新东西"：
- 新画面（场景切换 / 镜头切换）
- 新台词（金句 / 反转话 / 悬念话）
- 新信息（剧情推进 / 真相揭示）
- 新情绪（情绪转折）

**反例（必划走）**：长时间一个固定镜头 / 同一情绪持续 30 秒 / 反复说同一件事

### 4.4 结尾设计（决定二刷率 + 分享率）

4 种有效结尾：
- **反转型**：推翻前面认知（"原来 TA 是..."）
- **悬念型**：留一个未解的钩子（"下集见"）
- **余韵型**：一个安静的画面 + 一句金句（"看完想 1 分钟"）
- **引导型**：直接问观众（"你会怎么做？评论区告诉我"）

## 五、互动率优化

完播是流量基础，互动是流量放大器。

### 5.1 评论设计

**让观众想评论的几种设计**：
- **留可争议点**：开放性问题、有争议的观点
- **留待解释**：故意留一个"看不懂的点"让观众讨论
- **留缺口**：故事没讲完，引导观众脑补
- **直接邀请**：结尾问"你怎么看 / 你会怎么做 / 评论区聊聊"

### 5.2 点赞设计

**让观众想点赞的瞬间**：
- 情绪共鸣峰值（"这说的就是我！"）
- 高级感画面（"美得想保存"）
- 金句（"这话说得太好了"）
- 大笑点（"哈哈哈"）

### 5.3 收藏设计

**让观众想收藏的内容**：
- 实用价值（教程、清单、技巧）
- 可复习内容（深度知识、长文档）
- 美好画面 / 治愈片段（"以后重温"）

### 5.4 分享设计（最高级别）

**让观众觉得"必须发给某人"**：
- **情感共鸣**：发给同样有这感受的朋友
- **价值传递**：发给需要这个信息的人
- **身份认同**：发给同类（"我们这种人都懂"）
- **信息冲击**：发给应该知道的人

**短视频流量的金字塔**：
```
关注（最稀有）
  ↑
分享（高价值）
  ↑
收藏 / 评论（中价值）
  ↑
点赞（基础互动）
  ↑
完播（流量基础）
```

## 六、受众画像设计（写给 1 个具体的人）

**不要写给"年轻人"——要写给一个具体的人。**

### 6.1 画像模板

每个项目在编剧采访阶段确定：

```markdown
**目标观众画像**：

- 名字（虚构）：小米
- 年龄：25-28 岁
- 性别倾向：女性为主，但男性观众也欢迎
- 地域：一二线城市
- 职业：普通白领 / 互联网新人
- 收入：1-2 万 / 月
- 情感状态：单身 / 异地恋 / 刚分手
- 生活状态：合租 / 加班多 / 周末睡到自然醒
- 平时刷什么：抖音 / 小红书 / B 站
- 看视频的场景：地铁通勤 / 加班后躺床上 / 周末早上
- 看视频的需求：解压 / 治愈 / 想被理解 / 想找共鸣
- 最讨厌的内容：说教 / 装 / 强行煽情
```

### 6.2 用画像审视产出

每个产出后问自己 3 个问题：

1. 小米看到这一段会不会划走？（前 3 秒）
2. 小米会不会评论 / 点赞 / 收藏 / 分享？（互动设计）
3. 小米会不会想推荐给闺蜜？（分享潜力）

如果都是"不会"——回去改。

## 七、平台合规与流量底线

流量不能突破合规底线——具体红线见 `compliance-review-skill`。

**最常见的"为流量牺牲合规"陷阱**：
- ❌ 标题党到诈骗（"惊呆全网！我...")
- ❌ 暴力 / 色情擦边（短期高流量长期被限流甚至封号）
- ❌ 蹭未授权 IP（被原创方投诉下架）
- ❌ 蹭明星名人（违反平台真人保护）
- ❌ 诱导评论 / 诱导关注（违反平台规则）

**正确做法**：在合规框架内做创意优化——好钩子 vs 标题党的边界是「真实性」。

## 八、本指南的使用时机

### 8.1 编剧采访阶段

- 确认目标平台 + 受众画像（必问项，写入 `script-settings.md`）
- 根据目标平台选择剧本节奏（抖音节奏 vs B 站节奏完全不同）
- 根据受众画像选择主题 + 情感锚点

### 8.2 导演讲戏阶段

- 第一个剧情点（开场）按平台前 3 秒规律设计钩子
- 每个剧情点之间的过渡按平台节奏决定密度
- 情绪/音乐方向考虑平台主流音乐风格

### 8.3 服化道设计阶段

- 视觉风格符合目标受众审美（不要为"显得专业"做小众美学）
- 画面构图考虑竖屏 vs 横屏
- 关键道具特写按平台习惯设计（抖音偏强反差 / 小红书偏精致美感）

### 8.4 音乐总监阶段

- 抖音 / TikTok：考虑平台热门 BGM 类型作为参考
- B 站：原创性优先（B 站用户对烂大街 BGM 敏感）
- 院线 / 影展：纯艺术性，不考虑平台音乐潮流

### 8.5 分镜师阶段

- 镜头比例严格匹配平台（不要拿横屏提示词给竖屏平台用）
- 镜头节奏匹配平台（抖音密集 vs B 站舒缓）
- 字幕区域避让平台 UI（抖音底部 100px 是评论入口）

### 8.6 4 个审核 skill 评判时

- 加一个统一的「受众适配性」（1-10 分）评分
- 评分标准：本产出是否服务于用户标注的目标平台 + 目标受众？

## 十、一句话总结

> 流量是设计出来的，不是碰运气来的。设计的方法 = 把"我想讲的"和"他们想看的"找到一个交集点。
>
> 这个交集点 = 你的爆款。
