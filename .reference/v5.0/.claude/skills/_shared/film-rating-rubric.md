# 电影打分参考（导演审核的补充视角）

> 行业公开打分维度的提炼。导演在做业务审核时，可作为"补充视角"参考——不重复评分，但能帮助识别 AI 视频项目容易忽略的维度。
>
> 由 3 个业务审核 skill（script-analysis-review / art-direction-review / seedance-prompt-review）共享调用。
> 与 `review-methodology.md` 第三节"评分规则"配合使用。

---

## 行业 8 大评分维度（电影学院/影评人通用）

下列 8 维度 + 每维 1-10 分制，是行业评价一部完整影片的标准框架。
本项目是 AI 视频生成，不需要照搬全部 8 维，但**可以借鉴每个维度的"评判要点"**，让审核员避免只看技术细节、忘了整体观感。

| 维度 | 核心评判要点 | 对应到本项目的审核阶段 |
|------|------------|---------------------|
| 1. 剧本 | 故事是否有力？人物是否立得住？冲突是否成立？ | 阶段一编剧 + 阶段二讲戏本 |
| 2. 导演 | 视觉调度是否服务于叙事？节奏是否到位？整体气质是否统一？ | 阶段二导演分析 + 阶段五分镜 |
| 3. 表演 | 表演是否真实？情绪传递是否到位？（AI 视频：人物动作是否自然） | 阶段五 Seedance 提示词 |
| 4. 摄影 | 构图是否考究？光影是否有设计？镜头语言是否丰富？ | 阶段三服化道 + 阶段五分镜 |
| 5. 剪辑 | 节奏是否流畅？场景过渡是否自然？信息密度是否合理？ | 阶段二讲戏本节拍 + 阶段五分镜衔接 |
| 6. 美术 | 服化道是否服务于人物/世界观？视觉风格是否统一？ | 阶段三服化道 |
| 7. 音乐 | 配乐是否服务于情绪？是否有"一发入魂"的瞬间？ | 阶段四音乐设计 |
| 8. 创新性 | 创意是否新颖？设定是否独特？是否避开了套路？ | 阶段一选题 + 全程贯穿 |

---

## 每个维度的"打分标尺"

### 维度 1：剧本

| 分段 | 表现 |
|------|------|
| 9-10 | 故事独特、人物立体、冲突自然、结尾有余韵 |
| 7-8 | 故事完整、人物清晰、有亮点但稍套路 |
| 5-6 | 故事勉强成立，但人物或冲突有明显缺陷 |
| 1-4 | 故事讲不通、人物纸片化、冲突不成立 |

**审核器关注**：剧本医生反馈是否到位？戏剧动作是否完整？

### 维度 2：导演（影视维度，对应阶段二）

| 分段 | 表现 |
|------|------|
| 9-10 | 每个剧情点的讲戏都让人脑中浮现清晰画面；节奏起伏有设计；上承下启自然 |
| 7-8 | 讲戏整体到位，但有些剧情点稍模糊或上承下启薄弱 |
| 5-6 | 部分剧情点讲戏不够具体，下游不容易拍 |
| 1-4 | 讲戏笼统空泛，下游需要自己脑补 |

### 维度 3：表演（对应 AI 视频的"动作自然度"）

AI 视频里没有真人表演，但有"角色动作生成"。

| 分段 | 表现 |
|------|------|
| 9-10 | 每个动作描述具体到肢体细节，符合 1 拍 ≈ 2.5 秒密度；Seedance 大概率能生成自然动作 |
| 7-8 | 动作描述基本到位，但有 1-2 处可能让 Seedance 生成动作糊掉 |
| 5-6 | 多处动作描述抽象，预演生成效果不佳 |
| 1-4 | 动作密度严重过载，Seedance 几乎无法生成自然动作 |

### 维度 4：摄影（对应服化道 + 分镜的"视觉设计"）

| 分段 | 表现 |
|------|------|
| 9-10 | 光影设计具体到方向/色温/强度；构图有讲究；镜头语言有变化 |
| 7-8 | 光影基本到位，但有部分镜头平淡 |
| 5-6 | 光影描述模糊，构图单一 |
| 1-4 | 完全没有光影/构图意识 |

### 维度 5：剪辑（对应阶段二节拍 + 阶段五衔接）

| 分段 | 表现 |
|------|------|
| 9-10 | 全片节奏有起伏，每个剧情点之间衔接自然，没有"硬切"感 |
| 7-8 | 节奏基本到位，但有 1-2 处过渡稍突兀 |
| 5-6 | 多处节奏雷同，过渡缺乏设计 |
| 1-4 | 节奏失控，过渡完全靠剪辑硬切 |

### 维度 6：美术（对应阶段三服化道）

| 分段 | 表现 |
|------|------|
| 9-10 | 每个角色/场景/道具都有审美设计，服务于人物和世界观 |
| 7-8 | 设计基本到位，但有"模板感" |
| 5-6 | 部分设计不够具体或与人物气质不符 |
| 1-4 | 关键词堆叠，没有审美意识 |

### 维度 7：音乐（对应阶段四）

| 分段 | 表现 |
|------|------|
| 9-10 | 音乐策略克制有理由；有"一发入魂"的瞬间；音乐与画面叙事高度契合 |
| 7-8 | 音乐方案合理，但缺少记忆点 |
| 5-6 | 音乐与画面情绪偶尔脱节 |
| 1-4 | 为填空而填音乐，完全不服务叙事 |

### 维度 8：创新性（贯穿全程）

| 分段 | 表现 |
|------|------|
| 9-10 | 高概念新颖独特，设定让人眼前一亮（参考 [创作五原则 - 超绝创意]） |
| 7-8 | 创意尚可，但部分套路化 |
| 5-6 | 创意平平，与已知作品高度相似 |
| 1-4 | 完全套路化，没有任何新颖元素 |

---

## 怎么用这 8 维（重要）

**不要在每个审核 skill 里都做 8 维评分**——那会让评分表臃肿且重复。

正确用法：
- 各 skill 保持自己的评分维度（如 script-analysis 看节拍密度/画面感/动作链等）
- 审核员在评分**前**先脑内过一遍 8 维（特别是 "音乐" "创新性" 这种容易被忽略的维度）
- 如果发现某个 8 维度上有明显问题，**单独在"问题摘要"中点出**（不重复评分）

**示例**：
- 阶段五审核完 Seedance 提示词，整体平均 8.5（PASS）
- 但脑内过 8 维时发现"创新性"很低——所有镜头都是套路化的（推镜/拉镜/特写）
- 审核员在 PASS 报告中加一段「**整体评价**：评分通过，但建议下次注意"创新性"维度——本集镜头语言较为常规，缺少独特视觉记忆点。可参考 [创作五原则 - 超绝创意] 重新审视开场和高潮的视觉设计。」

这就是 8 维参考的真正用法——**让审核员"想得更宽"，而不是"评得更细"**。
