# 创作需求｜三个1分钟短剧剧本

## 背景参考

第一个视频《规矩是给谁看的》已完成（见参考素材）：
- **角色**：媛媛（拟人熊猫茶馆老板娘）+ 喜儿（翼族快递员）
- **视觉风格**：电影级3D国风奇幻动画，暖色中式茶馆，竖屏9:16
- **时长**：15秒，5镜
- **核心笑点**：立规矩→被自己的规矩反制→服软撤规矩

## 新剧本要求

创作 **3个新剧本**，每个剧本：
1. **时长**：1分钟左右（可以是60秒，也可以是50-70秒区间）
2. **角色系统**：复用媛媛和喜儿，可以增加新配角
3. **场景**：以茶馆为主，可扩展到浮云城其他场景
4. **风格方向**：
   - 偏**网络热梗**（如社交媒体流行的段子/梗图/网络用语）
   - 偏**恋爱**（暧昧/误会/追求/表白等轻松恋爱情节）
   - 或两者结合
5. **具体风格不定，由AI判断**（根据角色性格和场景潜力自由发挥）

## 角色素材

参考图已放入 `input/参考/` 文件夹：
- 媛媛：熊猫主角多视图、八个表情包
- 喜儿：三视图、八个表情
- 茶馆场景：内部场景图

## 期望产出

三个独立剧本，每个剧本包含：
- 完整的分场剧本（时间轴、台词、动作）
- 镜头数量建议（1分钟可能需要8-12镜）
- 核心笑点/情感高潮点标注
- 方言选择建议（可以继续四川话，也可以尝试其他方言或普通话）
