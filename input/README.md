# 📥 输入文件夹（input/）

所有你要交给 AI 团队的原始文件都放在这里。支持文字和图片。

## 文件夹说明

### 选题/（→ 触发编剧流程）
放入选题相关的原始素材，编剧会全部研读后开始创作。
- 文字：灵感来源、故事梗概、参考文本、世界观设定等（.md / .txt）
- 图片：参考图、灵感图、mood board 等（.jpg / .png / .webp）

放好后输入 **~write** 开始编剧流程。

### 剧本/（→ 跳过编剧，直接导演）
放入你已有的完整剧本、歌词、台词等，跳过编剧阶段直接进入导演分析。
- 文字：剧本、歌词、台词、分场脚本等（.md / .txt）
- 图片：分镜草图、故事板等（.jpg / .png / .webp）
- **命名规则**：
  - 带 ep 前缀（如 `ep01-剧本名.md`）→ 制片人会识别为对应集数
  - 不带前缀（如 `myscript.md`）→ 默认作为 ep01，制片人会自动重命名为 `ep01-myscript.md`
  - 多个不带前缀的文件 → 制片人会提醒你重命名后重试

放好后输入 **~start** 直接进入导演分析。

### 参考/（通用参考素材）
放入风格参考、竞品截图、mood board 等，所有阶段都可能用到。
- 适用于辅助编剧理解方向、服化道对齐风格、分镜师参考画面
- 不会触发任何流程，仅作为参考

## 使用路径

```
路径 A：有选题想法，从头创作
   input/选题/ 放入素材 → ~write → 编剧全流程

路径 B：已有剧本/歌词，跳过编剧
   input/剧本/ 放入文件 → ~start → 直接导演分析
```

## 其他指令速查

- **~status** 查看当前项目进度
- **~help** 查看完整指令手册
- **~mode** 重选介入模式（全自动 / 关键节点 / 全程介入）
- **~skip music [epXX]** 跳过本集音乐设计（适合无音乐项目如 ASMR）

## 可以同时放吗？

**可以。** 选题和剧本可以同时存在：
- `input/剧本/` 有文件 → 决定走路径 B（跳过编剧直接导演）
- `input/选题/` 和 `input/参考/` 作为**全局上下文**，导演、服化道、分镜师都会读取参考

例如：你有一首歌词放在 `input/剧本/`，同时把 MV 风格参考图放在 `input/参考/`，
系统会跳过编剧，导演直接分析歌词，服化道设计时参考你的风格图。
